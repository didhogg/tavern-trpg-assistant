## 3. 基础版与扩展版

**基础版**（M0–M10，首个可发布版本）：能用官方 2014 资料，跑一场带人物、掷骰、战斗、地点和冒险的完整游戏。

| 里程碑 | 主线（必须） | 次要（可后移到下一个里程碑） |
|---|---|---|
| M4 人物（一） | D1.2a → D1.2b → 推送与真机验收 → U6.1 → R1.1 → L1B → U6.2 | 加入人物的「随机名字」 |
| M5 人物（二） | U6.3、U5.1–U5.7（背包拆套组、家族与加值档；语言；恩赐） | U6.6 多选批量、迷你模式 |
| M6 规则引擎与掷骰 AI 闭环 | R1.2、U3、U4 其余 | 掷骰卡的高级模式 |
| M7 战斗 | 遭遇、先攻、回合、行动栏（动作速查） | 物件与载具作为参战者 |
| M8 地图 | 地点树（库里的官方地点可直接加入）、地点详情、底图、点位、当前地点 | 区块 |
| M9 战役、活动、资料与库 | 冒险导入（D1.2b 冒险包）、遭遇难度计算、L1C 书籍阅读与速查 | 存到我的库、导出模组包 |
| M10 上手引导与首版验收 | 凡戴尔的失落矿坑默认安装、上手引导 | — |

**扩展版**（A 系列，首版之后）

| 编号 | 内容 |
|---|---|
| A1 | 建卡 / 升级向导（含属性生成器、出身表、牧师选神）与营地 |
| A2 | 旧存档迁移 |
| A3 | 第二批扩展数据：并入 D1.2b，删除此项 |
| A4 | VTT 地图（含官方地图分区：用户上传与官方同尺寸的地图后按 `mapRegions` 自动生成区块） |
| A5 | DM / KP 助手（含 AI 生成条目草稿） |
| A6 | 模组编辑器 |
| A7 | CoC 7 版规则包 |
| A8 | 详细日志与行程 |
| A9 | 扩展包功能 |
| A10 | DM 工具：CR 计算器与怪物制作、按环境随机遭遇、战利品一键生成 |
| A11 | 内容黑名单：按书、按类别批量隐藏 |
| A12 | 导出为卡片 / 酒馆角色卡 |
| A13 | 文本转换器：粘贴属性块、法术、物品文字转成条目 |

## 4. 数据导入的节奏

- 规格一次定完（`docs/handoff/D1.2_全量结构化导入_交接.md`）：全部类别、全部子结构、中英对照、字段覆盖矩阵。以后的单元只读数据，不回头补导。
- 执行分两次交付：D1.2a（核心十本书与 SRD）→ 规划 agent 审批 → D1.2b（其余 2014 版书与 80 个冒险）→ 规划 agent 审批 → 统一推送 → 驾驶员真机验收 → U6.1。
- 后续再有新数据（如新出的中文翻译）只是重新构建同一条管线。
