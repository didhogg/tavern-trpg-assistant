## 1. 总规则（所有 Unit 都照这几条）

1. **进人物卡就是草稿**：点「保存」才写进持久数据；直接离开就丢掉，不弹任何框。
2. **改错了就撤销**：底栏「撤销」（也可 Ctrl+Z），一直能退到上次保存。不做「已改（原来…）还原」「已去掉 [恢复]」这类显示。
3. **能算的自动算，想要别的数就直接改**：数字框里直接输入；把框清空就回到自动算的数（框里用灰字显示自动值）。不显示「覆」「手」之类的标记。
4. **从库里选的东西帮你填好**：选种族、职业、背景、专长时，它给的熟练、特性、语言等帮你填上；换掉时旧的那份自动拿掉，你自己加的不动。系统内部记得每条来自哪里，但**界面上不显示来源标签**（不用 `[族][景][职][手]` 这类缩写）。
5. **同一项只出现一次，熟练取最高、不叠加**：两个来源都给同一个技能，仍是「熟练」，不会变成「专精」。没有「同步」「重新核对来源」按钮。
6. **状态和效果只写说明提醒，不自动改任何数**：要改数就直接改。
7. **在界面里也能像「库」一样看资料卡**：人物身上来自库的东西（法术、物品、特性、专长、种族、职业、背景、状态、怪物属性块、语言）点名字就打开它的资料卡；资料卡就是库里的条目详情页（同一个组件），在弹窗内换页、不叠弹窗。
8. **术语下划线**：只有「点了会打开资料卡」的文字才加下划线；规则见 §6。
9. **掷骰**：框起来的加值就是掷骰按钮，不另放骰子图标；掷法开关（普通 / 优势 / 劣势）切到哪就停在哪；结果就近显示，并记进掷骰页的「最近」，可「填入输入框」。

**判断一个设计要不要的四个问题**（占两条就删或改简单）：玩家会不会主动用？撤销能不能代替？要不要额外记一份数据？会不会背着玩家改别的数？

## 2. 人物卡结构

```
+----------------------------------------------------------------------------------------------+
| A  <- List                      (name fades in after scrolling)                   [ ... ]    |
+------------+---------------------------------------------------------------------------------+
|            | B  Name (EN)                                                                    |
|   avatar   |    [race] [class lv] [subclass]                                                 |
|   96x120   |    HP [-] 12 [+] / 18    temp [-] 3 [+]    ==========-----###                   |
|            |    AC 12    INI +2    SPD 30    PB +2    passive 11                             |
+------------+---------------------------------------------------------------------------------+
| C  Abilities & saves                                                [ Generate scores ]      |
|     STR      DEX      CON      INT      WIS      CHA                                         |
|      8       14       12       18       12       10                                          |
|     (-1)     (+2)     (+1)     (+4)     (+1)     (+0)     <- check: click = roll             |
|     save     save     save     *save    *save    save                                        |
|     (-1)     (+2)     (+1)     (+6)     (+3)     (+0)     <- save:  click = roll             |
+----------------------------------------------+-----------------------------------------------+
| D  Spell slots & resources           [ > ]   | E  Effects                              [ > ] |
|    1st  ##..  2/4                            |    [Poisoned  1h  x]  [Bless  conc  x]        |
|    2nd  #.    1/2                            |    [ + add effect ]                           |
|    other: arcane recovery #  hit dice ##.    |                                               |
+----------------------------------------------+-----------------------------------------------+
| F  [Abilities & skills]   Class & features   Gear   Spells   Story                           |
+----------------------------------------------------------------------------------------------+
| G  (tab content)                                                                             |
+----------------------------------------------------------------------------------------------+
| H  * unsaved 3   [Undo]                         [Short rest] [Long rest]  |  [ Save ]        |
+----------------------------------------------------------------------------------------------+
```

- **外壳**（A–E、H）：名字、头像、种族 / 职业 / 子职胶囊、生命值（可直接加减）、AC 等四格与被动值、六属性与豁免（框起来的加值点了就掷）、「生成属性」按钮、「法术位与资源」栏、「效果」栏、底栏（未保存数、撤销、短休、长休、保存）。
- **外壳上看到的东西，点它就到它的修改处**（跳到对应分页并高亮那一行）：种族、职业胶囊 → 「职业与特性」对应卡片；AC、先攻、速度等 → 「属性与技能」对应行；法术位栏 `›` → 「法术」页顶部；效果栏 `›` → 「职业与特性」页的效果列表。法术位 ◆◇、资源格、效果药丸的 × 在外壳里直接点。
- **新人物**：种族、职业、背景胶囊显示成虚线「选种族 ›」「选职业 ›」「选背景 ›」。
- **没有法术位的人**：D 栏改叫「资源」，只显示狂暴、气、生命骰等。
- **五个分页**（一行放下）：
  - **属性与技能**（默认）：生命与防御（当前 / 上限 / 临时、生命骰、死亡豁免、AC 算法下拉、先攻、速度）、属性表（基础 / 种族 / 成长 / 最终，最终可直接改）、豁免与技能（方框切熟练、加值掷骰、掷法开关）、攻击与动作、其他熟练、语言、抗性、感官、力竭。
  - **职业与特性**：效果完整列表；职业卡（等级、子职、「升级」、加兼职；卡里直接写「1 级要选：技能 2 项」）；种族卡；背景卡；专长与其他。每张卡下面挂它给的特性和次数。
  - **背包**：按旧 Unit 3 v3，删改见 §4。
  - **法术**：**所有人都有**（施法来源可以是职业、子职、种族、专长、物品、契约魔法）；法术位上限与契约位在顶部；按环阶列；删改见 §4。没有任何来源时显示「还没有法术。种族、专长、物品或子职也可能带法术。[从库里加法术]」。
  - **背景故事**：角色概念、动机、性格、外貌、经历、理想、牵绊、缺点、给 AI 的说明、笔记。
- **生成属性弹窗**：标准数组 / 购点（27 点）/ 掷骰（4d6 去最低）三种方式共用一张「分到 / 种族加值 / 结果」表；「写入属性」只替换基础值，种族加值和升级加的不动。
- **升级**：一页，列出这一级得到什么（要选的就地选）、生命值取平均或掷骰，加到上限；不存升级记录、不做回退（降级就直接改等级数字）。
- **所有人共用一个人物面板**（驾驶员 2026-11-02）：玩家角色、NPC、怪物都是同一个外壳、同样五个分页、同样的按钮（短休、长休、生成属性人人都有）；数据里有什么就显示什么，没有的留空，不按人物种类分视图。
- **生命值为 0 不做任何特殊显示**（不出「倒地」「倒下」标签、不改版式）；**死亡豁免是普通字段**（成功 3 格、失败 3 格），固定在生命值旁边，随时可点，不和生命值联动。

## 3. 人物列表（已定稿：`docs/units/U6_人物管理.md` v3）

- 默认分类：**全部 · 队伍 · NPC · 敌人**，可以自己加分类；一个人只属于一个分类；分类栏右端「编辑分类」。
- 标签可以有多个，可以筛选（同时具备）；标签管理只有新建、改名（重名报错）、删除。
- ＊ 收藏常驻顶部一条（跨分类）；置顶在当前视图最前（在行尾「...」里）。

- 去掉旧插件的「角色 / 敌人」主页签、两个并排搜索框、四个管理按钮、每行的「＋标签」「管理」、以及「未分组 · 非营地 · 当前效果：无」这类空信息。随行 / 留守与营地归以后的【活动模块】。

## 5. 数据：所有人共用一个结构（驾驶员 2026-11-02 定）

**人物的数据就是现有的怪物属性块结构**（`monsterDataSchema`），玩家角色、NPC、怪物都一样。怪物填自己的字段（挑战等级等），玩家角色填自己的字段（职业等级等），两种字段共存在同一个结构里，都是**可选**；任何一条都只登记自己写了的内容。

```
人物（人物列表里的一条）
├─ 列表外层  名字、头像、分类、标签、收藏、置顶、来源（sourceRef）、存库位置（libraryRef）、给 AI 级别
├─ 当场状态  当前 / 临时生命、死亡豁免、各资源已用量、效果（说明与时长）、力竭、灵感
└─ 属性块 block = 怪物结构
    ├─ 原有字段  体型、类型、阵营、AC、生命、速度、六属性、豁免、技能、感官、语言、
    │            挑战等级（改为可选）、抗性免疫、特性、动作、附赠动作、反应、传奇动作、施法、介绍
    ├─ 新增可选  职业与等级 [{ 职业, 子职, 等级 }]、种族、亚种族、背景
    ├─ 新增可选  背包 inventory [{ 库物品引用 或 自定义, 数量, 已装备, 已同调, 所在容器, 已用充能 }]
    │            ——怪物身上的装备（护甲、盾牌、携带的武器）也放这里，和玩家角色同一个背包结构
    └─ 以后各分页 Unit 需要的（熟练标记、选择、故事等）同样作为可选字段加在这个结构上，不另起结构
派生（不存，每次算）：调整值、熟练加值、豁免、技能、被动、AC、先攻、生命上限（未手填时）、法术位上限、法术 DC 与攻击、负重
合并规则：来源给的 ∪ 你手加的 − 你删掉的；同一项一次；熟练取最高
```

- **从库加怪物 / 具名 NPC**：属性块原样复制，不转换（具名 NPC 复制它引用的那个怪物属性块）。
- **存到我的库**：把属性块写成一条 `monster` 条目（合法数据），存进我的包；不新增条目类型。
- **库里改**：我的包里的怪物条目用人物卡打开、改、「保存到库」；不另做编辑器（条目编辑器 U11 以后做，给其他类型用）。
- **装备不另做一套**：怪物的护甲、盾牌、武器与玩家角色的背包同构；AC 等由同一套计算从背包得出，书上写死的值照填在 AC 字段里（填了就用填的）。

## 6. 资料卡与术语下划线

- **资料卡** = 库的条目详情页（`EntryDetailPage`）原样复用；人物界面里不另做一套「物品详情」「法术详情」。
- **加下划线的**：人物身上来自库的条目名（法术、物品、特性、专长、种族、职业、子职、背景、状态、语言、怪物属性块）；资料卡正文里已有的术语（沿用 L1 §4）。
- **不加下划线的**：输入框里的文字（编辑时）；按钮和胶囊（它们有自己的动作）；自己手写、库里没有的条目；数字（数字的点击是掷骰或改值）。
- **一个元素只做一件事**：条目行里，名字（下划线）= 看资料卡；方框 = 切熟练 / 准备；框起来的加值 = 掷骰；数量步进器 = 改数量；「⋯」= 其他操作。不在同一个位置叠两种点击。
- **资料卡里的操作**只有「看」：要改人物身上的这一项，回到人物卡里改（资料卡不写人物数据）。
