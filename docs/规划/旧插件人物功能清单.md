# 旧插件（dnd-panel）人物功能清单

状态：待驾驶员勾选。勾选结果就是 U6-L「旧界面移植」的单元蓝图范围。

来源：`didhogg/dnd-panel-updates` 发布包 R11.77.7（单文件约 44 MB，其中代码约 2.4 MB；原生 JS 拼 HTML，全局状态）。按函数名前缀与界面文字整理，没有在酒馆里实际运行；页面截图请驾驶员补充（最喜欢 / 最常用的几页）。

勾选说明：
- 「骨架建议」列是我的建议：**搬** = 人物骨架就照旧界面做；**简** = 只搬界面与手动编辑，不搬自动结算；**后** = 放到对应的后续模块。
- 只搬界面的布局、流程与文字，用本项目的 Vue 组件重写；数据一律走 `usePeopleStore`，计算走 `RuleSystem.derive`。旧插件的结算逻辑不搬（不可维护，且规则要做成纯函数）。
