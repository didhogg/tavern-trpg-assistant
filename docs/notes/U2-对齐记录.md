# U2 存档与内容包 · 对齐记录（工作笔记，定稿后以 docs/units/U2_存档与内容包.md 为准）

## 已确认
| # | 主题 | 结论 |
|---|---|---|
| 1 | 存放位置 | 只用 IndexedDB（所有宿主一致）；备份靠导出按钮 |
| 2 | 内容包来源 | 扩展内置官方 D&D 5e 基础数据库；其他扩展数据包放单独数据仓库，在"库"中按需下载；手动导入文件始终可用 |
| 3 | 存档内容 | 默认只记录引用（内容包 id@版本）+ 游戏内副本；导出存档时可勾选"附带所用内容包" |
| 4 | 内置基础数据库范围 | 内置 PHB、DMG、MM（含 SRD）；其他重要扩展书预先制作好数据包，放在库里可下载；玩家可从界面导入数据库文件（须能识别）；"能正常下载并导入"是验收测试点 |
| 5 | 防丢失 | 手动导出 + 轻度文字提醒（不弹窗）；首次启动申请持久存储 |
| 6 | 删除存档 | 先进"最近删除"，可恢复、可手动清空；只有彻底删除需要确认 |
| 7 | 游戏中增减数据包/模组 | 可随时在当前存档设置中启用/停用；停用不影响已加入游戏的副本 |
| 8 | 规则作用域 | 不同规则的存档、模组、界面互不混用；不匹配一律拒绝；读取其他规则的存档须经"切换规则并读取" |
| 9 | 可识别的导入格式 | 只认本扩展格式（.trpgpack / .trpgsave）；外部格式转换器放进阶阶段；旧 dnd-panel 导出不做（驾驶员自行转换） |
| 10 | 完整备份范围 | 所有存档 + 各卡当前数据 + 设置 + 已安装内容包清单；内容包本身仅在勾选时附带；不含最近删除 |
| 11 | 外观与排版 | 参考 docs/img 图 1、图 3：深色侧栏 + 羊皮纸内容区，窄屏深色标题栏 + 底部标签栏；新增首页 |

| 12 | 首页横幅 | 当前地点参考图 → 上级地点参考图 → 本规则默认横幅（D&D 5e 用驾驶员图床图片，各规则各自提供）→ 纹样 |
| 13 | 规则安装入口 | 向导与库显示未安装规则；可安装规则提供"安装规则"（安装器 A7 实现）；即将推出只展示 |
| 14 | 首页 | 采用；概览格显示各页实时数据并作为通往各页的入口 |
| 15 | 导航 | 宽屏全部项在左侧栏；窄屏全部项在底部标签栏（可横向滑动），骰盘为浮动按钮 |
| 16 | 同名数据包导入 | 同 id：弹出"覆盖数据包？"并对比两边；不同 id 同名：取消 / 保留两个 / 替换已安装的 |
