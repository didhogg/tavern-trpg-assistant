## 3a-1 起始装备：类别选项与固定物品补回（12 个职业）

- **问题**：PHB/TCE 起始装备里的"任意简易/军用武器""任意乐器""法器/圣徽"等**类别选项**整条丢失；个别固定物品（圣徽、法器、"任意简易武器"）缺。
- **怎么改**：逐条修正表（`rows/s3a-equip.ts`）。类别项一律写 `{ category: <记号>, label: <书上的中文说法>, qty }`（形状见 01 D3，**记号只能用 01 D3 表里的**）。
  - **补一个选项**：路径 `/data/startingEquipment/<块号>/choice/<选项号>`，`insert` 一个新选项（一个选项是"物品数组"，如 `[ {category:'weapon:simple', label:'任意简易武器'} ]`；"类别＋盾牌"这种是两个元素的数组）。
  - **⚠ 固定给一个类别项（圣徽、德鲁伊法器、任意简易武器）不能写进 `fixed`**：`fixed` 的格式只收具体物品（必须有 `item`），写类别项会被构建校验拒绝，旧扩展也会拒绝。**做法**：在原来的 `fixed` 块**后面**（金币块之前）`insert` 一个新块 `{ choice: [ [ { category, label, qty } ] ] }`——"只有一个选项、且全是类别项的选一块"。意思是"固定给你一件这一类的东西，具体哪一件玩家在类别里挑"。读取器已把这种块算作**固定项**（`equipShape`，不算"选一"），所以登记里 `equipChoices` 的"选项数列表"**不会**因此多出一项。
  - **已有选项里缺元素**（圣武士、战士的第一个/第二个选一块现在只有"盾牌"，书上是"任意军用武器＋盾牌"）：往那个选项数组里 `insert` 类别项（路径 `/data/startingEquipment/<块号>/choice/<选项号>/0`，插在盾牌之前），再另 `insert` 第二个选项。
  - **块号以 T1 `show` 看到的为准**；`insert` 新块会让后面的块号加 1，所以**同一职业的多处修改按从后往前的顺序写**，或每行的 `path` 在前面的行生效后重新核对。
