## 3. 冻结的取值（01 里"第 0 站定"的全部项）

- `when` 的合法集合：`status` ∈ {`rage`}；`armor` ∈ {`none`}（没穿护甲，可持盾）；`shield` ∈ {`none`}。
- 塔莎等扩展书的可选法术：**并列字段 `spellLists: [{ to, spells }]`**，不用 `joins`（旧扩展会拒装），无 `level`。
- 公式变量：`spell.level` ✔、`spell.attack` ✔（求值时由调用方传入）；新字段里的公式一律用严格公式（不认识的变量报错）。
- `spell:` 记号支持的键：`class`（职业短名｜`any`｜`@选择id`）、`level`（0–9）、`school`（`a|b`）、`ritual`（只能 `true`）、`attack`（只能 `true`；**法术的 `attack` 字段第 1 站导入前会明确报错**）。键不许重复、不许别的键。
- `critRange`／`critDice` 的 `scope` ∈ {`melee`, `ranged`, `spell`, `weapon`, `all`}。
- `restores.on` ∈ {`short`, `long`, `shortOrLong`, `dawn`, `initiative`, `event`}（`event` 必须同时写 `event` 文字）；保留池名 `spellSlots`；`tracker.kind` ∈ {`escalate`, `perTarget`, `choice`, `cooldown`}。
- 起始装备类别记号：`weapon:simple` / `weapon:martial` / `weapon:firearms` / `weapon:simple-melee` / `weapon:martial-melee`；`focus:arcane` / `focus:druidic` / `focus:holy`；`tool:anyMusicalInstrument` / `tool:anyArtisansTool` / `tool:anyGamingSet`。近战＝物品带 `M` 标签。
- 固定代码：`code:vehicles-land`、`code:vehicles-water`。
- `lang:other`：构建与读取器均报错 ✔（构建有过渡清单 `tools/data/fix/pending/langOther.ts`，登记 `race.bullywug.dmg`、`race.troglodyte.dmg`、`race.gith.mtf`；第 2 站 2-9 改完删这三行）。
- `summon`：`ac`/`hp`/`attackBonus`/`damageBonus` 四个公式都可选但至少写一个；`by:"spell"` 必有 `baseLevel`、不许有 `classId`；`by:"class"` 必有 `classId`。
- `upcast` 的 kind：`damage`、`heal`、`targets`、`area`（`unit`: `ft`｜`mi`）、`duration`（`table`）、`note`（`auto:false`）；**不许新增 kind**。
