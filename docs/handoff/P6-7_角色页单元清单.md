# P6-7 人物页单元清单（2026-11-15）

驾驶员要求：人物所有页面按「一个主界面 + 它里面每个模块的全部子抽屉 / 弹窗 / 菜单 / 选资料页」为一个单元。线框在 `docs/design/p6-wireframe/`（`index.html` 按单元分组）。

（2026-11-15 第二次修正后共 53 屏；0c 第 1 步按真实建卡选项重画后 54 屏；0c 收尾删「建卡中」一屏（未做完的人物不存）、5g / 5h / 5i 按做好的界面重画后 53 屏；抽屉分三类：直接填写 / 来源条目 / 掷骰，见 P6-5 顶部说明。）

规则：每个单元先有主界面屏，再有子界面屏；子界面里凡标「待核对」的，是按 Tidy5e 做法或需求推出、还没逐项对过源码或数据，不当定论。名字与数值是占位示例。

单元之间的关系：单元 0 = 列表 + 建卡；单元 1 = 角色表外壳（页头 · 侧栏 · 应用条）；单元 2–9 = 角色表八个分页，每页都挂在外壳里。

### 单元 0 · 人物列表（主界面 + 子界面）（16 屏）

- `p6-1-list` 人物列表：分组表（Tidy5e 队伍表的样子）
- `p6-2-list-states` 列表的其它状态：空 · 搜不到 · 加载 · 拖动排序
- `p6-3-select-new` 多选（遭遇结束清怪）· 新建菜单
- `p6-4-template` 从模板加入（和分步建卡同一套两栏页）
- `p6-5a-name` 分步建卡 ① 名字（只有这一项必填）
- `p6-5b-race` 分步建卡 ② 种族
- `p6-5c-bg` 分步建卡 ③ 背景
- `p6-5d-class` 分步建卡 ④ 职业（建 1 级）
- `p6-5e-sub` 分步建卡 ⑤ 子职业
- `p6-5f-feat` 分步建卡 ⑥ 专长（不需要 / 需要：变体人类 326 个候选，前置条件未检查）
- `p6-5f2-opt` 分步建卡 ⑦ 可选特性（需要时：战士的战斗风格，11 个候选）
- `p6-5g-ab` 分步建卡 ⑧ 属性值（标准数组 / 购点 / 手填，无掷骰）
- `p6-5h-eq` 分步建卡 ⑨ 装备（固定给 / 选一个 / 类别槽 / 起始金币）
- `p6-5i-done` 分步建卡 ⑩ 检查后创建
- `p6-16-library-sync` 存入我的库（和存档分开）· 来源与同步
- `p6-17-states` 异常状态：读档摘要 · 资料不可用 · 操作失败 · 只读

### 单元 1 · 角色表外壳（主界面 + 子界面）（11 屏）

- `p6-6-detail` 主界面 · 角色表外壳整页 · 行动（逐栏对照 Tidy5e CharacterSheet.svelte）
- `p6-13-hp-undo` 子界面 · 生命原地改 · 设定草稿
- `p6-13b-override` 子界面 · 来源条目抽屉（一个结算模块一个）：最大生命 · 属性值 · AC / 先攻 / 专注 · 等级与熟练
- `p6-13c-override-state` 子界面 · 含手动条目的数：只有一条金线（没有悬浮提示）
- `p6-13d-avatar` 子界面 · 人物头像：填链接 · 直接上传
- `p6-14-history` 子界面 · 改动记录 · 撤销到这里
- `u1-id` 外壳子界面 · 身份（直接填写）· 种族 · 背景（来源条目）
- `u1-id2` 外壳子界面 · 体型与生物类型 · 速度 · 感官（来源条目）
- `u1-dice` 外壳子界面 · 生命骰 · 力竭 · 死亡豁免（改数量 / 掷骰）
- `u1-top-side` 外壳子界面 · 应用条 ⋯ 菜单 · 侧栏「收藏」
- `p6-15-previews` 大操作先预览：长休 · 短休 · 等级管理（升 / 降）· 套用模板

### 单元 2 · 行动（主界面 + 子界面）（3 屏）
