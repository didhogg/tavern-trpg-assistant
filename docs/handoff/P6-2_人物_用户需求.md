## 4 严格区分的四件事（你的原则，单独成节）

```
 库（包）                                 存档（战役）
 ┌──────────────────────────┐            ┌──────────────────────────┐
 │ 官方下载 / 自制导入的数据   │   套用模板  │ 人物（队伍 / NPC / 敌人）  │
 │ 怪物 · NPC · 人物 · 条目   │ ─────────▶ │ 当前 HP、法术位、状态……   │
 │ 我的库里的包               │            │                          │
 │                          │ ◀───────── │                          │
 └──────────────────────────┘   存入我的库  └──────────────────────────┘
      ▲
      │ 导入数据（文件 / 下载 → 进库）

 四个动作：导入数据 ≠ 保存 ≠ 套用模板
 保存还分两种：保存进存档（人物） ≠ 存进自己库的包（数据条目）
```

- 目标：**一个统一接口**，下载的 / 保存的怪物、NPC、人物都能当模板来源。
- 在人物页点"自制"保存的东西，默认属于**人物 / 存档**，不是库；存进库要另一个明确的动作（R06）。
