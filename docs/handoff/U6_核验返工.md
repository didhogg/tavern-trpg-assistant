## 二、必须改

### 列表

1. **重复标题**：窗口顶栏已经写「人物」，页面里又有一个大号「人物」。去掉页面里的「人物」标题，只留「共 N 人」与「模板」「＋ 新建」「...」同一行。
2. **第二行内容错**：现在写「类人生物」（生物类型），规格 §4.4 是——
   - 来自模板的人：**来源条目的名字**（`sourceRef` 指向的条目名，如「地精」）・ 挑战等级；
   - 有职业的人：职业与等级 ・ 种族；
   - 什么都没有（新建的空白人物）：**空着**，不写「类人生物」。
3. **生命、AC 要在同一行**（规格 §4.1）：右侧固定三列「生命数字 + 血条 | AC | ...」，没有生命时生命那列留空，AC 不跳到第一行；每行右侧各列竖向对齐。
4. **骰子悬浮按钮挡住最后一行的「...」**（390 宽度明显）：列表底部留出不小于悬浮按钮高度 + 16px 的空白。
5. **排序与当前分类要记住**（规格 §3.3）：排序键、方向、当前分类存进战役设置，重新打开人物页恢复。
6. **队伍页**（规格 §4.5）：「被动察觉」「速度」是第一行右侧的两列（和生命、AC 同一行、竖向对齐），不是第三行文字；没有数就空着。
7. 排序方向按钮用 `sort-ascending` / `sort-descending` 图标，悬停与可读名称写「从新到旧」等。

### 模板弹窗

8. **弹窗太小**：宽屏弹窗宽 min(1100px, 92%)、高 86%（规格 §9.1）；左列表与右资料卡占满剩余高度，各自滚动。现在两栏只有约 200px 高，第一行被裁掉。
9. **两个关闭按钮**：只留标题栏的 x，删掉分段按钮那一行的 x。
10. **工具行**：搜索框加放大镜与清除 x；排序下拉缩到和「筛选」同一行（`[搜索…] [筛选 N] 排序 [名称 v]`），不单独占一整行。
11. **列表名字**：中文名与英文名之间留空格，英文名 12px 次要色（现在是「地精Goblin」连在一起）。
12. **窄屏资料卡页**：点一行后整页换成资料卡（顶部「‹ 模板」+ 名字，下面是资料卡，底部操作栏），**不再显示**分段、搜索、排序、「共 N 条」。
13. **筛选**：挑战等级写成一行「[0 v] 到 [2 v]」；生物类型、体型用可多选的药丸（规格 §7.1 图）；筛选面板高度放得下全部项目，不用在面板里再滚。
