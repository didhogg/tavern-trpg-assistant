## 3. 用户和场景（规格出发点）

```
谁用   玩家或主持人，在酒馆里跑团前建人、跑团中升级
何时   ① 第一次建人：一口气选职业、到几级、子职业，答完作者的题
       ② 跑团中升级：一次升 1 级最常见，偶尔一次几级
       ③ 修错：选错了技能 / 子职业 → 重选那一级、换子职业、降级
       ④ 兼职：中途加第二个职业
想看到 每一步只做一个决定；系统替我算好门槛、会收回什么；答完看清加了什么；能撤销
```

### 4.14 自动给 / 收回 与 手动取下 / 找回 的规则
| 动作 | 规则 |
|---|---|
| 升级到 N | 新几级给的加上；以前在这几级取下过的保持取下（虚线），不偷偷装回 |
| 降级到 N | 高于 N 的全部收回（官方成长 + 作者导入附带）；手动加的不碰 |
| 重选某一级 | 只换这一级；被换掉选项的取下记录作废；其余不动 |
| 换 / 删子职业 | 子职业各级给的全部换掉 / 退掉；职业自己给的不动 |
| 删除职业 | 这个职业给的全部收回（含作者导入的起始装备） |
| 手动取下 / 找回 | 记一笔 / 删一笔，按来源装回 |
| 共同 | 先预览、确认后一次写入、一条撤销 |
