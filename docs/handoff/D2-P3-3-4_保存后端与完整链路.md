## 1. 存档里现在有什么（P3-3）

在 M1 存档上加一段，不重建：

```
存档
 ├─ 原有战役数据、ruleId
 └─ kernel（可选）
      ├─ rule + kernelVersion
      ├─ library：本战役选书设置（范围/额外加/排除/版本选择）
      ├─ dataVersion：官方版本 + 各自制包校验和
      ├─ overrides[]：保存时实际生效的房规覆盖
      │    ├─ target（作者编号）
      │    ├─ house（房规条目作者编号）
      │    └─ digest（房规内容指纹）
      ├─ actors[]：引用 refs、选择 choices、状态 state、个人调整、已掷骰点
      ├─ revision：修订号
      └─ undo[]：撤销记录（最多 50 条，改前状态）
```

读档检查 `check` 现在返回：

```
引用在不在（P3-1 ScopedLibrary.fetch）
  ok / not-installed / not-found / excluded / out-of-scope / unclassified
  → 只列出，不删引用、不改存档

版本哪里变了
  official：before → after
  brews：每个自制包 added / removed / changed
  → dataVersionChanges 逐项列出

覆盖哪里变了
  target：added / removed / changed（before/after 内容指纹）
  → overrideChanges 逐项列出
```

两个入口：

- `keepSaved()`：恢复原样，保留存档里的版本/覆盖，不写数据。
- `adoptCurrent()`：采用现在的，写当前版本/覆盖，再走 M1 `CampaignService.branch` 存成新分支；旧存档不变。

结构太新 / 规则没装：`loadSave` 在写任何东西之前就拒绝；单元测试证明当前战役和原存档都不被覆盖。

`.trpgsave` 格式 3 → 4：

- 单个存档仍带 kernel 段；manifest 新增 `dependencies`（作者编号清单）和 `kernelVersions`（每个存档的规则/版本指纹）。
- 旧格式 3 仍可读，缺的清单按空处理。
- 导入时用 `checkRefs` 列出缺的资料；完整备份的【库】恢复先导入自制/范围/房规，再恢复存档。
- 完整备份带自制（作者格式原样）、范围设置、房规链接；官方数据不进备份，恢复时缺的列出来。
- 备份大小有后端数值：`estimateExport` 返回 `saveBytes`、`libraryBytes`、`totalBytes`；备份提醒可带 `estimatedBytes`。

### 3.1 报错逐条解释（不再统一放过）

汇总脚本 `p3-4-report.mjs` 对每条报错单独匹配；匹配不到就标 `UNEXPLAINED` 并让本轮 FAIL，不会再用一句“已解释”放过。本轮 Chrome/WebKit 各 10 条，全部有单条解释：

| 报错 | 解释 |
|---|---|
| `gendata-nav-adventure-book-index.json` | 文件在【库】镜像里存在（`hasSourceFile('cn-official', …) === true`），作者导航 `navigation.js` 仍请求它；只影响书目导航，不参与条目/存档/备份/内核变更。**单列**，不手写生成文件。 |
| `http 404 /vendor/foundry/api/plutonium` + 成对浏览器 404 | Plutonium 明确可缺的独立后端；与条目、存档、内核计算无关。 |
| `requires usable window dimensions` | 0×0 隐藏小窗的界面尺寸提示；只影响 Foundry 界面渲染。 |
| `KERNEL_NEEDS_INPUT` / `Unhandled ... KERNEL_NEEDS_INPUT` | 官方 CombatTracker/Activity 界面渲染被空界面类截住；命令结果本身是 complete/pending，不是静默失败。 |
| 放置法术范围模板失败 | 本轮已用官方用法 `cast(..., { create: { measuredTemplate: false } })` 关闭模板；P3-4 结果里已没有这类报错。若再出现会进入 `UNEXPLAINED` 并 FAIL。 |

`p3-4-*.json` 里每条 `errors[]` 都带 `decision` 和 `fatal`；`unexplained=0` 才是 PASS。
