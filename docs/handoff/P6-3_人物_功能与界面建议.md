## 0 先改正一句话：小操作不要确认界面，但**照样进存档**

v1 §1、§5.0、D16 写成"小操作不经任何保存按钮…进改动记录"，读起来像"不进存档"，**这是我写错了**。实际规则（你 2026-10-29 的决定 + 存档分层设计 `D2-P3_整体设计.md` §4.2）：

```
游戏中的小操作（HP、法术位、状态、背包数量、加怪、删怪、休息……）
   │  点一下就生效：没有"确认保存"界面，也不弹确认框
   ▼
当前战役数据（"当前工作副本"）──→ 立刻写入，插件里显示的永远是它
   │   ├ 同时记一条"改动记录"（可撤销；撤销记录随存档一起存，默认保留 50 条，G22）
   │   └ 外壳页头亮「● 有未保存修改」（由内容摘要判断，改了就亮）
   │  点页头 [保存存档]，或按设置自动存档
   ▼
存档文件（读档读回的就是它；里面包含这些小操作的结果和撤销记录）

另外两件事，不在这条线上：
  ① 编辑设定（改名字、职业、属性、背景文字…）：先进「编辑设定」模式 → 草稿 → [保存] 才写进当前战役数据（需要确认 / 取消，所以走草稿）
  ② 存入我的库：把人物当模板放进库的包里；不动战役数据，不动存档
```

一句话：**"保存确认界面"只有编辑设定才有；小操作直接写进当前战役数据并进存档，靠撤销兜底，不靠确认框。**

## 1 一句话结论

**三个标签（队伍 / NPC / 敌人）用同一个列表、同一个详情页，只是过滤条件不同。**
- 人物自带数据，打开不依赖库在线；库里的书被关掉 / 卸载，只是人物里的术语链接显示"资料不可用"。
- **屏幕上只有两种"点"**：带小骰子的 = 掷骰；其余数字 = 点一下改（弹一个小浮层，点了按钮才生效）。游戏中的小操作立刻写进当前数据并可撤销；编辑设定另开"编辑设定"模式。
- **点错了找得回**：页头撤销按钮写明要撤销什么（"撤销：HP 18→12"），旁边一个箭头打开改动记录。
- **列表里的位置不会自己乱跳**（默认手动顺序，改了血不会把人换到最上面）；**宽屏列表和详情并排**，来回切人不用返回。
