## 3. 工作包（按依赖顺序，每包完成后单独本地提交）

### P1 外壳与控件库（U1）

- 悬浮球 + 主悬浮窗（默认 960×640，最小 360×480，可拖动、可缩放、位置记忆）；侧栏 176px / 56px、窄屏深色标题栏 48px + 底部标签栏 56px（基本蓝图 §2.1）。侧栏与标签栏只列已完成的页面：首页、库、设置；没有战役时同样只有这三项。
- 令牌按开发规范 §5.1，深浅两套。字体、间距、圆角、阴影同规范。
- 控件：按钮、分段按钮、下拉（listbox）、可搜索下拉（combobox）、**开关（开 `━●`，关 `○━`，`role="switch"` + `aria-checked`）**、勾选框、徽章、药丸、**下划线术语 `Term`**、**下拉菜单 `MoreMenu`（「⋯ 更多」）**、骨架占位。
- **全局弹窗宿主 `ModalHost`**：页面栈（入栈 = 前进，「‹」与 Esc = 出栈，栈底 Esc = 关闭）；同一时间一个；遮罩只盖主悬浮窗；焦点陷阱与还焦点；窄屏整页；保留每页的滚动位置与内部状态。弹窗内容以「页」组件交给它。见开发规范 §5.3「模态弹窗」。
- **提示条 `ToastHost`**：4 / 6 / 8 秒规则，悬停暂停，最多 3 条，带「撤销」。见开发规范 §5.4。
- 页头：页面标题、存档芯片（P3 接入）、只读徽章。
- 现有探针面板移到「设置 › 诊断」，保持原有 M0–M2 探针与自检按钮可用。

### P2 骰盘悬浮窗基础版（U3 基础）

- 掷骰引擎 `src/rules/dice/`：骰式解析（`XdY`、多组相加、加减常数、`d20` 优势/劣势、加值）、可注入随机数源、返回每颗骰子的点数、天然 20 / 天然 1。纯函数，单元测试覆盖解析、边界与错误提示。
- 悬浮窗：基本蓝图 §2.1.1 与线框。独立窗口，不挡后面，点外部不关闭，模态弹窗打开时仍可用；位置记忆；窄屏 92% 宽、贴近标签栏上方。
- 「填入输入框」：把注释追加到酒馆输入框（`#send_textarea`）末尾，不发送、不覆盖；格式 `<!-- [掷骰] 说明：1d20+5 = 17（12+5） -->`。M0 探针已验证注释方式。失败时显示「尚未填入」并保留「复制」。
- 最近记录：本卡最近 20 次，本机保存（`localStorage`，带 try/catch）。

## 5. 已知的坑

- 界面挂在 Shadow DOM 里；样式用 `?inline` 注入；弹层的 portal 目标是 Shadow 内的 `.trpg-portal`（见 `src/ui/shell/mount.ts`）。酒馆自己的样式会影响原生表单控件，勾选框、输入框要自己画。
- 酒馆有全局键盘快捷键：输入框内的按键不能冒泡到酒馆；中文输入法组合期间不提交。
- 触屏拖动要用 Pointer Events（`useDrag`），悬浮窗不能拖出屏幕；窗口缩放后要重新夹回视口。
- 弹层控件上线前必须有 e2e：真实点选项，等界面稳定（≥250ms 或等具体状态）再断言，Chrome 与 WebKit 都跑（开发规范 §5.3）。
- 工程规则：单文件 ≤400 行；不写空 catch；状态只经 store；规则是纯函数；结构变更必带迁移；现有 114 个单元测试、26 项数据测试、Chrome 与 WebKit 共 96 项 e2e 必须继续通过。
- 复杂列表用虚拟滚动（包条目最多约 600 条，SRD 2,232 条）；搜索就地更新，不整页重绘、不丢焦点。
- 提示条、弹窗、悬浮窗里的文案用玩家语言，不出现开发术语。

## 7. 驾驶员真机验收项（在 TauriTavern 上，只能驾驶员给出）

1. 在一张没有数据的角色卡上：侧栏只有首页、库、设置；点纯色横幅进入开局向导，走完四步，首页变为战役概览。
2. 点书名（向导 ② 与库）打开弹窗看条目，点条目在同一弹窗翻到详情，「‹」返回；全程屏幕上从不同时出现两个弹窗。
3. 库·扩展：安装一本书、更新、卸载（行尾「⋯ 更多」）；断网时显示失败与重试。
4. 库·本存档：把一本书的开关从 `○━` 拨到 `━●`，资料可查；规则选项开关后撤销。
5. 保存、分支、读取、删除与恢复、导出与导入存档文件。
6. 骰盘：点 ⚄ 打开，点 d20 把它加进骰式、点「掷骰」出结果，「填入输入框」后酒馆输入框末尾出现注释，没有自动发送；拖动、点外部不关闭、主窗口打开弹窗时仍可掷。
7. 所有提示条会自己消失。
8. 手机宽度：标题栏 + 底部标签栏，弹窗整页，骰盘贴近底部。
