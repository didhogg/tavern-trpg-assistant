## 3. 最容易做错的地方（上一轮就栽在这些上）

1. **没有侧拉抽屉**：所有管理 / 选择 / 资料都是**居中弹窗**；手机变**底部整页，底栏固定**；`drawer` 变体详情页不再用。小气泡只作**悬停提示**（只读、不遮触发元素、没有按钮）。
2. **药丸点击 = 资料弹窗**（有真实正文）；**悬停 = 来源**；「+N」**悬停列被折叠的药丸、点击进对应标签**。不要「没有更多说明」。
3. **敌人视图与人物视图同构**：灵感、生命 ✎、死亡豁免（常驻，不是 0 血才出现）、生命骰、力竭、休息、职业框全部照常显示；**只多挑战与经验两枚徽章**。敌人的法术位读属性块 `spellcasting[].spells[环阶].slots`。
4. **读数弹窗不是矩阵**：三个标签（防御与先攻与熟练加值｜速度｜被动），每项是「项目卡」：来源与算法（只读灰字）+ 手动调整（输入框）+ 覆盖 + **[自动计算]**；**不画「—」占位**；**只读 = 纯文字，能填 = 才有框**。
5. **档案是三张带边框的卡**（防御｜感官｜熟练），各自 ✎；空类整行不画（**不写「—」**）；每类最多 3 个药丸 + 「+N」；弹窗里多类别用**浏览器式标签**；**入口决定标签**；每个类别列全（`enums.ts` 13 种伤害、15 种状态；语言 8+8+2+「其他书籍」折叠；武器类别 + 具名；护甲 4；工具分组；感官 4 种 + 距离框）；被移除的自动项进「可恢复」+ [按来源重新分配]。
6. **种族 / 职业 / 背景流程**：选择 → 补选 → 分配；按钮写「选用{名称}」；**可什么都不分配**（「只选用，先不分配」、分配页全不勾也能「应用」）；**更换时分配页最上面「移除旧来源内容」默认勾选**；写入带 `auto` 来源；属性加成与速度**不进分配**（由派生函数读取）。
7. **等级管理**在身份弹窗标签里，**真的能升降级**（生命：平均 / 掷骰，记 `hpRolls`；法术位、特性、属性提升级读数据）；职业框是**字段框**，点它看职业资料；旁边「等级管理」次按钮；**没有升级 / 降级两个按钮**。
8. **属性弹窗**：放入点数后该行**红框高亮**、池里数字**变灰**、再点退回；主按钮**「保存并写入属性点」**；「全部自动计算」改成「清除手动修正」并写明会清什么。**暂存的改动关闭即放弃。**
9. **效果结构化**：人物效果 = 类别 + 时长 + 是否专注 + 结构化 effects 快照；状态一行、效果一行（状态以外全是效果，未分类归「其他」）；**先审计数据再修转换器**，增补 `rollBonus`；骰盘自动加值**只来自结构化数据**，**不预制「神导术」之类**。
10. **骰盘检定 / 豁免**：行动者**真下拉** → 属性与技能**两个真下拉**（没有手风琴，没有平铺的 6 属性 / 18 技能网格）→ 自定义加值（常数 / 骰式，加「查资料」）→ 难度（**纯数字**，没有「很易」文字；随机；对抗；不设）→ 掷法（来源列表，优势劣势互相抵消）→ 掷。**选任何东西都不改变其他分区的位置**；快捷进入时只需设掷法与 DC；被动 = 随机 DC + 对比；**点击只填入不掷**。
11. **悬停来源**：AC、先攻、速度、熟练、被动、属性、技能、豁免都悬停显示全部来源明细。派生函数返回 `parts`。
12. **视觉**：没有 `--ok` 绿（成功 = 酒红实心、失败 = 墨色实心，文字照写）；骰子图标只在先攻格与属性图例；图标只用 16/20/24；药丸全是实线；档案卡有边框；顶栏三组有分隔线；FAB 不压内容（安全区、底部留白）；头像角标不重叠、没有「小人」徽章；死亡豁免点击区 44。
13. **截图自己看**，灰度再看一遍；**独立评审 < 8 分改到 ≥ 8**。
