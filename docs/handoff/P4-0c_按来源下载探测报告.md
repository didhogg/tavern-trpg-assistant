> 下载内容的规则是作者的离线设计（预载除冒险外的全部数据 + 搜索索引；冒险正文按本取），B1 设计 §0 / §8.2 / §8.3 已定，`src/library/plan.ts` 已实现，P2 已完成验收。P4 这条后端支线**不改下载设计**。

目的：驾驶员要求向导里"总下载约 xx MB 随勾选的书近似计算"，并在战役创建后才下载。先验证作者数据能不能只下一部分、我们的流程在文件不全时怎么表现。**没有改任何正式代码**；探测脚本 `work/tmp/partial-probe.mjs`，结果 `work/e2e-lib/partial-probe-*.json`（Chrome 与 WebKit 一致）。

## 结果 1：下载量（中文，按作者预载规则的文件清单，未实测下载）

| 选择 | 固定文件 | 按来源的文件 | 合计 |
|---|---:|---:|---:|
| 整套 | 34.6 MB（121 个） | 书 23.4 + 怪物 17.4 + 法术 1.6 = 42.4 MB（302 个） | **77.0 MB** |
| 默认 2014 范围（作者判为旧版的 112 个来源） | 34.6 | 书 16.0 + 怪物 14.3 + 法术 0.9 = 31.2 | **65.8 MB** |
| 只选 PHB / MM / DMG | 34.6 | 书 2.2 + 怪物 2.4 + 法术 0.6 = 5.2 | **39.8 MB** |
| 什么都不选 | 34.6 | 0 | **34.6 MB** |

英文没有单独探测，文件清单计算得整套 73.2 MB，按同样比例估算。**默认 2014 范围只比整套少约 11 MB（15%）**，因为 135 个拆分来源里 112 个是 2014 范围。

## 结果 2：只下一部分，作者加载器的表现（空库，固定文件 + PHB / MM / DMG 对应文件）

| 项 | 结果 |
|---|---|
| 77 个类别里 | **73 个解析成功**（含职业、物品、种族、专长、背景等单文件类别），**4 个整类失败**：`monster`、`monsterFluff`、`spell`、`spellFluff` |
| 失败原因 | 作者加载器按 `index.json` 把该目录所有文件都读一遍，第一个缺的文件就整类报错（"文件不存在：data/bestiary/bestiary-aatm.json"） |
| 书（按本取） | 选中的 3 本成功；没下载的书各自报"文件不存在"，**只影响那一本**，不影响别的 |
