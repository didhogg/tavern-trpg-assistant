# P4-0b 补后端：开局入口与战役视图

日期：2026-11-09。驾驶员批准草案（向导做四步；选完书后在【库】后台下载，向导不卡）。只补后端，不碰界面，不推送。

## 做了什么

```
向导 ──startCampaign(规则,资料语言,选书范围,冒险,名字,备注)──► 立刻返回
        │ 同一个事务里：第一个存档就带 结算内核段 + 选书设置
        └ 后台（【库】下载任务，不等）：
            缺的官方资料（所选语言 + 英文，内核只认英文原件）→ startOfficial（含换算）
            选的冒险 → 资料装好后 startAdventure
            下载完：战役还没被动过 → 补上现在的数据版本记号并重存一次
```

| 接口 | 位置 | 作用 |
|---|---|---|
| `backend.starter.wizardOptions(规则, 语言, 选书?)` | `src/core/start-campaign.ts` | 向导每步要的：范围清单与默认值、各语言资料装好没/下载中任务、书目、冒险 |
| `backend.starter.startCampaign(...)` | 同上 | 见上图；返回 `downloads`（任务编号）与 `finished`（后台收尾，不会 reject） |
| `campaign.getCampaignView(ownerKey, ruleId)` | `src/core/saves/view.ts` | 战役名（=根存档名）、根、当前、分支（带 parentId）、其他战役、各处数量 |
| `startNewCampaign` 新参数 `initialData` | `src/core/saves/campaign.ts` | 开局内容与第一个存档一起写，没有“建完又变脏” |

战役树规则：只看手动存档；父存档不在（被删）→ 这一份当根；恢复后自动接回；自动存档只数不进树。
书目在所选语言的官方资料装好前为空（书目来自装好的数据）；向导此时只显示范围，并提示“选完后在后台下载”。

## 草案之外多做的一件
下载完补数据版本记号（`refreshFreshVersion`）：资料没装时建的战役版本记号是空的，不补的话第一次读档就弹“资料换过版本”。只在战役未改动、无人物、内核修订号为 0 时才补；用户已动过则不碰。

## 验证（只做了局部快速测试）
- 单元：战役视图 3 项、开局入口 4 项；全部单元 185 项过；`npm run lint`、`npm run build` 过。
- **没验证**：对真实装好的数据在浏览器里走一遍 `startCampaign`（真实 dataVersion / 覆盖 / 下载任务）；Chrome / WebKit 未跑；全线回归按驾驶员要求没跑。
- 下载中途关页面：任务不续跑，下次进战役需手动重下（`startOfficial` 本身支持续传）。界面阶段再决定要不要自动恢复。

## 补：BE-7 书架（2026-11-09，驾驶员批准）
没装官方数据也能列出各本书和冒险，按作者分组。

```
wizardOptions ─► scoped.shelf(选书设置) ─► catalog(c, { remote: true })
                                              │ 官方数据集没装：BookDirectory 开允许联网的一次性小窗，
                                              │   让作者程序自己读书目文件（文件名来自作者加载器登记表）
                                              │   实际只下 4 个小文件：books.json、adventures.json、
                                              │   导航索引、初始化要读的 tag-redirects（中文共约 1.27MB 原文，传输约 0.33MB 含文件清单）
                                              │   整理结果按“数据集 + 锁定版本”存进派生物，下次与断网都直接用
                                              │ 已装好：用现成本地小窗，不联网
                                              ▼
                              按作者分组表排序的 ShelfGroup[]（组内按出版日期）
                              每行带作者字段：分组、出版日期、父来源、冒险等级 / 故事线、封面（作者原对象，只是链接信息，不下载图片）
```
- 联网取不到：`shelfError` 写明原因，`shelf` 为空，向导不卡住，可重试；不写缓存。
- 默认 `catalog(c)`（不带 remote）行为不变。
- 代码：`library/directory.ts`、`library/shelf.ts`、`runtime/frame/directory-commands.ts`，`scoped.ts` 接入。
- 测试：单元 `tests/unit/library/shelf.test.ts`（6 项）；浏览器 `tests/e2e/library/book-shelf.mjs`（Chrome、WebKit 各 16 项全过：空库联网、书数量来自作者书目、分组顺序、缓存、断网重开、空库断网给原因、启动报错消失）。
- 实测（中文，空库联网首次）：Chrome 2.1 秒、WebKit 1.0 秒；之后 10–30 毫秒。67 本书、102 个冒险，分 10 组出现（作者表 12 组，homebrew 与无书的组不出）。
- **没验证**：封面链接怎么拼成可显示的地址（只带了作者原对象，P5 显示时再查作者的图片规则）；GitHub 未登录限流（每小时 60 次）下的表现；手机、TauriTavern 真机。

## 补：BE-8 资料状态与大小（2026-11-09，驾驶员批准）
`starter.dataStatus()`（只读、不联网）：每套官方资料的 `status`、库里记的原始状态 `recordStatus`、整套下载大小 `downloadBytes`、正在跑的任务。`wizardOptions.data[]` 同样带上。

```
status:  none        没装过
         running     有任务在跑
         incomplete  库里记着 downloading / parsing / cancelled / failed，但没有任务在跑
                     （刷新页面后任务列表会清空，靠这个认出"装了一半"，界面给"继续"）
         installed   已装好
downloadBytes: 文件清单（书目步骤顺带缓存）按作者预载规则算，冒险正文不计；没联过网为 null
```
- 实测（Chrome、WebKit 一致）：没装时中文资料 80,747,044 字节（约 77MB）；模拟"库里记着 downloading、没有任务"→ incomplete，清掉记录 → none。
- 测试：单元 3 项（`tests/unit/start-campaign.test.ts`），浏览器局部 `tests/e2e/library/book-shelf.mjs` 增 2 项（两浏览器各 18 项全过）。
- 新增 `FileProvider.cachedFileList`（只读缓存，不联网）。
