## 驾驶员批准与追加要求（2026-11-11）

- 顺序 A→B→C→D→E。开工前后端先做：G2（`ResolvedTag.part` 补 `ixNamedSection`）、G3（跨条目 / 书的反向关联表）、G5（自制更新的对象计划、按书 / 按语言的准确估算）、G6（书目 / 包行带另一语言名字，书架和下载页中英名都能搜到，原第 18 条）。做 B 时补自制包按包下载进度。自制包和冒险的暂停 / 继续暂不需要。其他后端问题，查到后停下报告。
- 修后端前先查 handoff 里归档以外的文档，确认之前是否做过，然后在原实现上精准修，不另起炉灶。
- 【库】下载悬浮窗现在被压在插件框下面看不见。要求是让它看得见（可以超出插件框），不是限制在框内。
- 规则标签（2026-11-11 驾驶员定）：书架、下载页、包标题等所有显示规则版本的地方，不再写「旧版 / 新版」或「2014 规则 / 2024 规则」。作者归为 2014 规则的标「5e」，归为 2024 规则的（含 2025 年出版的）标「5.5e」；分不出规则的不标；从自制源下载的包标「自制」。
- 依赖按作者程序处理（2026-11-11 驾驶员定，取代当天先批的「装 mod 方式 / 保留暂停」）。实测发现：缺一个依赖，作者会让**全部**自制条目消失（见 §6），所以不提供「保留」：
  - 下载自制包前弹预览，列出会一起下载的依赖包、需要的官方书（可勾选一起下载）、找不到的依赖。可以选「以后下载不再提示」（设置 → 库里也能改），依赖仍然自动一起装。
  - 卸载一个被别的包依赖的数据源时，预览列出会一起删除的包（作者规则，不可取消）。
  - 包 ⋯ →【管理】→【依赖包】标签：列出这个包依赖的所有包（自制包或官方书），标出已装或缺；缺的附下载按钮。管理页顶部有缺依赖时自动提醒。
  - 点进因缺依赖读不到的条目：说明需要哪个依赖包，联网时自动拉取一次；失败时显示原因和【重试拉取】。
  - 读档补包按书、按包给，不再整套下载；自制包补装时作者自动带上依赖。
  - 修复单本卸载漏掉「只有来源、没有书号」的来源。
- 所有错误用横幅提示。下载类失败在横幅或下载悬浮窗里重试。任何情况下（下载中、断网、某项出错、读不出）都不能跳页、卡在某页、标志一直不消，也不能操作后整页空白。

## 2. 逐项接线与验收

### A. 书架、按包浏览与删除

**1｜依赖清单、固定确认按钮。** 书架和我的库共用删除预览。按真实对象构造 `RemovalTarget`，调用 `backend.removalImpact(target)`，确认后原样调用 `backend.removalExecute(impact)`。只有 `mustRemove` / `removeTogether` 指定的包随删。方向是「删除提供者 → 找到失去最后有效提供者的使用方 → 沿使用方继续查」。依赖提供者、普通关联、存档、房规与版本选择按各自的影响说明展示。多个替代提供者仍可满足时保留使用方。指纹过期须重新预览确认。用现有确认弹窗，把长明细放进单独滚动区，底部确认/取消固定可见，键盘与触屏可达。验收用长清单、替代提供者、传递依赖和反向依赖；取消零写入，确认只执行一次计划。 [影响与计划](../../src/core/removal-impact.ts) · [现有动作入口](../../src/ui/libview/actions.ts) · [U2 确认线框](../design/p5-wireframe/out/u2-3-uninstall.html)

**2｜2014、2024/2025 书目可单独管理。** 官方书行传数据集和作者 `bookIds`，冒险传 `adventureIds`，自制传 `docIdLocals`。整套移除是单独的明确入口。确需中英一起操作时，一次向预览传目标集合，禁止按语言循环执行。资料是逻辑卸载，界面按实际报告展示空间情况。验收删一本 2024 规则体系的书，其余书和同一书架仍可读，删除后可单本重装。 [目标类型](../../src/core/removal-impact.ts:14) · [卸载执行](../../src/library/uninstall.ts)

**9｜下载前后保留战役、书架与详情。** `libview.refresh(s)` 使用当前战役；保持既有开关、搜索、滚动和旧详情。已读书架只在一次新版读取成功后替换。更新中、失败、取消继续用旧版本，不把 loading 当未安装。目录、自制、书架和日志错误单独显示；日志列表先读 `logs.list`，体检失败只影响自己的区域。任务进度直接更新对应行，避免每次轮询都重取目录或清空书架。过期请求按资料版本、战役身份与页面请求序号丢弃。包与搜索保留已有虚拟滚动。验收有/无战役、离线、任务失败、下载过程中打开旧详情、多次点同一对象以及两个任务并行。记录首个反馈、查询和小窗数量，定位主线程卡顿。 [书架状态](../../src/stores/libview.ts) · [分区读取](../../src/library/scoped.ts:336) · [下载页当前刷新](../../src/ui/libview/DownloadTab.vue)

**包身份与书架。** 官方行按来源数据集和书号，自制行按 `CatalogRow.pack.docIdLocal`，我的库按已装包编号。同来源多包可分别打开、卸载和重试。按包浏览用 `scoped.query(c, prop, { mode: 'browse', packDocIdLocal, expand: true, view })`；包分类取 `service.packOwnedItems(setId, brewPack, view)` 的非空类别。官方单书查询约束在选定数据集和作者来源，显示战役可用性时用现有 `scoped.viewFor`。列定义用于显示名称和排序，条目是否存在由查询结果决定。关闭的条目灰显仍可看。正式列表行、弹窗栈、语言切换都保留来源、真实包编号、`EntryRef` 和现有备选身份。验收《元素与彼界》三个来源都在，《超大长弓》出现，同编号两包点击后仍是各自内容。现有详情接口的包身份边界见 §3。 [按包查询](../../src/library/scoped.ts:185) · [包页当前接线](../../src/ui/libview/pack-data.ts) · [导航入口](../../src/ui/libview/open.ts)

### B. 下载、更新和进度

**3｜按书下载、按对象更新。** 下载页从 `scoped.catalog(c, { remote: true })` 取得已装和可装行；界面可单本、多选以及明确的批量动作。按书请求 `tasks.startOfficial(setId, { books: ids })`，冒险用 `startAdventure(setId, id)`，自制沿用作者目录和 `service.brewAddUrl` / `brewInstallSources`。按实际选中集调用已有下载估算，显示新传、共用和复用字节；取不到计划显示计算中或错误。界面无需维护文件或依赖列表。首次按书仍可能需要一批共用文件，估算以实际计划为准。 [选书估算](../../src/library/download-estimate.ts) · [生产任务](../../src/library/tasks.ts:179)

「拉取更新」留在书架上，只做 `updates.check(setId)` 和 `service.brewCheckUpdates(setId)`。按真实对象标「可更新」，并显示已装资料；用户可选能独立更新的书或包，或更新全部待更新对象。官方用 `updates.apply(setId, { bookIds, adventureIds })` 或确认整批后调用 `apply(setId)`。共享文件牵连或未选对象也变化时，按后端结果说明整批范围和字节，需用户确认，禁止自动退回整套下载。「整批更新」是同资料集内当前计划，界面显示后端算出的新增、改动、移除和复用。自制按 `brewPull(setId, docIdLocals)`，部分失败和检查错误分别保留，失败可原地重试。验收空库按书安装、部分安装补一本、更新仅取计划差异、共享更新拒绝独立提交、取消或失败保留书架和战役。 [检查与执行](../../src/library/official-update.ts) · [更新现有入口](../../src/ui/libview/update-flow.ts)

**4｜规则版本独立于更新。** 下载区用作者的 `edition.classic` / 已有范围信息显示「2014 规则」「2024 规则」与「未归类」。2025 发布且作者归入 2024 规则的书仍显示「2024 规则」，出版日期另外显示。可筛两种规则范围，再在范围内选书，书的安装状态和「有更新」各自呈现。这个下载筛选不会改战役规则或已装资料。验收规则范围切换、未归类、同一书已装但有更新、同一书已装且最新。 [作者版本判断](../../src/library/runtime/frame/edit-commands.ts:16) · [书目接口](../../src/library/scoped-catalog.ts)

**10｜悬浮窗与每个下载任务的控制。** 侧栏和底栏共用浮层，锚定库图标并限制在插件窗内，跟随滚动/缩放。鼠标从图标移到浮层可继续操作，触屏、键盘、Escape 与外部点击有明确入口。任务行用后端任务号或操作号，目标含数据集及真实书/包身份，保留同语言同时请求两本的两行。总量已知用环形进度，未知用阶段文字与不定进度环。暂停等待后端状态变成 `paused`，继续采用新的任务号，取消确认后按任务号调用。可逐项关闭失败、取消或已完成提示，末项消失时图标去环；清除展示和取消任务各自有明确动作。栏内图标、数字及环均在布局边界内。能力范围见 §3。验收宽/窄、鼠标跨浮层、键盘、触屏、进度未知、多个任务、失败逐项关闭、最后一项消失。 [当前浮层](../../src/ui/shell/LibraryNav.vue) · [下载状态](../../src/stores/downloads.ts) · [任务控制](../../src/library/tasks.ts:104)
