## 1. 驾驶员对这两个单元的要求（原意汇总，按时间）

**页头布局**
- 页头三个框：名字 / 职业与出身 / 特征。每框右上角一支小铅笔，点框就打开这个单元的编辑弹窗。
- 框里的下划线术语点了打开术语详情弹窗。

**名字弹窗**
- 只有「名字」和「英文名」；名字旁的复制按钮删掉。

**职业与出身**
- 包括职业、兼职、子职业、种族、背景。
- 宽屏左边一行一行、右边看细节；窄屏在弹窗里翻页。
- 等级用下拉改。升级、降级的预览和选择都在右边（窄屏翻页）。
- 职业的每一级都能点，右边看这一级的细节、做这一级的选择。
- 升级 / 降级时自动收回 / 赋予（用户选过的）自动项目；用户也能手动取下、再补回。

**特征**
- 体型 / 生物类型 / 速度 / 感官 / 阵营，每样用最合适的控件：
  - 体型用药丸，生物类型用下拉；
  - 速度一行一项 +「添加一项」下拉，感官用药丸；
  - 阵营用九宫格。
- 这几样不用资料片那种大卡片。

**数据与显示（共用规矩）**
- **所有选项、条目数据，一律从用户库里开着的全局数据包取，没有例外**（不是「官方 xxx」，不许在前端写死名单）。
- 悬停只出一个不遮挡的小注释，例如【来源：种族-半精灵】。
- 「从资料库添加」一律用统一两栏页：宽屏左边库列表、右边资料内容，在当前弹窗里翻页。
- 所有弹窗只能在左侧侧栏外面的内容区里打开，侧栏永远能点。
- 弹窗里再开弹窗 = 在当前弹窗里翻页：左上「返回」，右上「×」。
- 中文显示只走统一出口（`services.backend.texts` / `kernel/display.ts` 的 FrameText），禁止自己接。

**11-25 最后几轮**
- 批零星几条手写译文，但必须走统一入口，不许遇到一个手写一个。
- 「只能重选最高一级」不行，去找现成程序改。
- 熟练、语言本来就有编号，必须画下划线。
- **不做到极其完整可用，禁止交付。**

**驾驶员最后两条消息（没修，最重要，见 §6）**
- 「为什么主职业和子职业不在一起？为什么主职业选 2 级，子职业能选任意一级？你看看人家做的是不是这样？」

- 上一位 agent 的小脚本（原来放在会话临时目录，会被清掉，照抄在这里）：
```python
import json, socket, sys
SOCK = '/tmp/tauri-pilot-com.tauritavern.client.sock'
def call(method, params=None, timeout=15):
    s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM); s.settimeout(timeout); s.connect(SOCK)
    s.sendall((json.dumps({'jsonrpc': '2.0', 'id': 1, 'method': method, 'params': params or {}}) + '\n').encode())
    buf = b''
    while not buf.endswith(b'\n'):
        chunk = s.recv(1 << 20)
        if not chunk: break
        buf += chunk
    s.close()
    return json.loads(buf.decode() or '{}')
if __name__ == '__main__':
    print(json.dumps(call(sys.argv[1], json.loads(sys.argv[2]) if len(sys.argv) > 2 else {}), ensure_ascii=False)[:4000])
```

  - 然后轮询 `#trpg-assistant-root` shadowRoot 里 Vue app 的 pinia，看 `_s.get('app').booted`。
  - 插件界面在 shadow DOM 里，点元素要从 `document.querySelector('#trpg-assistant-root').shadowRoot` 找。

**真机脚本规矩（出过事故）**
- 刷新后等 `campaign.owner` 就绪，再多等约 20 秒才操作。

## 9. 诚实说明：为什么会这样

- 上一位 agent 一直用自己写的 e2e 在**模拟页面**上验证，路线固定（牧师，1 级选子职业，答题全选默认）。检查的是「数据对上」，不是「人用起来对不对」。
