## 2 地基

### 2.1 颜色：旧名 → P4 新名（**不新增色相**）

| U5R / U6 旧名 | 用途 | P4 令牌（浅 / 深） |
|---|---|---|
| `--paper` | 页面底 | `--bg`（#fdf8f0 / #302a24） |
| `--card` | 卡片、输入、弹窗内容 | `--surface`（#fefdfc / #3b332b） |
| `--panel` | 悬停底、只读单元格、标签栏底托 | `--bg-side`（#f8f0df / #26221e）、悬停 `--bg-hover` |
| `--line` | 细线、分隔 | `--line`（#e7ddca / #5b4d40）——**只用于分隔，不用于控件边线**（对卡片底只有 1.33 : 1） |
| 控件边线 | 输入、药丸、方框、血条外框 | `--line-ctrl`（#ad7f58，浅 3.47 : 1 / 深 3.51 : 1） |
| `--ink` / `--ink-2` | 正文 / 次要 | `--text` / `--text2` |
| `--primary`（旧酒红） | 选中、主按钮、熟练、法术位实心 | `--primary`（番茄红 #b43118 / #d13415）；**图形标记**（血条、圆点、下划线）用别名 `--mark`（深色取 `--primary-text` #f67c60，因为深色下 #d13415 对卡片底只有 2.49 : 1） |
| `--gold` | 临时生命、灵感「有」、专精菱形、新加入药丸 1.2 秒底、头像内框线 | `--accent`（#e9c162，**极小面积**）；要读字时用 `--accent-text` |
| `--hp` / `--hp-track` | 血条 | 填充 `--mark`；底槽 `--bg-sunk` + 1px `--line-ctrl` 外框；低于 1/4 填充改 `--danger-text` |
| `--danger` | 错误、血条危急 | `--danger-text` / `--danger-line`（错误仍用"2px 红边框 + ⚠ + 文字"） |
| `--unsaved` | 未保存圆点 | `--accent`（外壳页头已用同款，`pages.css` 的 `data-dirty`） |
| `--ok` 绿 | —— | **不用**（11-04 你去掉了；P4 的 `--success-*` 在人物页也不用） |

别名只有两个：`--mark`（图形标记色）、`--hp-low`（= `--danger-text`）。别名写在人物页自己的样式里，不改自动生成的 `palette.css`。

### 2.2 对比度（我算的，深浅两套；不是 WCAG 认证，没有真实审计）

| 配对 | 浅 | 深 | 要求 |
|---|---|---|---|
| 正文 `--text` / 卡片底 | 12.03 | 9.68 | ≥4.5 |
| 次要 `--text2` / 卡片底 | 5.71 | 6.52 | ≥4.5 |
| 血条填充 `--mark` / 底槽 | 5.85 | 5.99 | ≥3 |
| 血条危急 `--danger-text` / 底槽 | 4.93 | 4.73 | ≥3 |
| 血条外框、药丸边、方框边 `--line-ctrl` / 卡片底 | 3.47 | 3.51 | ≥3 |
| 临时生命段外框 `--accent-text` / 底槽 | 5.95 | 8.31 | ≥3（金色填充本身对底槽只有 1.44 : 1，所以**必须带外框**） |
| 死亡豁免 成功（`--mark` 实心）/ 卡片底 | 6.09 | 4.70 | ≥3 |

| 分页下划线 `--mark` / 页面底 | 5.85 | 5.38 | ≥3 |
| **焦点环 `--focus` / 卡片底** | 6.09 | **2.49** | ≥3 |

**发现（不在 P6 范围）**：P4 的对比度报告 30 对里没有"焦点环"这一对，深色下 `--focus`（#d13415）对卡片底只有 2.49 : 1，低于 3 : 1。建议深色把 `--focus` 改成 `--primary-text`。改的是 P4 的令牌，**这里只报告，不动**，请你定要不要修。

不只靠颜色（逐项）：血条 = 长度 + 数字；危急 = 数字 + 红色（长度已经说明）；死亡豁免 = 实心 / 空心形状 + "成功 / 失败"文字；选中的卡片 = 左侧 3px 竖条 + 底色；未保存 = 圆点 + 文字；状态药丸全部同一款，类别靠分行与小字。

### 2.3 字体与字号（沿用 P4 阶梯 12 / 13 / 14 / 16 / 18 / 22 / 28；行高 1.6）

| 角色 | 字号 / 字重 / 字体 | 旧值（U5R / U6） |
|---|---|---|
| 详情页名字 | 28 / 700 衬线（窄屏 22） | 26 |
| 列表卡名字 | 18 / 700 衬线 | 18 |
| 英文名 | 13 / 400 `--text2` 无衬线 | 13 / 14 |
| 卡标题（战斗、属性、法术位……） | 18 / 700 衬线 | 17 |
| 卡内分组标题（生命） | 16 / 700 衬线 | 15 |
| 大数字（生命、AC、检定值） | 22 / 700 衬线，`tabular-nums` | 24 |
| 正文 / 药丸 / 按钮 | 14 / 13 | 14 / 13 |
| 说明小字 | 12，同一屏不超过 2 处 | 12 |

- 无衬线用 P4 系统字体栈（PingFang SC / Noto Sans SC / 微软雅黑），衬线用 P4 的 `--font-serif`。**不打包字体。**
- 名字和大数字用衬线是"名册"这套语言对 P4 规则（"外壳无衬线，术语用衬线 + 虚下划线"）的**有意延伸**：名字不带虚下划线（它不是"点了开资料卡"的术语；是术语的地方才带）。
- 最小 12px，不用 9–11px（U5R 视觉 §3）。
- 12px 和 13px 紧挨时靠字重区分，不靠颜色。

### 2.4 间距、圆角、阴影

- 4pt 网格（P4）：卡内边距 16；卡与卡之间 12（U5R 原写 14，不在 4pt 网格上，**改 12**）；卡内分区 12；药丸之间 8。同一种关系同一个间距，不再有"桌面端大空白"。
- 圆角：卡片 12；输入、字段框 6（沿用现有 `.trpg-input`）；药丸 999；头像框 8；血条 4。
- 阴影沿用三档：卡片 `--shadow-1`、浮层 / 提示条 `--shadow-2`、窗口 / 弹窗 `--shadow-3`。卡片悬停 = `--shadow-2`。

### 2.7 动效（只动 `transform` 和 `opacity`，开发规范 §5.5；减少动效时全部关闭）

## 7 无障碍（实施时逐项验证；现在只是规则）

- 键盘：所有操作可用键盘；焦点环可见（P4 双环）；弹窗 / 弹层打开焦点进入，关闭回到触发器；↑ ↓ 在列表里切人（并排时右边跟着换）；Enter 打开 / 提交；Esc 关浮层或还原输入；`/` 聚焦搜索；Ctrl / ⌘ + Z 撤销。
- 触摸：点击区 ≥44×44（窄屏 或 触屏），相邻 ≥8px；圆点点击区外扩。
- 语义：血条 `role="meter"`；圆点 `role="checkbox"`；分页 `role="tablist"`；撤销按钮有完整可读名；图标按钮都有 `aria-label`。

- 文字放大到 200% 不破版：靠容器查询折叠 + 文字允许换行（中文名截断时悬停显示全名）。
- 减少动效：所有动画关闭，改成直接切换。

## 8 文案规则（第 4 阶段落实）

- 动词具体：「保存修改」「加入」「撤销到此」「套用」「回自动」；不用"确定""提交"。
- 同一个动作全流程同一个名字：弹窗里叫「套用」，提示条也叫"已套用"。
- 空 / 错 / 无结果：说发生了什么 + 下一步一个按钮；错误就近，不弹窗，不道歉。
- 数据未知**留空**，不写"未填写""无"（开发规范 §5.4）。
