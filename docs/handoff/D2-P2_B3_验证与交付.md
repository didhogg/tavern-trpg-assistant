## 2. 一本书长什么样（真实数据：XPHB《玩家手册（2024）》中文版）

按类别查询 `query('cn-official', 类别, { source: 'XPHB' })` 的条数（数解析结果，不写死）：

```
 法术 391 · 子职业特性 309 · 职业特性 283 · 物品 223 · 变体规则 117 · 专长 80 · 可选特性 58 · 表 54
 怪物 53 · 子职业 48 · 种族特性 38 · 种族 34 · 语言 19 · 动作 18 · 技能 18 · 背景 16 · 状态 15
 职业 12 · 物品属性 9 · 武器精通 8 · 危害 5 · 感官 4 · 状况 3
 背景描述类：法术 51 · 物品 54 · 子职业 48 · 背景 16 · 怪物 15 · 职业 12 · 种族 10 · 专长 8
 全书正文：corpus('cn-official', 'book', 'XPHB') → 序章、第一至第七章、附录 A/B、术语汇编、制作组
```

一条的详情 `detail('cn-official', 'spell', 编号, 'XPHB')`（火球术，节选；对象是作者对象原样）：

```
 item:    { name: '火球术', ENG_name: 'Fireball', source: 'XPHB', page: 274, level: 3, school: 'V',
            time: [{ number: 1, unit: 'action' }], range: { type: 'point', distance: { type: 'feet', amount: 150 } },
            components: { v: true, s: true, m: '一颗蝙蝠粪和硫磺搓成的小球' }, duration: [{ type: 'instant' }],
            entries: ['明亮的闪光……{@variantrule 球状 [效应区域]|XPHB|球状}……{@damage 8d6}点火焰伤害……'],
            entriesHigherLevel, damageInflict, savingThrow, classes(加载器加的：哪些职业可用), … }
 fluff:   { images: [{ href: { path: 'spells/XPHB/Fireball.webp' }, … }] }     ← 作者的背景描述
 english: { status: 'found', via: 'name', item: { name: 'Fireball', … } }      ← 英文原文对象
```

正文里的 `{@damage 8d6}`、`{@variantrule …}` 是作者的标记写法，显示交给作者排版器（P4）。

搜索 `search('cn-official', '火球')`：作者搜索器原样排序，前 8 条里有 XDMG 的火球项链、火球魔杖，XPHB 的延迟爆裂火球、火球术等；每条带作者编号、类别、来源、中英文名。

## 3. 给前端的数据说明（库服务 `src/library/service.ts`）

| 接口 | 交回什么 |
|---|---|
| `categories(源)` | `{ 类别: 条数 }` |
| `query(源, 类别, { source?, includeExcluded? })` | `[{ hash 作者编号, source 来源, excluded 是否被关, item 作者对象 }]` |
| `detail(源, 类别, 编号, 来源?)` | `{ item, fluff, fluffError, hash, source, excluded, engSiteHash, english }`；english.status：found / not-installed / not-paired / not-found |
| `corpus(源, 'book'\|'adventure', 编号)` | 一本书或冒险的全文（作者对象） |
| `search(源, 关键词)` / `searchSettings(源, {改哪项})` | 作者搜索结果 `[{ score, prop, doc }]` / 作者的搜索设置 |
| `setBookExcluded(源, 书, 关?)` | 按书开关（作者屏蔽表） |
| `brewCatalog` / `brewInstalled` / `brewAddUrl` / `brewImport` / `brewDelete` / `brewPull` | 自制：书目、已装、装、导入、删、更新（作者包管理器原样） |
| `englishCoverage(源)` | 中英配对覆盖率、没配上的按原因分、名字不一致清单 |
| `health()` | 体检：每项 `{ source, check, layer?, level ok/info/warn/error, title 大白话, count, details, stale? }` |
| 安装：`installOfficial({ source, db, files, openFrame, onProgress })`（`src/library/install.ts`） | 安装报告（第 1、2、5 层） |

界面不碰字段名、不另起格式：显示什么由界面按真实对象的形状决定（P4）。

## 4. 真机验证（驾驶员来点）

入口：酒馆 → 打开助手 → 设置 → 诊断 →【库】真机验证（B3）。按钮依次点：

```
 ① 装中文官方      联网，几分钟；显示"安装成功：xxx 个文件，解析 xx 类"
 ② 体检           显示 ok/info/warn/error 各几项；error 应为 0
 ③ 查一本书       显示"XPHB 法术 391 条；火球术详情取到；搜索"火球" n 条"
 ④ 关掉网络（飞行模式），完全退出酒馆再打开，再点 ③   结果应与联网时一样
 ⑤ 存储空间       显示已用 / 上限；iPhone 上请记下这两个数
```

要在三处各点一遍：电脑上的 SillyTavern、TauriTavern、iPhone。每处把诊断页"复制报告"的内容发给开发者。
英文原文要再装英文官方，这个入口不装；③ 里英文显示 not-installed 是正常的。

## 5. 已知问题与没做的

**设计 §9 里还没做的接口**（后端缺口，要在 P4 界面之前补）：
- `书目()`：官方各书（含开关状态）、各自制包的总表。现在只有分散的 `brewCatalog`、`brewInstalled`、按书开关，没有合起来的"书目"。
- `下载冒险(冒险)`：按本下载冒险正文。现在官方安装时冒险正文不下载（作者离线规则），也没有按本下载的接口。
- `取条目(作者编号[])`：给结算内核、人物用的按编号批量取。
- `取消下载`；`下载官方` 只是独立函数，还没放进库服务。

**B3 中修掉的 bug**：只装中文官方时点体检会报错（体检去开英文作者程序问英文自制，而英文作者程序启动要读英文官方数据）。改为：对应官方数据没装就跳过那套自制的检查，体检里注明。

**审计**：中文可疑 4 对：治疗药水（DMG）中文数据同名同来源有 item 和 itemGroup 两条，作者只留 itemGroup（上游数据问题，只记录）；3 件通用变体并进物品后英文名变了（出处未查到）。
**体检 warn**：中文英文名不一致 11 条（位置配对得来，只列不改）；测试残留的"没有来源"自制包（测试夹具留下的，作者列表里删不到）。
**自制的书和冒险正文**未解析（B2-7 留下）。
