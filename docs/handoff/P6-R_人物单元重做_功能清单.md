# P6-R 人物单元重做 · 功能清单与底层（2026-11-23，驾驶员授权：照 DiceCloud 重做整个人物单元，自己查、自己做、自己验）

## 为什么重做
驾驶员实测：只能从模板建人、建不了空白人物；改个数值编辑窗口把东西删光；点撤销整张卡读不出来消失。
根因在底层：存档只存“用了哪些库条目 + 和重建结果的差别”，读档 / 改 / 撤销都要从引用重建再对齐缓存，任何一层对不上就丢东西或建回来。

## DiceCloud 的做法（照搬的原则）
1. **人物本身就是唯一的真数据**：一个人 = 一份完整文档；改 = 改这份文档的字段；撤销 = 换回改之前的那份。不从引用重建。
2. **每个数都能点开**：看它从哪来（明细）、改它的底值；派生值由引擎算（我们的引擎 = dnd5e 官方，在结算小窗里）。
3. **空白人物**：新建就是一份默认人物，之后在“构建”里加种族 / 职业 / 背景 / 属性。
4. 休息按钮、增益与状态、生命条加减、生命骰 / 资源 / 法术位都能直接加减。

## 新底层
- 存档里每个人存 **完整人物数据**（dnd5e `actor.toObject()`，`KernelActor.doc`）；`refs` 只作“用了哪些库条目”的说明（从物品的作者标记现取），不再用来重建。
- 每次写入：小窗里执行 → 取这个人的完整数据 → 存档里整份替换；撤销记录存改之前那份 → 撤销整份换回，小窗按它重建。
- 旧存档（只有引用）：读档照旧路建出来，第一次写入时自动存成完整数据（迁移）。
- 编辑窗口按 dnd5e 官方字段定义生成（字段名、类型、选项都取官方），不手写表单。
