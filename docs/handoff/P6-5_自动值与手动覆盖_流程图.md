# P6-5 自动值与手动覆盖 —— 用户交互流程图（先画流程，再改线框）

驾驶员 2026-11-15：角色表上**所有自动计算值都按普通文字显示**；要改时去「小铅笔页面」手动覆盖，**随时能复原成自动值**。包括且不限于等级、最大生命、豁免、初始属性值、属性加成。严格按流程图做。

本文件只画用户怎么操作、界面怎么反应，**不碰后端**（后端是否支持见 §5，未查）。线框在 `docs/design/p6-wireframe/`（p6-13 系列）。

## 0 两种值，两种改法（P6-0 §10.2 已区分）

| | 自动值（算出来的） | 状态值（游戏里变化的） |
|---|---|---|
| 例子 | 等级、最大生命、AC、先攻、速度、熟练加值、六属性的最终值与调整值、豁免加值、技能加值、被动值、法术豁免 DC / 攻击加值、负重上限 | 当前生命、临时生命、法术位已用、生命骰已用、死亡豁免、力竭、灵感、经验、物品数量 |
| 平时怎么显示 | **普通文字**（不画框、不像输入框） | 当前生命 / 临时生命：点数字原地改；圆点：点一下；步进器：− n ＋ |
| 怎么改 | 点块角上的**小铅笔 ✎** → 小铅笔页面（手改页）→ 手动覆盖 | 就地改，立即生效 |
| 能复原吗 | **能**：每一项都有 [回到自动]，也可 [全部回到自动] | 没有"复原"，只有撤销（改动记录） |
| 改了之后 | 数字下面一条金色细线 = 「已手改」 | 一条改动记录，可撤销 |

## 1 小铅笔页面（手改页）长什么样

一个弹窗（窄屏 = 底部抽屉），顶部分页：**等级 · 生命 · 属性 · 战斗 · 技能**；每页一张表，一行一项：

```
项目     现在显示     自动值（点 ▾ 看来源明细）     手改为       操作
最大生命   18  ▁▁      16 = 6 + 4 + 4 + 2           [  18  ]    [回到自动]
```
- 没手改过：「现在显示」= 自动值，手改框是空的（灰字写「不改」）。
- 手改过：「现在显示」带金色细线，手改框里有值，[回到自动] 可点。
- 底部：[全部回到自动]（本页）· [取消] · [应用]。[应用] 写入当前战役数据，算**一条**改动记录（可撤销）；不需要再点"保存修改"。

## 2 各块的小铅笔在哪、打开哪一页

| 角色表上的位置 | 小铅笔打开 | 这一页里的自动值 |
|---|---|---|
| 页头身份行（法师 3 级 · 种族 · 背景） | 等级页 | 等级（= 各职业等级之和）、升级所需经验；〔[等级管理] 仍是单独的升降级动作，先预览〕 |
| 生命块右上角 | 生命页 | 最大生命（含来源：生命骰 / 体质 / 加成）、生命骰数量与面数 |
| 六属性那一排右上角 | 属性页 | 每个属性：**初始（基础）值**、各种加成（种族 / 专长 / 物品…）、最终值、调整值、豁免加值、豁免熟练 |
| AC / 先攻 / 速度 / 熟练 那一排右上角 | 战斗页 | AC（含来源）、先攻、速度、熟练加值、被动察觉 / 洞悉 / 调查、法术豁免 DC、法术攻击加值 |
| 「数值」页技能表标题 | 技能页 | 每个技能：熟练级别、加值、被动值 |

## 3 流程图

### 流程 A：覆盖一个自动值（最常见：把最大生命改成 18）

```
 角色表（所有算出来的数 = 普通文字）
        │ 看到「/ 16」想改
        ▼
 点生命块右上角 ✎
        │
        ▼
 小铅笔页面 · 生命页  ←──(窄屏：底部抽屉)
   最大生命  显示 16   自动 16 [▾ 来源明细]   手改为 [ 不改 ]
        │ 在「手改为」里输入 18
        ▼
 这一行立刻预览：显示 16 → 18（金线），[回到自动] 亮起
        │
   ┌────┴─────────────┐
   │ [应用]            │ [取消] / Esc
   ▼                  ▼
 关闭页面；角色表上「/ 18」带金线；        关闭；什么都没变
 页头撤销按钮 = 「撤销：盖尔 最大生命 16→18」
 （一条改动记录）
```

### 流程 B：复原成自动值（三条路，都能走）

```
 路 1  角色表上看到带金线的数 ──点一下──▶ 小气泡：「已手改 18（自动 16）」
                                           [回到自动]  [去修改 ✎]
                                              │点 [回到自动]
                                              ▼
                              金线消失、数字变回 16；一条改动记录（可撤销）

 路 2  点 ✎ → 小铅笔页面 → 在那一行点 [回到自动] → 手改框清空 → [应用]

 路 3  点 ✎ → 小铅笔页面 → [全部回到自动]（只作用本页）→ [应用]

 任何一路都不需要记得"原来是多少"：自动值一直显示在那一行。
```

### 流程 C：当前生命 / 临时生命（状态值，不走小铅笔）

```
 角色表生命块： 12 / 18   +3 临时   ▓▓▓▓▓▓▓░░
        │ 点「12」
        ▼
 「12」原地变成输入框（金色描边）；下面一行预览
        │ 输入 −7（也认 +5、=12、全角、各种减号）
        ▼
 预览「生命 12 → 5 / 18」
   ┌────┴────┐
 Enter     Esc
   ▼         ▼
 生效（临时生命先扣，由内核算）   还原
 一条改动记录；生命条动画 150 ms
 点「+3 临时」同样原地改；点「/ 18」→ 不在这里改，打开小铅笔页面（因为它是自动值）
```

### 流程 D：覆盖之后，自动值变了怎么办（升级 / 换装备 / 加专长）

```
 已手改的值 ──(来源变了：例如升级后自动最大生命 16→20)──▶
        │
        ▼
 手改值保持不变（金线还在）；气泡多一行：「自动值现在是 20」[采用自动值]
        │ 不点 = 一直保持手改；点 = 回到自动（一条改动记录）
 小铅笔页面里这一行：自动值 20 旁边有淡色提示「已变化」
 （这条规则是否能做取决于后端怎么存覆盖，见 §5 缺口）
```

### 流程 E：从建卡带来的「初始属性值」和「属性加成」

```
 建卡「属性值」步：只填 初始（基础）值（标准数组 / 购点 / 掷骰 / 手填）
        │ 种族 / 背景给的加成由内核自动加上，建卡页只显示
        ▼
 角色表六属性 = 最终值与调整值（普通文字）
        │ 想改初始值或加成？
        ▼
 点属性排 ✎ → 小铅笔页面 · 属性页
   力量   初始 [ 8 ] [回到自动]   加成 +0   最终 8（自动）→ [手改为]   调整值 −1（自动）
 初始值是「设定」，改它也走同一个 [应用]；最终值、调整值、豁免是自动值，同样可覆盖、可复原
```

### 流程 F：点数字掷骰（可掷的自动值）

```
 角色表上的加值 / 豁免 / 技能（普通文字，悬停浮出淡底）
        │ 点一下
        ▼
 送去骰盘（P7 接线）——不会进入手改，也不会弹框
 要改这个数：去 ✎，不是点数字
```

### 流程 G：换头像（可填链接，也可直接上传）

```
 角色表页头头像方框（右下角小图标）／建卡「名字」步里的 [填图片链接] [上传图片]
        │ 点
        ▼
 「人物头像」窗口（窄屏 = 底部抽屉）   [图片链接 | 上传图片]
   ├─ 图片链接：贴网址 ──▶ 右边方框立刻预览（居中裁切成方的）
   │        └─ 加载不出来：输入框下一行写原因，输入保留，仍可改
   └─ 上传图片：拖进虚线框，或 [选择文件…] ──▶ 立刻预览 + 文件名 / 大小
            └─ 不是图片 / 太大：虚线框下一行写原因，不丢已选内容
        │
   ┌────┼──────────────┐
 [使用这张]   [取消] / Esc   [移除头像]
   ▼             ▼              ▼
 关闭，头像换新（一条改动记录）   关闭，没变    回到默认人像（一条改动记录）
```
头像一律显示成方框（列表、角色表、资料卡都一样）。

## 5 要查后端的（只登记，不查不改）

- **G14（已有）扩充**：覆盖入口。引擎只有 AC（`ac.override`）和最大生命（`hp.max` 可空）有现成覆盖字段，其余是"来源值 + 加成"（P6-0 §10.2）；等级、豁免、技能、先攻、速度、属性值、被动、DC 等"能不能覆盖、存在人物段哪里、复原就是删掉那一项吗"都要查。
