# P6-5 自动值与手动覆盖 —— 用户交互流程图（先画流程，再改线框）

驾驶员 2026-11-15：角色表上**所有自动计算值都按普通文字显示**；要改时去「小铅笔页面」手动覆盖，**随时能复原成自动值**。包括且不限于等级、最大生命、豁免、初始属性值、属性加成。严格按流程图做。

本文件只画用户怎么操作、界面怎么反应，**不碰后端**（后端是否支持见 §5，未查）。线框在 `docs/design/p6-wireframe/`（p6-13 系列）。

## 0 两种值，两种改法（P6-0 §10.2 已区分）

| | 自动值（算出来的） | 状态值（游戏里变化的） |
|---|---|---|
| 例子 | 等级、最大生命、AC、先攻、速度、熟练加值、六属性的最终值与调整值、豁免加值、技能加值、被动值、法术豁免 DC / 攻击加值、负重上限 | 当前生命、临时生命、法术位已用、生命骰已用、死亡豁免、力竭、灵感、经验、物品数量 |
| 平时怎么显示 | **普通文字**（不画框、不像输入框） | 当前生命 / 临时生命：点数字原地改；圆点：点一下；步进器：− n ＋ |
| 怎么改 | 点块角上的**小铅笔 ✎** → 小铅笔页面（手改页）→ 手动覆盖 | 就地改，立即生效 |
| 能复原吗 | **能**：每一项都有 [回到自动]，也可 [全部回到自动] | 没有"复原"，只有撤销（改动记录） |
| 改了之后 | 数字下面一条金色细线 = 「已手改」 | 一条改动记录，可撤销 |

## 1 手改小抽屉：一个自动小模块一个（2026-11-15 驾驶员修正，取代"一个大手改页五个分页"）

外面所有自动值都是**只读的普通文字**；每个模块角上一个小铅笔 ✎，点它打开**这个模块自己的小抽屉**（居中小窗，宽 480，高度跟内容走；窄屏底部铺满；内容多了在窗口里滚）。抽屉里：

```
项目名                       [自动 | 手动]   填写框（选「手动」才可填）
自动 18 · 来源 ▾                [●自动] [手动]      —
```
- 每一项下面小字写**自动值与来源**；选「自动」就是回到自动值（并告诉你会变回什么数），不靠"清空"；
- 手改过的项名字带金线；底部 [全部用自动] · [取消] · [应用]；[应用] 立刻生效，一条改动记录，可撤销，角色表上的数字马上跟着变；
- **不用悬浮窗 / 小气泡**：已手改的数只有一条金色细线，想看 / 想改回，点 ✎ 进抽屉。

## 2 哪个模块哪个抽屉（不是所有东西都做抽屉）

| 模块（外面只读） | 小铅笔位置 | 抽屉里 |
|---|---|---|
| 等级 | 身份行等级旁 | 等级、升级所需经验 |
| 生命 | 生命块右上角 | 最大生命、生命骰数量、生命骰面数（当前 / 临时生命不在这里） |
| 属性 | 六属性那排右上角 | 每个属性的最终值；展开 = 初始值、加成、最终值、调整值、豁免 |
| 战斗数值 | AC / 先攻 / 速度 / 熟练那排右上角 | AC、先攻、速度、熟练、被动 ×3、法术豁免 DC、法术攻击、负重上限 |
| **技能** | 技能表标题 | 每个技能的熟练级别 [无 / 半 / 熟 / 专] + 来源；改过的行带金线，↺ 回到自动 |
| **特质** | 特质块标题 | 语言 / 感官 / 抗性 / 免疫 / 熟练 / 护甲熟练：药丸 + 来源，可删、可加；删掉的自动项收进「已删除」可恢复 |
| 背包 / 法术 / 特性 / 行动（大清单） | — | **不做抽屉**：就在各自的表里改（行 ⋯ 菜单、[＋ 加]），这几块下一步单独画 |
| 头像 / 名字 / 背景文字 | — | 沿用小窗口（头像见流程 G） |

建卡每步选的东西（种族给的语言、背景给的技能……）自动出现在对应模块里，来源写「种族」「背景」……；之后想删、加、改，都是进该模块的抽屉。

## 3 流程图

### 流程 A：覆盖一个自动值（把最大生命改成 20）

```
 角色表（所有算出来的数 = 普通文字）
        │ 想改「/ 18」
        ▼
 点生命块 ✎ ──▶ 生命抽屉（居中小窗 / 窄屏底部）
        │  最大生命  自动 18 · 来源▾   [自动|●手动]  [ 20 ]
        ▼
 [应用] ── 或 [取消] / Esc（什么都没变）
        ▼
 抽屉关闭；角色表上「/ 20」带金线；撤销按钮 =「撤销：盖尔 最大生命 18→20」
```

### 流程 B：复原成自动值

```
 路 1  点该模块 ✎ → 抽屉里那一项选「自动」→ [应用]
 路 2  点该模块 ✎ → [全部用自动]（只作用本抽屉）→ [应用]
 路 3（技能 / 特质）抽屉里那一行的 ↺ ／ 已删除药丸上的 ↺
 任何一路都不用记"原来是多少"：自动值一直写在那一项下面。
```

### 流程 D：覆盖之后，自动值变了怎么办（升级 / 换装备 / 加专长）

```
 手改值保持不变（金线还在）；
 抽屉里这一项的自动值会更新，旁边多一个淡色提示「自动值已变」；用户自己决定要不要选「自动」。
 （是否做得到取决于后端同时给出自动值和手改值，候选 G32；做不到就不提示）
```

### 流程 E：初始属性值和属性加成

```
 建卡「属性值」步只填初始值 → 种族 / 背景加成由内核加上
 角色表上的最终值、调整值、豁免 = 普通文字
 点属性 ✎ → 属性抽屉 → 点「展开」看 初始值 · 加成 · 最终值 · 调整值 · 豁免，每项 [自动|手动]
```

### 流程 H：技能与特质（外面只读，进抽屉才改）

```
 技能：数值页技能表（熟练点 + 加值，普通文字）
   └ 点表头 ✎ → 技能抽屉：一行一个技能，熟练级别 [无|半|熟|专]，来源写在名字下面
        ├ 改一行 → 该行带金线、出现 ↺ → [应用]
        └ ↺ 回到自动
 特质：语言 / 抗性 / 熟练等（普通文字药丸）
   └ 点块头 ✎ → 特质抽屉：药丸 + 来源
        ├ × 删除（自动来的 → 收进「已删除」，可 ↺ 恢复；手动添加的 → 直接没了，可撤销）
        └ [＋ 加…] 手动添加（来源写「手动添加」，药丸金边）
```

### 流程 C：当前生命 / 临时生命（状态值，不走小铅笔）

```
 角色表生命块： 12 / 18   +3 临时   ▓▓▓▓▓▓▓░░
        │ 点「12」
        ▼
 「12」原地变成输入框（金色描边）；下面一行预览
        │ 输入 −7（也认 +5、=12、全角、各种减号）
        ▼
 预览「生命 12 → 5 / 18」
   ┌────┴────┐
 Enter     Esc
   ▼         ▼
 生效（临时生命先扣，由内核算）   还原
 一条改动记录；生命条动画 150 ms
 点「+3 临时」同样原地改；点「/ 18」→ 不在这里改，点生命块 ✎ 打开生命抽屉（因为它是自动值）
```

### 流程 F：点数字掷骰（可掷的自动值）

```
 角色表上的加值 / 豁免 / 技能（普通文字，悬停浮出淡底）
        │ 点一下
        ▼
 送去骰盘（P7 接线）——不会进入手改，也不会弹框
 要改这个数：去 ✎，不是点数字
```

### 流程 G：换头像（可填链接，也可直接上传）

```
 角色表页头头像方框（右下角小图标）／建卡「名字」步里的 [填图片链接] [上传图片]
        │ 点
        ▼
 「人物头像」窗口（窄屏 = 底部抽屉）   [图片链接 | 上传图片]
   ├─ 图片链接：贴网址 ──▶ 右边方框立刻预览（居中裁切成方的）
   │        └─ 加载不出来：输入框下一行写原因，输入保留，仍可改
   └─ 上传图片：拖进虚线框，或 [选择文件…] ──▶ 立刻预览 + 文件名 / 大小
            └─ 不是图片 / 太大：虚线框下一行写原因，不丢已选内容
        │
   ┌────┼──────────────┐
 [使用这张]   [取消] / Esc   [移除头像]
   ▼             ▼              ▼
 关闭，头像换新（一条改动记录）   关闭，没变    回到默认人像（一条改动记录）
```
头像一律显示成方框（列表、角色表、资料卡都一样）。

## 5 要查后端的（只登记，不查不改）

- **G14（已有）扩充**：覆盖入口。引擎只有 AC（`ac.override`）和最大生命（`hp.max` 可空）有现成覆盖字段，其余是"来源值 + 加成"（P6-0 §10.2）；等级、豁免、技能、先攻、速度、属性值、被动、DC 等"能不能覆盖、存在人物段哪里、复原就是删掉那一项吗"都要查。
- **候选 G32**：流程 D（自动值变了、手改保留、提示自动值已变化）需要后端同时给出"当前自动值"和"手改值"；没有就退而求其次：覆盖后不提示变化。
- **候选 G33**：初始属性值（建卡基础值）读回、能否改（和建卡计划里没有基础属性值同一件事，P6 线框 p6-5g 已标）。
- **候选 G34**：头像上传——上传的图存在哪（存档里？还是别处）、有没有大小 / 格式限制、存档会不会因此变大；以前定过"图片只存链接"（数据库条目），这里是玩家自己的人物头像，是否例外要你定。
- 这些没查之前，线框只表达交互，**不承诺**每一项都真的能覆盖。
