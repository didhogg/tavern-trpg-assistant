## 0. 一句话

只做**人物管理页面和它的子页面**：人物数据层 + 人物列表（分类、置顶、搜索、标签筛选、排序、多选、行尾菜单）+ 模板弹窗（只管怪物与具名 NPC）+ 存入我的库弹层 + 回收站、标签管理、分类管理三个弹窗 + 一个**临时人物卡页**（名字 + 保存，UNIT2 整页替换）。

**不做**（归 UNIT2 及以后）：正式人物卡、套用模板、库里用人物卡打开、人物卡「...」菜单、五个分页、给 AI。

## 5. 停止条件（只有这四种才停整站）

1. 批 0：两次 `build:data` 哈希不同，或数据比对出现允许以外的变化，或 `g2-oldext` 失败；
2. 迁移会改变旧存档里已有的数据（不只是补三个键）；
3. 已有 e2e（`library`、`upgrade`、存档）因本任务失败且两次修不好；
4. 合并规划者分支时 `NEXT.md` 以外的文件冲突。

**其余问题当场解决，不停、不另开任务**：规格没写清的小细节按规格 §11「总原则」自己定，写进报告「与规格不同之处」；单文件超 400 行就拆。
