## 5. 批 3：随机表与参考表

规格以大纲 §G3「随机表／参考表界面」为准，本节只补**做法**与**取舍**。

### 5.1 掷表是纯函数

新建 `src/rules/dice/table.ts`：

```ts
rollTable(table: TableData, rng: () => number, modifier = 0): TableRoll
// TableRoll = { formula: string; total: number; rowIndex: number | null; text: string; then?: { table: string; times: number } }
tableCopyText(results: Array<{ label: string; roll: TableRoll }>, opts): string   // 复制格式全在这里
```

- 骰式用 `src/rules/dice/parse.ts` 现有解析；随机源可注入，测试用固定序列。
- 命中行：`min ≤ total ≤ max`；没命中（数据缺口）`rowIndex: null`，界面显示「没有对应的行」，不报错。
- 复制格式（单表、本节全掷多行「标签：结果」、多列用「／」、连环「A → B：结果」、单元格里的 `{{roll:2d8}}` 复制成 `2d8 = 9`）全在 `tableCopyText`，单测逐条覆盖。

### 5.2 界面

| 位置 | 做什么 |
|---|---|
| 条目页「相关表格」面板 | 列出 `parent.id` 或 `parent.appliesTo` 指向当前条目的表；有 `at` 的按 `at.heading` 分组、`at.order` 排序；**没有 `at` 的**（背景的特点／理念／牵挂／缺陷这类，SRD 包里 89 张表只有 41 张有 `at`）归一组「本条目的表」，按 id 的书中顺序（`x`、`x-2`、`x-3`…）排；每张表一行：表名、骰式、来源书与页、🎲；有 `appliesTo` 的写「也适用于：…」。查法照 `joinersOf` 带缓存；**没有表就整块不出**，不留空位 |
| 表页（`type: 'table'` 的详情） | 顶部一行「属于：〈主人〉（也适用：…）　位置：书名 p.页「小标题」」，主人可点；表头骰子按钮 = 整表掷一次 |
| 点了就掷 | 命中行高亮并滚入视野；自动复制（`src/host/clipboard.ts` 的 `copyText`）；提示条「🎲 表名 d8 = 3　已复制，Ctrl+V 粘贴」带按钮 **[填入输入框]**（`src/host/input.ts` 的 `appendToInput`，追加不发送）；复制失败时提示条改「复制失败」，按钮与历史照样在 |
| 本节全掷 | 同一组（同一 `at.heading`，或「本条目的表」）里 ≥ 2 张可掷表时，组标题右侧出「本节全掷」 |
| 连环表 | 命中行有 `then`：提示条多一个 [继续掷]，点了掷下一张，复制文字连成「A → B：结果」 |
| 参考表（`kind: 'ref'`） | 不掷。在**主人条目页**里只显示 `row.refs` 含当前条目的那几行 + 「看完整表」；单元格里的 `{{roll:…}}` 可点，掷一次并复制 |

- `src/stores/toast.ts`：现在只支持「撤销」一个按钮。加通用动作 `push(kind, message, { actions?: Array<{ label: string; run: () => void | Promise<void> }> })`，旧的 `undo` 用法不变。

## 6. 批 4：头像与生物类型图标

### 6.1 组件

新建 `src/ui/kit/EntityAvatar.vue`（人物模块以后直接复用，所以放 kit、不放 library）：

```ts
props: { art?: MonsterArt; creatureType?: string; size: number; label: string }
```

- **有 `art.portrait`**：方形容器 `size×size`、`overflow: hidden`。图片加载后按焦点算：裁切边长 `c = focus.size × min(宽, 高)`，缩放 `k = size / c`，图片宽 `宽×k`，左移 `(focus.x×宽 − c/2)×k`，上移 `(focus.y×高 − c/2)×k`。算法写成纯函数 `cropStyle(focus, 宽, 高, size)` 放 `src/ui/kit/crop.ts`，单测覆盖居中、贴左上、贴右下（结果不得露出容器外的空白）。
- **只有 token、或都没有、或图片加载失败**：显示生物类型图标（§6.2）。**不显示名字首字**（驾驶员 2026-11-02 定）。token 本身不当头像用。
- `<img loading="lazy" decoding="async" referrerpolicy="no-referrer" :alt="label">`；加载前先显示图标，加载成功再淡入（尊重「减少动态效果」）。
