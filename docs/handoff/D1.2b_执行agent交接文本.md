## 0. 你是谁、这次做什么

- **你是谁**：D1.2b 的执行 agent。项目是 SillyTavern 扩展「TRPG 跑团助手」（Vue 3 + TypeScript），里面有 D&D 5e（2014）资料库：11 个 `.trpgpack`，版本 1.4.1。
- **这次只做三件事**：
  1. 把核心十本书以外、2014 规则范围内的**怪物**（5etools `bestiary`）程序化导入，去掉重复的；
  2. 从冒险**英文正文**里，按确定性规则提取「使用某某数据」的**具名 NPC**，生成 `npc` 模板；
  3. 给**全部怪物**（含核心 1,191 个）写上**立绘头像与 token 的地址**，以及**头像裁切焦点**。焦点的定法：有 token 时用 OpenCV 拿 token 去立绘里匹配；匹配不上再用画面重心裁切。
- **一个都不多做**：
  - 物品、法术、种族、专长、背景、随机表、正文章节、据点：都不导；
  - 冒险结构：不导；
  - 图片本身：不下载进仓库、不打进包；
  - 界面：只做执行文档 §5.3 列出的那几处。
- **一次做完**：执行文档 §9 的批 0 到批 6 按顺序做。**批与批之间不停、不等任何人**。每批结束本地提交一次，提交信息以「D1.2b 批 N：」开头。
- **交回什么**：
  - 报告 `docs/probes/D1.2b_报告.md`（格式见执行文档 §13）；
  - `NEXT.md` 更新；
  - 本地提交（扩展仓库的 `d12b` 分支、数据仓库的本地提交）；
  - 最后一条回复：先一句话结果，再列出提交号、测试数、需要驾驶员看的抽查页路径。

**为什么这么严**：以前出过的事故，几乎都是「看到数字对不上，就顺手改测试、改读取器、改期望值让它变绿」，或者「顺手多做了范围外的事」。你的任务不是让测试变绿，是让数据真的对，并且能证明只改了该改的。闸门拦住你时，停手报告比绕过去好得多。

## 3. 最容易出错的地方（逐条记住）

1. **5etools 的 token 不是头像。** 它是给 VTT 用的圆形棋子图，带红色或橙色圆框，内容可能伸出框外（比如龙头）。只存地址，不当头像用。头像焦点来自立绘。
2. **token 匹配只用圆框里面**：掩码半径 0.80，翻转也要试。匹配阈值按执行文档 §8.3 第 6 条用真实分布定，**不许拍一个数**。
3. **构建不联网。** 只有 `npm run art:focus` 联网，结果写进 `tools/data/art/focus.json`；`build:data` 只读这个文件。否则两次构建哈希会不同。
4. **图片地址按 5etools-cn 网站源码推**，函数注释写源码文件与行号；**不许手写域名**。第 0 批的 30 个地址探针必须 30/30 是图片，才做头像。
5. **去重只决定新条目要不要**，绝不修改、删除、合并核心包或已处理来源里的条目（`art`、`supersededBy` 除外）。批 1 结束时要证明：核心包重建后除了版本号以外 0 差异。
6. **「有差别」要分类**（A 相同、B 只差文字、C 变体、D 新、同名异物），并按执行文档 §6.6 抽检。B 类不改字；抽检发现是数据源抄错的，不改数据，写进报告「来源本身的问题」。
7. **NPC 只用确定性规则**（执行文档 §7.2 的两档句式），英文正文判定、中文正文取名字。**对不齐就用英文名并标 `missing: zh`，不许自己翻译。**
8. **来源归属看条目的 `source` 字段**，不看文件名。P0 盘点里的数字只是参考，以你实测为准。
9. **未翻译的来源不放宽体检**：该来源不出包，列清单。
10. **已有测试只因「现在也读到新包」而失败时**（它默认所有包都是核心 11 个）：可以照 `tests/data/g2-additive.test.ts` 里 `loadAllPacks().filter(…)` 那一行的示范，把它的读取范围限定为核心包，每处只改这一行，在报告「范围限定」一栏逐个列出；数值和断言内容一律不改。其他原因的失败：按第 4 节处理。
11. **新测试只断言规则**（能解析、在图内、非空、没有 A 类重复……），**不钉死总数**；总数只写进报告。
12. **版本**：所有包 1.5.0，扩展 0.3.0。含 `npc` 的包写 `minAppVersion: '0.3.0'`；核心 11 个包不写，旧扩展必须仍能装（`g2-oldext` 通过）。
13. **构建副产物**：`docs/probes/D1.1_人物数据_报告.md`、`D1_抽检.md`、`D1_构建报告.md`、`D1.2a_R13_对照报告.md`、`D1.2a_R14_清洁报告.md`、`dist`、`docs/reviews` 只有日期变化就还原。真有内容变化的，在报告里说明。

## 4. 停止条件

**停整站**（立即停手、写报告、回复驾驶员）只有这四种：

1. 两次构建哈希不同；
2. 要改执行文档 §5 冻结的字段形状，或 §5.3 以外的 `src/`，才能继续；
3. 会修改、删除核心包已有条目的非 `art`、非 `supersededBy` 字段（含批 1 的「0 差异」核对不过）；
4. `g2-oldext` 失败。

**其余只停当前这一项**：写理由与证据，接着做下一项，不留「以后再做」。详见执行文档 §11。

**清单外的发现**：只记 `NEXT.md`「待议」，不做。
