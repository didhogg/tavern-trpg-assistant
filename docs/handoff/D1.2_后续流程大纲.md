# D1.2 后续流程大纲（S1–S3 与 D1.2b）

驾驶员 2026-10-31 批准的顺序：**S1 显示快修 → S2 数据可用性体检 → S3 数据驱动化（去掉写死十本书） → D1.2b 导入**。每一步先写执行文档，再动手；本文件是总览，细节以各步执行文档为准。

## 0. 为什么在 D1.2b 之前插入 S1–S3

- **真机发现（R15 推送后）**：
  - 随机表页面的表格单元格把引用标记原样显示，如 `{{ref:spell.burning-hands.phb|燃烧之手}}`。
  - 未安装塔莎时，职业特性显示成编号（如 `feature.druid-wild-companion.tce`），点击只提示「扩展包还没有安装」。
  - 驾驶员不确定「任选」内容（武器、语言等）、法术位等数据表、容器结构，人物模块能不能真用。
- **数据库检讨**：
  - 应用里的数据库层（`src/core`，IndexedDB）按「包」设计：安装、卸载、导入、导出、复制成「我的」、按存档启用都不认书名。
  - 写死十本书的是两处：一是造官方包的构建管线 `tools/data`（书目清单、依赖层级表、测试里写死的总数）；二是界面里的一张书名表（`src/ui/library/typeLabels.ts`）。
  - 还缺：自制条目编辑（U11）、全库查询（L1B）、统一的跨包扩展规则；卸载时的引用完整性目前只提示、不拦。
- **原则**：先把十本书的数据做对、做成真能用，再扩到 40 本三档书与 80 个冒险，避免问题被复制。

## 2. 各步

### S1 显示快修（执行文档 `docs/handoff/D1.2-S1_显示快修_执行文档.md`）

- **目标**：详情页不再出现裸标记、裸编号；跨包引用目标没装时，显示名字并能引导安装。
- **范围**：
  - 随机表页的表格单元格（379 张表受影响）。
  - 正文的小标题、引文、引文出处、表格列名（共 58 处）。
  - 正文表格单元格里的引用改成可点。
  - 跨包可选授予（45 处）在数据里带上显示名与目标包。
  - 点击未安装的引用时，提示需要哪本书并可直接安装。
  - 全库扫描测试：把每个条目详情页要显示的文字都过一遍，防止再漏。
- **不做**：布局调整、新页面、S2 的数据正确性问题。
- **验收**：全库扫描 0 处裸标记、0 处裸编号；单元测试、数据测试、库套件快速 e2e 通过；驾驶员真机看随机表与职业页。

### S2 数据可用性体检（执行文档待写）

- **目标**：用「模拟人物模块来取数」的方式，证明人物模块要用的数据真能用；查出的问题当场修。
- **检查**：
  - **职业**：生命骰、豁免、熟练与技能「从中选 N 项」、起始装备二选一、施法进度与法术位表（1–20 级 × 1–9 环，对照玩家手册）、职业表各列、子职业等级、各级授予都能找到条目、属性值提升等级、兼职要求。
  - **子职业**：授予、选择池、扩展法术、三分之一施法者的法术位。
  - **种族、亚种族**：属性加值（固定 / 自选）、体型、速度、黑暗视觉、语言（固定 / 任选 / 从列表选）、熟练、种族特质、天生法术。
  - **背景**：技能、工具、语言、装备、背景特性、特征随机表。
  - **专长**：前置条件能被程序读懂、属性提升、授予。
  - **物品**：武器伤害与属性（能指向物品属性规则）、护甲等级、容器内容物（编号与数量）、附带法术、充能、家族成员。
  - **法术**：环级、学派、职业、成分、持续时间、伤害与豁免的行动。
  - **「任选」记号全部能展开成具体条目列表**：如 `skill:*`、任选语言、军用武器、工匠工具、乐器。
  - **使用次数 `uses`**：修正 R15 抽检发现的 13 条误判，审计「每长休 1 次」宽松规则的 231 条。
- **交付**：
  - 体检报告。
  - 每项一条自动测试。
  - 一份「人物模块数据约定」：人物模块可以依赖哪些字段、什么形状，供 U6.1 直接使用。
- **验收**：每项检查有测试；查出的问题已修或写明理由交驾驶员；数据测试与快速 e2e 通过。

## 3. 常驻规则（防遗忘）

- **推送**：每一次推送都要驾驶员当次明确授权；发布、打标签、刷新 CDN、安装、删除用户数据同样要单独授权。
- **验证方式**：
  - 改动后跑 `npm run check`、`npm run test:data`，以及相关的快速 e2e 子集（如 `E2E_ENGINE=chrome E2E_VIEW=desktop E2E_SCHEME=light E2E_SUITE=library node tests/e2e/smoke.mjs`）。
  - **不再每改一处就跑约 35 分钟的整套 e2e**；整套只在一个阶段收尾、且驾驶员同意时跑。
  - 报告里如实写明「整套未在最终版本上运行」。
- **生成物还原**：构建与 e2e 之后先还原 `docs/probes/D1.1_人物数据_报告.md`、`docs/probes/D1_抽检.md`、`docs/reviews/M3-*.png`。`docs/probes/D1_构建报告.md` 与 R13、R14 报告在数据真的变化时随提交更新。
- **数据仓库目录**：用 `TRPG_DATA_TAG=main npm run build:data` 生成 `catalog.json`；默认的占位版本 `@v0.0.0-placeholder` 在 jsDelivr 上不存在。
- **代码约束**：
  - `tools/data/convert/` 下 11 个审计过的文件只允许末尾追加或单行原地修改。
  - 单个文件不超过 400 行。
  - 不写空 catch。
- **官方书**：中文 `reference/龙与地下城官方资料/txt`、英文 `/Users/xxx/Downloads/龙与地下城官方资料/Tashas_Cauldron_of_Everything.pdf` 与 `Sword_Coast_Adventurer_Guide.pdf`。只用于手工核对，不进数据；中文目录里的「塔莎」PDF 与「剑湾」是同一个文件。
- **提交身份**：`git -c user.name=didhogg -c user.email=143271304+didhogg@users.noreply.github.com`，末尾写 `Co-Authored-By` 行。

## 4. 已定的决定

- **塔莎包依赖**：塔莎包依赖 PHB、SCAG、DMG、XGE，因为「受祝击」等 TCE 可选变体特性挂在这些书的子职业下。

- **卸载**：确认窗列出依赖它的包，只提示、不拦截。
- **D1.2b 的 P0 范围决定**：出版不早于 2024-09-17 的 17 本书、22 个冒险不收录；UA 神秘者职业、渲染演示不收录；其余来源代号按 P0 文档处理。
