# P5-1 后端改动（为【库】界面）

日期：2026-11-10。来源：`P5-0_用户调查与需求.md` §1.1（R23–R91）与驾驶员 2026-11-10 的全部答复。**驾驶员已批准：按本文顺序一次做完，中间碰到问题再停下来问。**
每项一个本地提交，不推送；只跑相关单元测试和对应的快速 e2e 子集（`RULE LIST`：日常不跑全量）。**B-35（列显示值）是 2026-11-10 前端发现缺口后驾驶员批准补做的。**

## 0. 已定口径（驾驶员 2026-11-10）

| 事项 | 口径 |
|---|---|
| 数据格式 | 只认作者（5etools）格式；自制、冒险、我的库一律不加适配层，读不出来就是没接作者现成读取 |
| 存档 | = 对资料条目的**引用** + 存档级改动（数量、等级、充能…）。资料更新不改旧存档里存的任何东西，详情默认显示新版 |
| 设置 | 全局设置、战役设置都不进存档；读档、回档不改任何设置 |
| 读档提示 | 只在三种情况：缺包（默认勾选下载）、包在但本战役关着（默认不勾）、条目版本变了（一行提示）。P4 读取确认页去掉【恢复原样】，不列差别 |
| 编辑 / 覆盖 | 所有条目都能编辑 / 覆盖；官方源的覆盖后可复原；现有"房规"（`_copy` 指向原件）就是这套 |
| 存入我的库（Q-C 甲） | 本地**原样副本**，不受源仓库更新、卸载影响；不是"变成可编辑态" |
| 官方更新（Q-A 甲） | 官方数据跟上游新提交；**只有上游作者程序版本号与插件里带的一致时才跟**，不一致提示"要升级插件" |
| 变体（R50） | 只做变体在条目旁边正确显示；覆盖功能先不做 |

## 4. 限制与没验证

- **作者的brew结构定义不许自制文件使用官方来源标识**：存入我的库的副本，`validate` 会报 `/_meta/sources/0/json must NOT be valid`。作者格式和导入都照常通过（只提示不拦截），副本能用；界面可以忽略这类提示或说明一句。
- **B-18**：职业、行动、神祇、载具等作者没有 `ModalFilter` 的类别没有排序列；首次排序一类要 0.2–3.5 秒。
- **B-27**：整本复制大书（如 PHB）会产生大量同编号并存，解析和备选计算会慢（LLK 83 条约 4.4 秒，大书没测）；卡牌类 `card` 的备选取不到（作者隔离解析不交这一类），体检里是警告。
- **B-28 官方 `apply`**：真实下载没跑（上游现在都需要升级插件）；之前下载过的冒险正文如果上游改了，不会自动重下（下次要用时才会发现）。
- **B-34**：缺包 / 关着的包的清单界面还没做（P5 前端）；P4 读取确认页现在只剩缺资料列表 + 一行"资料有更新"。
- **没跑的 e2e**：整套 `npm run e2e`（按规矩阶段收尾且驾驶员同意时才跑）、`p3-4-full`、`suite-saves`（读取确认页）、`suite-wizard-books`（向导，联网）；`p3-1`（Chrome + WebKit）、`p3-3b-full`（Chrome）、`p5-1-backend`（Chrome + WebKit）已跑通。
- 早先的遗留：`gendata-nav-adventure-book-index.json` 缺文件的报错没查。
