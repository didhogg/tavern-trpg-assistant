1. **禁止写死数据。** 规则正文、条目名称、页码、数值说明，一律从用户已安装的数据里读。读不到就不显示，不自己写一段补上。判断标准：这段文字如果换一个数据包就该变，那它就是数据。
2. **样式以 artifact「人物详情画板」为准。** 链接 https://claude.ai/artifact/AMEiuLvooi7WCM1XMzvFg4 ，本地全文：`/Users/xxx/.claude/projects/-Users-xxx/97e3c5f5-0de9-4e30-881b-01428a961d1b/tool-results/artifact-4bb59481-1793730212-5bcb.html`。每改一块，都要拿它同一画板做对照，写明差在哪。
3. **改一块、截一次图、发给驾驶员，再改下一块。** 截图前必须 `npm run build`（截图服务读的是 `dist`）。不许拿旧图交差。
4. **不手写、也不另造第二份。** 同一份名称表只能有一份，且来源是数据。
5. 提交、推送、打标签、发布都要驾驶员当次明确授权。本表任务默认只改工作区。
6. 回复用大白话，先说结果。
