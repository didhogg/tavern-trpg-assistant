## 3. 最容易做错的地方

1. **所有人共用怪物结构**：人物的数据就是 `block`（怪物结构）；从库加怪物 / 具名 NPC 是原样复制，不写任何转换；存到我的库是写一条合法的 `monster` 条目，不新增条目类型。
2. **装备只有一个背包结构**：怪物的护甲、盾牌、武器进 `inventory`，和玩家角色同一个形状；书上的 AC 值不改，算出来对不上的只报告。旧字段 `ac[].items`、`attachedItems` 保留不动。
3. **「＋ 新建」直接进空白人物卡**，没有任何弹窗；不保存就离开 = 这个人不存在，不弹框。
4. **模板弹窗就是 L1B 选择器**（锁定怪物、具名 NPC），不另写搜索和筛选；存进我的包的人就在「怪物」分页里，靠来源书筛出来。
5. **存到我的库**：存前用 `entryDataSchemaFor('monster')` 校验；同名时有「更新它 / 另存一份」，`libraryRef` 指向那条时默认更新；包版本号由 `mine.saveEntry` 自动 +1。
6. 「加入列表」后**弹窗不关**；「编辑后加入」关弹窗进人物卡；「套用到 X」只改人物卡草稿，可撤销。
7. **起名**：第一个不带号，之后「地精 2」「地精 3」；回收站里的也算；号不回收。
8. **生命值取卡上的固定值**；没有固定值上限留空，不掷骰、不写提示文字。
9. **只有删除带撤销**（= 从回收站恢复）；其余操作不做撤销；不可撤销的（彻底删除、删有人的分类、删标签）在弹窗内**原地**确认，不叠第二个弹窗。
10. 不做收藏和顶部收藏条；行上只有「...」；置顶在「...」里；「全部」平铺不分组；行内标签全部显示、换行；行内不加术语下划线。
11. 多选栏替换工具行（在上面，不在底部）；四个操作：移到分类、加标签、去标签、删除。
12. 搜索框一直显示；切分类保留搜索与标签筛选。
13. 弹层的 e2e 照开发规范 §5.3 写（打开 → 点选项 → 值变化 → 关闭且 `body.style.pointerEvents` 恢复）。
