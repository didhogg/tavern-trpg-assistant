# P6 · 0c 画面接完整建卡器

2026-11-22。人物页的新建入口使用 0c 的左侧资料选择、右侧选择与资料、中文步骤栏和检查页。窄屏由候选列表进入右栏内容。作者完整建卡实例从选资料起就活着，每次点击立即进入作者当前选择。

```text
人物 → 新建 → 名字
                 ↓
战役库的中文名 → 左侧列表 ──玩家点选──▶ 作者自己的条目选择控件
                                         ↓
中文步骤与检查页 ◀──读取当前结果── 同一个作者建卡实例
                                         │  属性 / 装备 / 法术控件直接在页面上操作
                                         ▼
                               作者确认所有导入已完成 → 现有战役存档
```

## 接线与边界

- `native-scope.ts` 从当前发布的库和战役可见条目取名称，用已有中英编号配对对齐作者候选。左栏使用作者筛选后的选项和实际选中动作，编号含作者来源。英文资料集有对应中文资料时从库取中文显示名。
- `native-builder-ui.ts` 接作者创建可搜索条目选择器的位置。同一个位置承接种族、背景、职业和子职业。0c 步骤和检查页放在原有建卡专用小窗中。属性、技能、等级、装备、法术、自制特性仍使用原控件和作者内部选择。
- `native-builder-review.ts` 读取作者已有的等级、属性分配、装备有效性及法术数量。未填属性、未选等级、缺装备和超支会返回对应页面。法术页保留作者允许少准备法术的行为，完成页列出数量和继续选择提示。
- 建卡专用小窗的作者程序已锁定文件指纹。界面使用已批准的中文语言包。作者右栏里的部分规则正文和原控件文字仍为英文，正式启用 2024 规则另有结算入口。
- `native-build.ts` 给每一个新草稿分配跨小窗唯一的人物编号。之前每个小窗有自己的发号器，从同一号开始，随后两个草稿要进同一个战役就会撞号。正式流程在作者最后任务完成后才交出现有完整人物结果。
