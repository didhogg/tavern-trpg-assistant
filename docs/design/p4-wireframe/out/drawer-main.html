存档抽屉（有战役）

存档抽屉 · 灰度线框（只表达结构、层级、密度、控件位置；颜色、字体留给 Gate 4）

流程
F3 / F4
用户目标
一处看清当前战役、它的存档树、别的战役和被删的存档；保存、分支、读取、导出、导入
主动作
保存存档 / 读取某个存档
模式栈
Titled Sections · Collapsible Panels · Two-level tree（缩进 + 连线）· Prominent Done
法则核对
Common Region（分区用框）· Uniform Connectedness（父子用缩进和左线）· Miller（六区默认只展开两区）· Fitts（底部抽屉按钮 ≥44px）
宽度差异
宽 / 中：右侧抽屉 440 宽（中布局最大 100%）；窄屏：底部抽屉，高 88%，顶部有拖拽条，按钮 ≥44px；抽屉内部内容一样，只是更长，纵向滚动。
#元素行为 / 去向状态 · 后端
1当前战役块战役名（根存档名）+ 当前存档名 + 保存状态【接】getCampaignView.name / current
2[保存存档]（主）[分支存档][导出…]有改动才可点；无改动显示"已是最新"；分支 → 小弹层改名；导出 → 抽屉内换页【有】campaign.branch；【接】kernelSave.save
3这场战役的存档（树）分支缩进挂在父存档下；每行：名称 · 更新时间 · 规则 · 手动/自动 · 父存档 · 备注；[读取]→ 读取确认页；⋯ → 改名 / 备注 / 导出 / 删除【接】getCampaignView.branches / parentId
4其他战役（折叠）同卡的另一场、别的卡的战役，按战役根分组；读取别的卡的存档会复制成本卡新存档【接】getCampaignView.otherCampaigns
5[新建战役]（仅有战役时出现）→ 开局向导；没战役时首页横幅才是入口，不重复放【有】
6折叠区：自动存档 / 最近删除 / 其他规则自动存档只有[读取][存为手动存档]，不能单独删；最近删除有[恢复][彻底删除]【有】listAuto / listDeleted / listOtherRules
