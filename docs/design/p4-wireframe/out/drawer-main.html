存档抽屉（有战役）

存档抽屉 · 灰度线框（只表达结构、层级、密度、控件位置；颜色、字体留给 Gate 4）

流程
F3 / F4
用户目标
一处看清当前战役、它的存档树、别的战役和被删的存档；保存、分支、读取、导出、导入
主动作
保存存档 / 读取某个存档
模式栈
Titled Sections · Collapsible Panels（每个战役一张可折叠卡片）· Prominent Done
法则核对
Common Region（一场战役 = 一张卡片，存档都在卡里）· Proximity（卡头和它的存档靠在一起）· Miller（只展开当前战役）· Fitts（底部抽屉按钮 ≥44px）
宽度差异
宽 / 中：右侧抽屉 440 宽（中布局最大 100%）；窄屏：底部抽屉，高 88%，顶部有拖拽条，按钮 ≥44px；抽屉内部内容一样，只是更长，纵向滚动。其他战役的卡片都折叠，点开才看到它的存档。
#元素行为 / 去向状态 · 后端
1当前存档条当前存档名 + 保存状态；没有当前战役时整块不出现【接】getCampaignView.current
2[保存存档]（主）[新建分支存档][导出…]有改动才可点；无改动显示"已是最新"；新建分支存档 → 小弹层起名；导出 → 抽屉内换页。页头的[保存]和这里的[保存存档]都保留【有】campaign.branch；【接】kernelSave.save
3战役卡片（当前战役，默认展开）一场战役一张卡：卡头是战役名 + ⋯ + 一行说明（日期 · 规则 · 存档数），卡头没有[读取]；卡内是这场战役的所有存档，每行左对齐、不缩进，父子关系用文字"来自「…」"表达；当前存档用圆角高亮外框，在卡片里面、不压卡片边线；[读取]→ 读取确认页；行上的 ⋯ → 改名 / 备注 / 导出 / 删除（当前存档的删除不可点）。第一行"战役起点"是界面上的叫法，存的名字仍是战役名（做法 A）【接】getCampaignView.branches / parentId
4其他战役（卡片，默认折叠）头部：战役名 · 日期 · 存档数，点开才看到存档；同卡的另一场、别的卡的战役都在这里；读取别的卡的存档会复制成本卡新存档。卡头 ⋯ 的内容待驾驶员定（现在后端只能改战役名）【接】getCampaignView.otherCampaigns
5[新建战役]（仅有战役时出现）→ 开局向导；没战役时首页横幅才是入口，不重复放【有】
6折叠区：自动存档 / 最近删除 / 其他规则自动存档只有[读取][存为手动存档]，不能单独删；最近删除有[恢复][彻底删除]【有】listAuto / listDeleted / listOtherRules
