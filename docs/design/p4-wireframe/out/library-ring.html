#元素行为 / 去向状态 · 后端
1环的算法作者阶段归并为 3 段：下载文件 → 整理资料 → 准备结算；环 = 3 段 × 任务数，完成的段填满，当前段按 done/total 填；整理阶段没有总数，环转圈、不显示百分比。所以环表示"到了第几步"，不是精确百分比【有】tasks.list().progress.stage
2数据界面定时读 tasks.list()；刷新页面后任务清空，靠 dataStatus 的 incomplete 状态继续提示【有】BE-8
3完成动画环闭合 → 打勾停 2 秒 → 恢复普通图标 + 提示条"资料已就绪"【定】已批准
