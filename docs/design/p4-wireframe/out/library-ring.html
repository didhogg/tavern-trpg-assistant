#元素行为 / 去向状态 · 后端
1小环作者阶段归并为 3 段：下载文件 → 整理资料 → 准备结算；环 = 3 段 × 任务数，完成的段填满，当前段按 done/total 填；整理阶段没有总数，环转圈、不显示百分比。所以环表示"到了第几步"，不是精确百分比【有】tasks.list().progress.stage
2环旁边的数字还没完成的项数（官方资料算 1 项，每本冒险各 1 项）；失败的项也计入【有】tasks.list
3数据界面定时读 tasks.list()；刷新页面后任务清空；"上次没装完"的提示归 P5，P4 不显示【有】
4完成动画环闭合 → 打勾停 2 秒 → 小环消失 + 提示条"资料已就绪"【定】已批准
5向导里没有环向导只用浅灰文字说明；不显示任何下载进度决定
