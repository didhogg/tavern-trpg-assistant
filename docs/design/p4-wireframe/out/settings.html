流程
F7
用户目标
找到备份相关设置；进诊断；看关于
主动作
（进入栏目）
模式栈
Settings Editor · 一级下钻（Drilldown）· 平铺列表（无边框，淡色细线分隔）
法则核对
Hick（只有三个入口）· Chunking（备份的三项并成一个栏目）· Jakob（设置页的惯用下钻）· Common Region（行宽和窗口内容区同宽，对齐外壳边框）
宽度差异
窄屏：栏目行整行 ≥68px 高；其余一样。
#元素行为 / 去向状态 · 后端
1"备份与撤销 ▸"栏目是平铺的整行：左右铺满窗口内容区（和外壳边框对齐），没有边框和圆角，栏目之间只用淡色细线隔开。点进去看到三项（见下一屏）【有】updateSettings / settingsSchema
2"诊断 ▸"→ 诊断页（运行检查 → 结果 / 错误 → [返回设置]），内容不改【有】
3"关于 ▸"→ 版本、许可、致谢【有】
4栏目名"撤销记录上限"其实是结算撤销，不是备份；和备份放一起只是为了设置页只有一个栏目，所以叫"备份与撤销"（待驾驶员确认名字）待定
