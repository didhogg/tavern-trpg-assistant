```
index.html        总览（缩略图 → 点进大图和标注）
out/<屏>.html     每屏三宽度并排 + 标注表（元素 / 行为 / 状态·后端入口）
shots/<屏>.png    同上的截图（2900 宽）
p5.css            只放库页新增的类（lib-*）和线框专用类（wf-*）
lib/ screens/     生成脚本与每屏定义（u1…u6 分文件）
build.mjs         node docs/design/p5-wireframe/build.mjs [--shots] [--only=u4]   重新生成（--shots 截图，需要本机 Chrome）
```

## 怎么复制进插件
1. **样式不是另做的**：build 时把 `src/ui/styles/{tokens,palette,base,kit,shell,pages}.css`（插件真实样式）原样内联（`:host` → `.ds-root`），所以颜色、控件、窗口外壳都是插件现成的；DOM 沿用 `MainWindow.vue` / `kit` 的类名。
2. **库页新增的类**（`p5.css` 里 `lib-` 开头）复制进插件时放进 `pages.css` 或新建 `library.css`：`lib-table`（表格列表，首列 sticky）、`lib-split`（左列表 + 右详情）、`lib-dhead / lib-dbody`（详情壳）、`lib-pills`（类别药丸）、`lib-banner`、`lib-alt`、`lib-tabs`、`lib-health`、`lib-file` 等。
3. **只在线框里的类**（`wf-` 开头：酒馆顶栏占位、标注圆点、状态板）不要带进插件；`.trpg-window { position:absolute }` 和 `[data-fullscreen] { height:auto }` 两条覆盖也只是线框为了摆在酒馆占位图里。
4. 每屏的 `render()` 返回的 HTML 就是 Vue 组件模板的雏形：把 `screens/*.mjs` 里的数据（示例条目、数字）换成 store / 服务返回值；列、摘要行字段由登记表声明，不手写。

## 说明
- 线框里的条目文字（火球术、法师、书名、冒险名、自制包名）取自真实中文官方数据 / 自制目录；**数字（"n 条"、"xxx MB"、页码、体检条数、影响页里的"2 个自制包"）和"（你导入的文件名）"之类是占位**，真实界面由后端 / 作者函数给。
- 〔待核〕的 7 点（P5-0 §13.6.11）没有画成确定的界面：#1 影响预览、#2 自建范围入口、#3 配对行一次装两边、#4 "有新版"标记、#5 范围设置单独导出 / 导入、#6 无战役 / 只读态、#7 `appendToInput` 失败返回——各屏标注表里写明了怎么处理。
- 线框里关掉了所有动画（截图稳定）；真实动效用设计系统的时长，见 `docs/design/p4-design-system`。
- 未验证：只用 Chrome 截图；WebKit、真机、触屏、键盘操作都没测。
