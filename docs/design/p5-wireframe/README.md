## 弹窗形态（驾驶员 2026-11-10 定）
包 / 书 / 全库搜索都是**浮在整个插件窗口上的居中模态弹窗**（宽屏，背后压暗，样子同 P4 条目弹窗）；窄屏是**从底部上拉的抽屉式模态**。弹窗里只有一个栏目：列表 ⇄ 详情 ⇄ 下一条详情都在同一个弹窗里换页（不叠第二层），`‹` 回上一页并保留状态，`✕` 整个退出。样式见 `p5.css` 的 `data-variant='sheet'`（复制进插件时并入 kit.css 的 modal 部分）。

## 怎么复制进插件
1. **样式不是另做的**：build 时把 `src/ui/styles/{tokens,palette,base,kit,shell,pages}.css`（插件真实样式）原样内联（`:host` → `.ds-root`），所以颜色、控件、窗口外壳都是插件现成的；DOM 沿用 `MainWindow.vue` / `kit` 的类名。
2. **库页新增的类**（`p5.css` 里 `lib-` 开头）复制进插件时放进 `pages.css` 或新建 `library.css`：`lib-table`（表格列表，首列 sticky）、`lib-mbody / lib-dtools`（弹窗里的列表页 / 详情页工具行）、`lib-dbody`（详情正文）、`lib-pills`（类别药丸）、`lib-banner`、`lib-alt`、`lib-tabs`、`lib-health`、`lib-file` 等。
3. **只在线框里的类**（`wf-` 开头：酒馆顶栏占位、标注圆点、状态板）不要带进插件；`.trpg-window { position:absolute }` 和 `[data-fullscreen] { height:auto }` 两条覆盖也只是线框为了摆在酒馆占位图里。
4. 每屏的 `render()` 返回的 HTML 就是 Vue 组件模板的雏形：把 `screens/*.mjs` 里的数据（示例条目、数字）换成 store / 服务返回值；列、摘要行字段由登记表声明，不手写。
