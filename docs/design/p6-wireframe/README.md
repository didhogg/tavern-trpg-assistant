共 14 屏，每屏 3–4 种宽度（同一屏的不同宽度可以画不同状态，画框上方有说明）。做法同 `docs/design/p5-wireframe/`：build 时把插件真实样式（`src/ui/styles`）内联，所以颜色、控件、窗口外壳都是插件现成的（配色 A）；人物页新增的类放 `p6.css`（`pc-` 列表与通用、`pd-` 详情、`wf-` 只在线框里）。零件规格见 `docs/handoff/P6-4_人物_设计系统.md`。


## 宽度怎么分档
- 外壳按窗口内部宽（代码 `MainWindow.vue`）：≥720 wide / 481–720 mid / ≤480 narrow。
- 人物区按**面板宽**（容器查询）：面板 ≥720 列表 + 详情并排，否则整页下钻；详情页再按**详情面板自己的宽度**折叠（980 / 760 / 640）。
- 所以：`1440` 画框（960 窗口，内容约 760）= 并排；`900` 画框（868 窗口，约 668）= 整页；`390` = 窄；`full`（全屏）= 详情最宽的双列档。
