## 版式要点
- **配色**：整体浅色简约，红色只作点缀（选中、主按钮、生命条、法术位圆点、当前分页下划线）；外侧次级栏目用稍深的次级黄（不用浅黄白），分组条再深一档；没有 AC 盾；头像是方框。配色见 palette-v2.css（v3：红色与整体饱和度调高）。
- **列表**：照 Tidy5e 队伍表。
  - 分组条上写组名和列名「生命」。
  - 每行：方形头像、名字、职业等级、种族、小字「AC / 被动察觉」、标签、生命条、⋯。
  - 点一行进整页详情，列表和详情不并排。
- **详情**：照 Tidy5e 角色表。
  - 浅色页头。左边是生命块：**当前 / 上限 / 临时三个框就在原地**，下面是死亡豁免、生命骰、力竭、灵感。右边是身份和经验条，下面一排六属性，后面是 AC、先攻、速度、熟练四个小格，再下面是被动值。
  - 页头下面一条：状态和法术位。
  - 分页依次是：行动、数值、背包、法术、特性、效果、背景、笔记。
  - 每个分页都是"工具行（搜索 + 筛选）+ 分组表"。带框的数字点一下就掷骰。
  - 底部固定条：生命 / AC 小条、短休、长休；有设定草稿时多一个 [保存修改]。
- **窄屏**：
  - 页头竖排；
  - 表格只留名字和关键列（Tidy5e 的做法）；
  - 建卡左栏变成顶部一排圆点。
- **钱币**：没有钱币栏，钱币是背包（容器）里的物品。
