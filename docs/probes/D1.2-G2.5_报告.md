### 独立核对（不用 5etools 核对 5etools）
- 升环：用 5e API（SRD 法术）逐环核对每环骰式（`tests/data/g2-s1-spells.test.ts`）：全部一致；核对中发现冰墙术两项伤害同类型会含糊，改为"同类型的多个标签只留文字"，11 个标签认不准的法术只写 `note`（原文，`auto:false`）。
- 攻击类型：与 API `attack_type` 一致；API 漏标的 3 个（保护性结界类：驱散善恶、烈焰刀、灼热射线）以法术自己的正文"近战/远程法术攻击"为准。
- 材料价格：与 API 材料文字里的 gp 数一致（保护纽带 API 写"每枚 50gp"，两枚＝100 gp，数据对，测试里排除"每…"写法）。
- 奇械师法术表：与 **TCE 英文原书第 12–13 页**列表逐项对过：95 个全部一致。**发现并修了 G2 与我自己的盲区**：XGE 定义的 15 个法术（霜咬术、投石术……）在 5etools 里记在 `classVariant`，只看 `class` 会漏。
- 子职业扩展法术：37 个缺的是"软引用被误裁"，不是 5etools 缺；修了裁剪逻辑。
