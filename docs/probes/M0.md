## 第一轮真机结果（2026-10-28）

| 项 | 结果 |
|---|---|
| 环境 | TauriTavern 宿主已识别；`api` 含 layout/chat/chatSurface/characterCards/agent/llmConnections/mcp/skill/dev/extension/db/worldInfo；酒馆上下文不暴露 `extension_prompt_types`（注入使用数值枚举）；`libs` 在 `SillyTavern.libs`，含 localforage、DOMPurify、Fuse、lodash |
| 输入框读写 | 通过 |
| 存储 | IndexedDB 读写正常，4MB 数据可读；`navigator.storage.persisted()` 为 false（配额约 20GB，已用约 3.8GB）；扩展设置跨刷新累加正常；**完全退出后的持久性待测** |
| 聊天标识 | 角色卡聊天可取：`characterId`、头像文件名、`chatId`（含分支名，如 `… - Branch #1`）；群组与无聊天状态待测 |
| 界面实测 | 5 项通过；发现"同时存在两个下拉列表时无法选择"的缺陷，已修复并加入永久 e2e（见开发规范 §5.3） |
| 注释入请求、提示词注入、聊天事件 | **待测**（需发送消息） |
| TauriTavern 接口 | `api.chat.current` 是对象，handle 需调用 `current.handle()`（探针已修正，待重测）；另有 `api.extension.store`、`api.dev.llmApiLogs`（可读请求原文，已加入核对按钮）、`api.db` |
