### 做了什么（对应 U5R §0.1 的 15 条）
1. **没有侧拉**：全部居中弹窗（`ModalHost` 的 `dialog` 变体新增 `width`；手机变底部整页，顶部拖动条，底栏固定）。`IdentityDrawer`、`AddEffectPopover`、`HelpPopover` 已删除。
2. **悬停 = 来源，点击 = 资料弹窗**：`HoverTip`（只读、不接收鼠标、上方优先）；药丸点击 → `InfoDialog`（类别 / 获得方式 / 来源 / 正文；有条目的嵌入条目资料页）。
3. **职业框 + 等级管理按钮**；没有升级 / 降级两个按钮。
4. **身份弹窗五标签**（`BrowserTabs`）。
5. **种族 / 职业 / 背景流程**（`EntryFlow` + `flowOps.ts`）：选择 → 补选 → 分配；「选用{名称}」、「只选用，先不分配」；更换默认勾选移除旧来源内容；写入带 `auto` 来源；亚种带 `subrace:` 来源；防御与感官（抗性、黑暗视觉等）一起分配。**等级管理**真能升降级（`applyLevels`：生命平均 / 掷骰记 `hpRolls`、属性提升记 `asiLog`、降级可还原、当前生命压到新上限、生命骰已用压到总数）。
6. **敌人同构**：灵感、生命 ✎、死亡豁免、生命骰、力竭、职业框全在；只多挑战与经验徽章；敌人法术位读 `spellcasting[].spells[环阶].slots`。
7. **生命原地编辑**：上限明细、手动修正、上限覆盖、生命骰覆盖、全部恢复自动。
8. **读数三标签项目卡**（`ItemCard` + `readoutOps.ts`）：来源 / 算法只读灰字，手动调整，覆盖，[自动计算]。
9. **属性弹窗**：点数池放入红框 / 变灰 / 再点退回；「保存并写入属性点」；「清除手动修正」写明清什么（`abilityStage.ts`）。
10. **档案三卡**：各自 ✎、每类最多 3 个药丸、「+N」悬停列出、点击进对应标签；管理弹窗用浏览器式标签；可恢复 + [按来源重新分配]；感官行带距离框；工具行带 [熟练|专精]；语言按标准 / 特种 / 秘密分组、其他书籍按书折叠。
11. **效果结构化**：添加效果 = 可搜索的资料弹窗（状态 / 疾病 / 法术效果 / 其他 + 自定义）；药丸带时长与「专注」；同时专注只提示不自动移除；`rollBonus` 数据（5 个法术）。
12. **骰盘**：左侧附着标签「检定｜豁免｜自由」；检定 / 豁免面板：行动者真下拉 → 属性与技能两个真下拉 → 加值（自动只读行 + 自定义 + 查资料）→ 固定 DC（纯数字、随机 1–25）/ 对抗 / 不设 → 掷法（优势劣势互相抵消）→ 底栏（公式预览、结果区固定高度、掷骰）；被动 = 随机 DC + 「对比 DC」；死亡豁免 DC 10。`openRoll` 只填入不掷。
13. **骰子图标只在先攻格与属性图例**；检定方框、豁免、被动徽章上没有骰子。
14. **？**：顶栏唯一一个，弹窗里图标 + 一句话；空白新人物另有「怎么开始」与顶栏提示。

### 看截图后改掉的问题
读数项目卡里「手动调整」没显示（布尔 prop 默认被当成 false）；属性弹窗底栏挤成一条竖字；等级管理里特性名显示成条目编号；手机属性计算表错位；生命编辑在 WebKit 下点「添加修正」会误提交（影子 DOM 的 `relatedTarget`）；撤销没清掉撤销前新增的 `hpAdj`；顶栏粘住时上方漏出 16px 内容；深色下勾选框是纯白；骰盘「被动」时隐藏了掷法区、DC 行换行。

### 与规格不同之处
- 弹窗高度**固定**（宽屏 `min(86%, 800px)`），不是「内容高度」：切标签不跳。
- 骰盘「全部技能 18 项」入口只打开检定标签，**没有自动展开技能下拉**（reka 下拉没有安全的程序化展开）。
- 骰盘对抗标签的「对手」不含「手动输入」选项（只有人物列表 + 手填对手加值）。
- 档案里防御 / 感官 / 抗性等在数据里**没有来源字段**，来源只能写「模板 / 手动添加」；种族带来的抗性更换时按旧条目的列表移除（不是按来源精确移除）。
- `asiLog`（升级时选过的属性提升）是我为「降级可还原」新增的人物字段（草稿写入键）。
- 特性 / 物品 / 疾病 / 环境的 `data.duration` **没加**：来源（5etools）里没有可读的结构，逐条补要读书。
