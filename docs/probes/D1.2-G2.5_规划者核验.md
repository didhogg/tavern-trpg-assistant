## 发现的问题

1. **执行结果来自脏工作区**：执行 agent 跑测试时，工作区有 134 项规划者未提交改动（含 50 多个 `tests/data/*.test.ts`、`tools/data/fix/` 与 `tools/data/overlay/`）。报告里的全绿不能直接当作已推送版本的结果，须在干净工作区重跑。
2. **结构字段里的文字**：MPMM 狗头人龙盾护卫 `resist: ["见下文龙之抗性"]` 不是伤害类型代码。人物模块读取 `resist` 时必须容忍或跳过非代码值；建议 G3 或 D1.2b 统一改成空数组＋文字，数据约定写明。
3. **单元测试依赖本机原始数据**：`mod.test.ts` 经 `tools/data/config/books.ts` 在导入时读 `reference/…/books.json`，没有本机数据就整个文件失败。云端与以后的 CI 都跑不了 `check`。建议 books 数据改为惰性读取，或单元测试改用夹具。
4. **可见文字露出英文变量 `summonSpellLevel`**：TCE 94 处、BMT 2 处，例如「命中：1d10 + 3 + summonSpellLevel光耀伤害」；`src/` 里没有任何把它显示成「法术环阶」的处理。归 G3 显示整理（与 R15 处理 `<$…$>` 占位符同类）。
