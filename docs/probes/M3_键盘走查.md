## 已知限制

- macOS 的 WebKit（Safari 与 TauriTavern 的网页内核）默认不让 Tab 停在按钮上，这是系统「键盘导航」设置决定的。弹窗内的 Tab 由我们自己接管，不受影响；主窗口侧栏与页面内的按钮沿用系统行为。
