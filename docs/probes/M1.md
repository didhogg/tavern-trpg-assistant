# M1 真机自检

探针面板顶部的"M1 数据层自检"按钮，在独立的临时数据库中依次运行（只用合成数据，结束后自动删除）：

1. 运行环境（IndexedDB、structuredClone、getRandomValues、BroadcastChannel）
2. 生成并识别内容包（zip 压缩与解压）
3. 安装内置包与模组（模组依赖核心包）
4. 重复导入同一个包：要求先选择覆盖；选择后升级
5. 新存档、修改、保存、分支
6. 读取存档（写自动存档）与模板副本
7. 删除、最近删除、恢复、彻底删除
8. 导出存档并导入到另一张卡
9. 完整备份导出与覆盖恢复
10. 删除内容包

通过标准：状态为 pass，显示"全部通过（10/10 步）"。
