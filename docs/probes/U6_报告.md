6. 模板弹窗左栏宽 340（旧规格 400）：右栏底部操作栏要一行放下「编辑后加入 / 放进 / 数量 / 加入列表」。筛选面板不是贴着按钮的小浮层，而是盖在列表上、占满弹窗剩余高度（里面可滚动，底部「清除 · 完成」固定）。

8. `.trpg-btn--danger` 的字色从固定白色改成 `--primary-ink`（深色主题里危险色偏亮，白字对比度太低）；通用弹窗标题栏改衬线 20/700——这两处是共用组件，库里其它弹窗会一起变。
9. 速度写「30尺」，数字和「尺」之间没有空格（「尺」14px 小一号）。
10. 数值栏的标签和数字之间保留一个真正的空格（只是不占版面）：WebKit 读卡片文字时会把没有空格的「AC17」连在一起，旧 e2e 断言要读「AC 17」。
11. **立绘与头像数据**：地精头目在数据里没有立绘（只有 token，没有 portrait），所以显示类型图标占位，没有做假图；有立绘的真实怪物用地精（MM）。「上传了头像的玩家角色」用 `avatar` 字符串字段（盖尔，用大法师立绘图转成 data 地址当夹具）。`{ $asset }` 形式的本地上传头像目前没有读取方式（图片仓库界面还没做），遇到就回退到立绘/类型图标。
12. 队伍页：内容区 ≤ 720 用堆叠卡片，更宽用规格的竖线分栏（队伍页的生命栏 150、AC 64、被动察觉/速度 70，比普通页略窄，给名字留地方）。
