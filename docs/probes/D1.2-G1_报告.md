## 3. 与执行文档不同之处

1. **依赖**：纯引用推导会改变 MM、XGE、VGM 的现有依赖（它们没有指向 DMG / PHB 的硬引用）。保守保持现状，在政策表用 `requires` 额外写明（MM→DMG、XGE→PHB、VGM→PHB）；其余依赖完全由引用推导，与开工快照一致。这是我自己做的决定（触到停止条件 2），请驾驶员复核。
2. **旧格式包**引用不合规：只在控制台提示，没有接入体检。
3. **dataVersion 3** 只用于新建的自制包；复制的包保持原版本，避免旧包的副本装不上。
4. **正文变化**：6 个条目（MTF、MPMM 的提夫林、基因西亚裔等亚种族）里原来的纯文字法术名变成了可点引用（依赖推导更完整）。`g1-additive` 验证：还原引用后与原文逐字相同。
5. `joins` 的 `as: member` 校验已实现，界面未显示；剑湾图腾选项（`as: option`）界面也未显示，留给 G3。
6. 删除的 S1 测试 `s1-additive`、`s1-grant-labels`；`r15-tce-variants`、`r15-totem-options`、`r3-optional-class`、`r1-grants`、`d12a-*` 等改成新格式（理由：旧格式的可选授予与 `joinsChoice` 不再存在）；写死的总数、依赖表改为规则型断言。
