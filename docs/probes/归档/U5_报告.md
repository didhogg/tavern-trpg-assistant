# U5 UNIT2 · 人物详情页概览带报告

状态：**实现、自动测试、截图与两轮独立视觉复查已完成；等驾驶员真机验收。**
分支：`u5a`（从 `main` 的 `411be95` 建出；未推送）。

## 交付范围

- 顶栏：返回、居中名字、保存状态、唯一撤销入口、保存、⋯、？；新卡首次打开提示一次。
- A 基本信息卡：头像点击选图→`autoCropAvatar` 4:5→草稿；名字/英文名/身份/灵感/套用模板/升级降级占位；生命当前/上限/临时原地编辑、死亡豁免、生命骰、休息占位；AC/先攻/速度/熟练/被动读数。
- B 属性卡：检定大方框、豁免小框、最终属性值、熟练点、图上两个同尺寸骰子图标、上限 20；390 为 3×2。
- C：法术位圆点、力竭 0–6 与逐级说明、效果药丸、添加效果/自定义提示；资源无数据源时不显示。
- D：抗性/免疫/易伤/状态免疫/感官/语言/武器/护甲/工具只读摘要，超过 3 个折成 `+N`。
- E/F：五个分页标签全部显示「本分页尚未开放」；窄屏标签横滑并把当前项滚入视野。
- 身份抽屉（480）：头像上传/重新截取/清除、名字、英文名、阵营代码、种族/亚种族/背景、模板体型与类型；底部草稿说明。
- 重新截取页：4:5 拖框、四角、滑条与 −/＋、键盘移动、预览、取消/应用。
- 添加效果弹层：14 种状态 + 法术搜索 +「法术效果」说明、自定义占位；效果说明小层与移除。
- 库模式：`存入我的库` 后从库条目「打开」同一张卡，顶栏「保存到库」、库上下文与不改战役的提醒。
- 套用模板：只替换 `block`，名字为空才填；套用后进入草稿并可撤销。
- R1.1 派生函数：属性、总等级/熟练、豁免、技能、先攻、被动、AC、生命上限/生命骰、速度、法术位；纯函数带单测。
- `useDiceStore().prefill`：打开骰盘并填骰式/说明，不自动掷。

不做：UNIT3 属性/读数/技能抽屉、九个档案弹窗与来源弹层、行动与技能页；UNIT4 选择/分配/升降级/加点；UNIT5 AC 装备；UNIT6 法术页；活动结算；底栏与任何掷骰功能。

## 数据与迁移

`src/schemas/people.ts` 新增可选字段：`inspiration`、`exhaustion`、`hitDiceUsed`、`slotsUsed`、`resourcesUsed`、`avatarSource { asset, crop }`。
`monsterDataSchema` 新增可选字段：`abilityOther`、`abilityGrowth`、`overrides`、`adjust`、`proficiencies`（技能/豁免/语言/武器/护甲/工具，均带来源）。

全部字段可选、旧数据直接通过；没有新增必填字段或改字段形状，因此**不升 `schemaVersion`、不写迁移**。写入只经 `usePeopleStore` 的 `setLive` / `saveDraft` / `autoAssignAvatar`；`src/schemas/peopleWrites.ts` 登记当场状态与设定类写入集合。

## 规格处理与偏差

- 无战役时侧栏隐藏「人物」：沿用 U6 已接受决定。
- 头像：主界面 96×120、390 72×90；与 U5 视觉规格一致。
- 所有抽屉单页，不叠第二个模态；身份抽屉宽 480，重截取在同一抽屉栈内换页；窄屏底部上拉 92%。
- 生命上限是设定类（草稿），当前/临时是当场状态；编辑一次只占一步撤销。
- 添加效果只写说明，不参与任何派生计算。
- `.trpg-card-a` 不拉高，避免读数被推到底部；宽屏右侧 B+C 比 A 高时，D 区按网格排在其后。
- 库模式保存到库时只写怪物结构，不带头像/当前生命/临时/死亡豁免/效果；这是 U6 §5.2 的既有契约。
