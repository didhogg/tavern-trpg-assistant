## 真机结果（TauriTavern / macOS / WebKit，2026-10-28）

| # | 探针 | 结论 | 证据 |
|---|---|---|---|
| 1 | 宿主与设备环境 | 通过 | 识别 TauriTavern；`api` 含 layout、chat、chatSurface、characterCards、agent、llmConnections、mcp、skill、dev、extension、db、worldInfo；`extension_prompt_types` 不在上下文；libs 在 `SillyTavern.libs` |
| 2 | 注释入请求 | 通过 | `chat_completion_prompt_ready` 与 `generate_after_data` 的请求原文含完整 `<!--…-->`；消息已存入聊天记录；楼层 DOM 无该文字、无注释节点。仅在事件层确认，未用请求日志接口核对 |
| 3 | 提示词注入 | 通过 | 请求中出现 system 消息，距末尾 14 条（预设在聊天记录后追加了 14 条） |
| 4 | 输入框读写 | 通过 | 写入、读回、恢复一致 |
| 5 | 存储持久性 | 部分通过 | IndexedDB 跨刷新保留，4MB 数据可读；`persisted()` 为 false（配额约 20GB）；扩展设置出现一次丢失写入（IndexedDB 计 8 次、设置计 7 次）；完全退出后的持久性待确认 |
| 6 | 角色卡/群组/聊天标识 | 部分通过 | 角色卡聊天：可取 `characterId`（下标字符串）、`avatar` 文件名、`chatId`（含分支名）；群组与无聊天状态待测 |
| 7 | 聊天事件 | 部分通过 | 已观察：GENERATION_STARTED、MESSAGE_SENT、GENERATION_ENDED、MESSAGE_RECEIVED；待测：CHAT_CHANGED、MESSAGE_SWIPED、MESSAGE_EDITED、MESSAGE_DELETED |
| 8 | TauriTavern 接口 | 通过 | `api.chat.current.handle()` 有效；`searchMessages`、`locate.findLastMessage`、`handle.store`、`api.extension.store` 的读写删列均成功；`metadata.get` 返回整个聊天元数据（含其他扩展数据） |
| 9 | 界面实测 | 通过 | 5 项人工确认通过；下拉缺陷修复后复测通过 |

| 10 | 请求日志核对 | 未验证 | 核对时最新的一条请求是普通消息，不是带标记的测试请求 |

**未验证项的处理**：群组与无聊天标识 → M1 真机验收时由界面显示当前数据键来验证；CHAT_CHANGED / SWIPED / EDITED / DELETED → M5、M6 真机验收时验证（提及扫描与日志依赖它们）；请求日志核对 → M5 端到端验收时由扩展自动核对。

**TauriTavern 存储接口**：`api.extension.store` 为文件存储，位于数据目录 `_tauritavern/extension-store/`，每个 `(namespace, table, key)` 一个文件，随数据目录备份；单键写入原子，不支持跨键事务；Blob 可流式读取；文档未给出体积上限。`api.db` 为向量/文本/图数据库（TriviumDB），位于 `_tauritavern/databases/`。

## 模拟宿主冒烟结果（非真机）

`npm run e2e` 在模拟酒馆页面中验证了扩展挂载、探针接线、样式隔离、窗口拖动限位与下拉不越界（桌面 1440 与窄屏 390 两种宽度，截图见 `docs/reviews/M0-mock-*.png`）。该结果只说明代码接线正确，**不能代替上表的真机结论**。
