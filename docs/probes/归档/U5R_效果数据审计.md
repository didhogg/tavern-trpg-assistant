## 结论

1. **状态与法术的数据已经够做结构化人物效果**：状态直接带 `effects`；法术带 `duration[]`（含专注）。
2. **特性 / 物品 / 疾病 / 环境没有 `duration` 字段**，疾病与环境没有结构化 `effects`。U5R §12 要增补的可选字段 `data.duration` 与 `rollBonus` 属于数据管线任务（批 1）。
3. 所有条目都有正文或摘要，资料弹窗「没有正文也没有摘要」的条目数 = **0**（以此口径）。
4. `effects.ts` 现有 22 种效果；没有「掷骰额外加值」（祝福术 +1d4、神导术 +1d4 无处表达），要加 `rollBonus`。
