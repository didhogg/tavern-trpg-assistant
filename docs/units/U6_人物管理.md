## 1. 设计说明

- **北极星**：**一眼找到人，一下进人物卡。** 列表是通往人物卡的目录，不是第二张人物卡。
- **主角**：人物列表；**主动作**：点行打开人物卡。第二位是「＋ 新建」（右上角唯一主按钮）。管理功能（分类、标签、回收站）收进「⋯」，批量操作收进多选。
- **视觉层级**（从强到弱）：名字 → 生命 → 第二行（职业、种族或怪物、挑战等级）→ 标签、AC → 图标按钮。每行只有名字用衬线字体和正文色，其余都退到次要色。
- **关键状态**：正常、空列表、空分类、搜索无结果、多选中、加载中、写入失败。
- **设备**：主悬浮窗内部宽度 1440 / 900 / 390 三档检查（开发规范 §5.2）；手机上是 TauriTavern。
- **验收重点**：从打开人物页到进入某人的人物卡，熟悉的人 ≤ 2 次点击（收藏条或列表行）；加一批怪物 ≤ 5 次点击；一屏能看到的人数宽屏 ≥ 10、手机 ≥ 6。

## 2. 范围

**做**：分类、收藏、置顶、搜索、标签筛选、排序、多选批量、行尾菜单、新建（从库里选、空白人物）、分类管理、标签管理、回收站、撤销；支撑这些的数据、store 与迁移。

**不做**：人物卡本身（各分页 Unit）；流程式 6 步建卡（进阶版本，菜单灰显）；随行 / 留守与营地（地图之后的进阶版本）；全队休息、分经验、分战利品（【活动模块】）；「谁是玩家扮演的角色」（U4.0）。

**依赖**：U6.1 数据层（本文件 §8）；R1.1 提供行内等级、AC、生命上限（完成前完整卡行只显示已填的值）；L1B 选择器（「从库里选」复用）；G3 的 `EntityAvatar`；外壳与 `ModalHost`（U1）；G3 续做 §12.6 的怪物生命值修正。

## 4. 区块细则

### 4.1 分类栏（A）

- 顺序：**全部** → 队伍 → NPC → 敌人 → 自建分类（按「分类管理」里的顺序）→ 「＋」。
- **全部**不是分类，只是列出所有人；**默认三类**能改名、不能删、不能挪位置。
- 每项「名称 + 人数」；人数用小一号常规字重。名称超过 8 字截断，悬停或长按显示全名。
- **「＋」**：点了在原位变成输入框（宽 160px，占位「分类名」），回车创建并切到新分类，Esc 或失焦（空内容）取消；名称 1–16 字，重名时输入框下方写「已经有这个分类了」。
- 放不下时横向滚动；两端 24px 渐隐；溢出一侧显示 ‹ › 图标按钮，每次滚动一屏宽度的 80%。
- 当前分类在本次打开期间记住；重新打开人物页回到上次的分类（存战役设置）。
- 键盘：分类栏是 `tablist`，← → 移动、Enter / 空格切换，Home / End 到两端。

### 4.2 收藏条（B）

- 打了 ★ 的人按收藏时间排（早收藏的在左）：28×35 头像 + 13px 名字（最多 6 字，超出截断）。
- **跨分类常驻**；点一下直接打开人物卡。没有收藏时整条不显示。
- 放不下时横向滚动，规则同分类栏。
- 标题「收藏」12px 次要色，在最左边；窄屏省略标题，只留头像。

### 4.3 工具行（C）

| 控件 | 组件 | 规则 |
|---|---|---|
| 搜索框 | 输入框（带放大镜图标与清除 ×） | 占位「搜名字、种族、职业、标签」；匹配名字、英文名、种族名、职业名（多职业逐个）、属性块怪物名、标签名，不分大小写；中文输入法拼字期间不搜；输入停 150ms 后搜；只在当前分类里搜 |
| 「＋ 标签」 | 可搜索下拉 `Combobox` | 列出全部标签与人数，↑↓ 选、Enter 加入、Esc 关；选中的标签变成筛选药丸（`TagPill`，带 ×）；多个标签 = 同时具备 |
| 「共 N 人」「清除」 | 次要文字 + 文字按钮 | 有搜索词或筛选时出现在工具行末尾；「清除」一次清空搜索与全部筛选 |
| 排序 | 下拉选择 `SelectField` + 方向按钮 | 选项：修改时间（默认）、创建时间、名称、等级或挑战等级；方向按钮图标 ↓ / ↑，可读名称「从新到旧」等随排序变化 |
| 「选择」 | 次按钮 | 进入多选（§4.5） |

- 当前视图 ≤ 8 人时**不显示**搜索框和「＋ 标签」（排序与「选择」保留）。
- 搜索、筛选、滚动位置、分组折叠**每个分类各自记住**（本次打开期间）；排序与方向存战役设置。

### 4.4 列表（D、E）

**分组标题（D）**
- 「全部」：置顶 → 队伍 → NPC → 敌人 → 自建分类；某个分类里：置顶 → 其余（没有置顶时不显示标题）。
- 标题行：组名（12.5px 次要色，字距 0.04em）+ 人数（右侧）+ 一条细线；「全部」里的组标题前有 ▸ / ▾，点整行折叠或展开；人数为 0 的组不显示。
- 列表滚动时组标题吸顶。

**人物行（E）：显示规则**

| 位置 | 内容 | 规则 |
|---|---|---|
| 头像 | 40×50 | 玩家上传的图 → 属性块立绘焦点裁切 → 生物类型图标（属性块）→ 剪影图标（其余）；`EntityAvatar` |
| 名字 | 中文名 + 英文名（12px 次要色） | 英文名与中文名相同或为空时不显示；单行截断，`title` 显示全名 |
| 第二行 | 完整卡「法师 3 / 人类」，多职业「战士 3 · 法师 2 / 人类」；属性块「地精 / 挑战 1/4」 | 什么都没有就留空 |
| 标签 | 药丸按钮，最多 2 枚 + 「+N」 | 点标签 = 加为筛选条件；「+N」点了展开显示全部标签（本行内） |
| 状态 | 方块徽章，最多 2 枚 + 「+N」 | 有状态才显示；不可点（点了等于点整行） |
| 生命 | 「12/18」+ 64×6 血条 | 临时生命在血条右端接一段金色；当前为 0 显示「倒下」（危险色，无血条）；上限未知时整块不显示 |
| AC | 「AC 12」 | 未知时不显示 |
| ★ | 收藏开关（图标按钮） | 关：空心、次要色 40% 透明；开：实心金色 |
| 📌 | 置顶开关（图标按钮） | 关：空心、次要色 40% 透明；开：实心主色 |
| ⋯ | 行尾菜单 | §4.6 |

**人物行：点哪做什么**

| 点 | 结果 |
|---|---|
| 行空白处、头像、名字、第二行、生命、AC、状态 | 打开人物卡 |
| 标签药丸 | 加为筛选条件 |
| ★ / 📌 | 切换（立即生效，提示条可撤销） |
| ⋯ | 打开菜单 |
| 组标题（「全部」） | 折叠或展开 |

- 行内**不加术语下划线**（人物模块框架 §6）。
- 键盘：↑ ↓ 在行之间移动焦点，Enter 打开；行内的按钮用 Tab 进入。
- 从人物卡返回：列表回到原来的分类、滚动位置与筛选；刚打开过的那一行淡金色闪一下。

### 4.5 多选（F）

- 进入：「选择」按钮。退出：「完成」或 Esc（退出即清空勾选）。
- 多选中：行首出现勾选框（`Checkbox`），点行任意处 = 勾选或取消；桌面 Shift + 点击选一段；行尾 ★ 📌 ⋯ 隐藏；分类栏仍可切换（切换时清空勾选）。
- 底栏内容（左 → 右）：「已选 N 人」·「全选当前结果（N）」（全选后变「取消全选」）· 移到分类 ▾ · 标签 ▾ · 收藏 · 置顶 · 复制 · 删除 ·「完成」。没选人时除「全选」「完成」外全部禁用。

| 按钮 | 组件 | 行为 |
|---|---|---|
| 移到分类 ▾ | 下拉菜单 | 列出所有分类（当前分类禁用）；点了立即移动 |
| 标签 ▾ | 弹层：搜索 + 标签列表（三态勾选框：全有 / 部分有 / 都没有）+「新建标签…」+「完成」 | 点「完成」时一次应用；部分有的标签不点就保持原样 |
| 收藏 / 置顶 | 按钮 | 选中的人全都已收藏时变「取消收藏」；置顶同理 |
| 复制 | 按钮 | 唯一人物跳过，提示条写「2 个唯一人物没有复制」 |
| 删除 | 危险色文字按钮（放在最后） | 移入回收站，不确认，提示条撤销 |

- 多选只作用于当前看得见的结果（搜索、筛选之后）；操作完成后保持多选状态，便于继续下一步。

### 4.6 行尾菜单（⋯，`MoreMenu`）


菜单项是动词短语；危险项放最后；菜单不放「打开」「收藏」「置顶」（行上已有）。

### 4.8 从库里选（弹窗内页）

```
┌ ‹ 人物 · 从库里选 ─────────────────────────────────────────── ✕
│ [ 怪物 | 具名 NPC ]   [⌕ 搜名字、挑战等级、类型…]   [筛选 ▾]      共 3,873
│ ───────────────────────────────────────────────────────────────
│ [头像] 地精 Goblin            小型类人 · 挑战 1/4 · 怪物图鉴
│ [头像] 地精首领 Goblin Boss   小型类人 · 挑战 1   · 怪物图鉴
│ …（虚拟滚动）
│ ─────────────── 选中后在底部出现 ───────────────
│ 地精 Goblin（下划线术语，点了看资料卡）
│ 生命 7（卡上的固定值）   AC 15   挑战 1/4
│ 数量  [−]  3  [+]            放进  [ 敌人 ▾ ]
│ 会叫：地精 1、地精 2、地精 3
│                                                        [ 加入 ]
```

- 「怪物 | 具名 NPC」是分段按钮（`Segmented`）；列表、搜索、筛选复用 L1B 选择器。
- 选中一行：行高亮（主色 8% 底 + 左侧 3px 主色竖条），底部出现加入区；再点别的行切换选择；Enter 等于「加入」。
- **数量**：数字输入 + 加减按钮（1–30）；规则按开发规范 §5.4 数字输入。**放进**：下拉选择，默认怪物 → 敌人、具名 NPC → NPC。
- **唯一条目**：数量锁定 1；已在列表里 →「加入」换成「已经在列表里 · 打开」；在回收站 →「在回收站里 · 恢复」。
- **生命值**（驾驶员定）：

| 卡上 | 加进来的人 | 加入区显示 |
|---|---|---|
| 有固定值 | 当前 = 上限 = 固定值 | 「生命 7（卡上的固定值）」 |
| 特殊规则 | 上限留空 | 「生命：卡上写『…』，加入后请在人物卡里填」 |
| 原书未给出 | 上限留空 | 「生命：原书未给出，加入后请在人物卡里填」 |

- **命名**：同一库条目第一次只加 1 个叫「地精」；数量 > 1，或列表里已有同条目的人时，编号续接（不带编号的算 1）：「地精 2、地精 3…」。编号不回收，已有的人不改名。「会叫：」一行实时预览。
- **加入后**：关闭弹窗，切到目标分类，新行淡入并闪金色、滚到可见；提示条「已加入 地精 1–3 · 撤销」。
- 名字是下划线术语：点了在同一弹窗内换页到库的资料卡；「‹」返回时选中、数量、搜索词都还在。

### 4.9 空白人物（弹窗内页）

```
┌ ‹ 人物 · 空白人物 ──────────────────────── ✕
│ 名字   [                          ]
│ 放进   [ 队伍 ▾ ]
│                       [ 创建并打开 ]
```

- 名字必填（1–40 字，去首尾空白）；为空时按钮禁用，输入框下方写「起个名字」。
- 「放进」默认当前分类；在「全部」里新建时默认「队伍」。
- 创建后关闭弹窗、打开这个人的人物卡。

### 4.10 分类管理（弹窗内页）

```
┌ ‹ 人物 · 分类管理 ──────────────────────────────────────── ✕
│ 队伍       4 人                                      [改名]
│ NPC        9 人                                      [改名]
│ 敌人       2 人                                      [改名]
│ ──────────
│ 深水小队    3 人                       [改名] [↑] [↓] [删除]
│ [ ＋ 新建分类 ]
```

- 改名：名字原位变输入框，回车保存、Esc 取消。
- 删除自建分类：原位展开一行「里面 3 人移到 [ 队伍 ▾ ]　[删除]　[取消]」——这是选去向，不是确认；空分类直接删。删除后提示条可撤销。
- ↑ ↓ 调整自建分类顺序（默认三类不动）。

### 4.11 标签管理（弹窗内页）

```
┌ ‹ 人物 · 标签管理 ─────────────────────────────────────────────── ✕
│ 冒险者  5 人       [改名]  [合并到 ▾]  [这些人移到分类 ▾]  [删除]
│ 商人    4 人       [改名]  [合并到 ▾]  [这些人移到分类 ▾]  [删除]
│ [ ＋ 新建标签 ]
```

- 标签名 1–24 字，不分大小写不能重名。
- 合并、删除、移到分类都直接执行，提示条撤销（例：「已把『商人』并到『商贩』· 撤销」）。
- 窄屏时四个按钮收进每行末尾的「⋯」。

### 4.12 回收站（弹窗内页）

```
┌ ‹ 人物 · 回收站 ───────────────────────────────────────── ✕
│ [头像] 地精 1    原来在：敌人    3 天前删除    [恢复] [彻底删除]
│ [头像] 地精 2    原来在：敌人    3 天前删除    [恢复] [彻底删除]
│                                                 [ 清空回收站 ]
```

- 恢复回原分类；原分类已删时恢复到「队伍」，提示条写明。
- 「彻底删除」「清空回收站」不可撤销 → 弹窗内换页到确认页（`ConfirmPage`）：「彻底删除 地精 1？删除后不能恢复。」[彻底删除]（危险色）/「‹ 返回」= 取消。
- 回收站里的人不出现在列表、收藏条、搜索中，不给 AI。不自动清空。

### 4.13 提示条

| 类型 | 停留 | 例子 |
|---|---|---|
| 可撤销的操作 | 6 秒，带「撤销」 | 已收藏 盖尔 · 已把 3 人移到 NPC · 已删除 地精 1、地精 2 · 已加入 地精 1–3 |
| 成功（不可撤销后） | 4 秒 | 已彻底删除 2 人 |
| 失败 | 8 秒；出错的行显示 ⚠ 与「重试」 | 没能保存：存储已满 |

- 同时最多 3 条，新的在下；鼠标停留或焦点在提示条内时暂停计时。
- 撤销只还原这一次；这几个人之后又被改过 →「已无法撤销」，不强行覆盖。

### 4.14 空状态与加载

| 情况 | 说明 | 主操作 |
|---|---|---|
| 一个人都没有 | 还没有人物 | ＋ 新建 |
| 当前分类没人 | 这个分类还没有人 | ＋ 新建 |
| 搜索或筛选没结果 | 没有符合的人物 | 清除条件 |
| 回收站为空 | 回收站是空的 | — |
| 加载 | 超过 300ms 才显示 3 行骨架 | — |

## 7. 交互通则、边界与错误

### 7.1 键盘

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框（不在输入框里时） |
| ↑ ↓ | 在行之间移动焦点 |
| Enter | 打开焦点所在的人物卡；多选时勾选 |
| 空格 | 多选时勾选 |
| Esc | 依次：关闭弹层 → 清空搜索 → 退出多选 |
| ← → | 分类栏内切换 |

### 7.2 可访问性

- 分类栏 `role="tablist"`，每项 `role="tab"` + `aria-selected`；列表 `role="list"`，行 `role="listitem"`。
- 图标按钮都有可读名称（§6 最后一行）；开关类按钮用 `aria-pressed`。
- 状态不只靠颜色：★ 📌 开关有实心 / 空心之分；「倒下」有文字。
- 提示条 `aria-live="polite"`。

### 7.3 边界情况

| 情况 | 处理 |
|---|---|
| 名字很长 | 单行截断，`title` 显示全名；收藏条最多 6 字 |
| 重名 | 允许；靠头像、第二行、编号区分 |
| 一个分类上千人（怪物导入多次） | 超过 80 行启用虚拟滚动（`VirtualList`，需扩展支持吸顶组标题与三种固定行高） |
| 自建分类很多 | 分类栏横向滚动 |
| 回收站里的人的原分类被删 | 恢复到「队伍」并提示 |
| 唯一 NPC 在回收站时又从库里加 | 「在回收站里 · 恢复」 |
| 多选时切换分类 | 清空勾选 |
| 撤销时相关人物已被改过 | 「已无法撤销」 |
| 库条目所在的包被卸载 | 列表照常显示（数据已拷贝到人物上）；资料卡打开时提示「这个条目所在的扩展包没有安装」 |

### 7.4 写入失败

- 每个操作先写当前数据，成功后才更新界面并出提示条；失败时界面不变，出失败提示条（8 秒），出错的行显示 ⚠ 与「重试」。
- 不先显示成功再回滚。

### 7.5 性能

- 搜索输入停 150ms 再算；排序、筛选、分组是纯函数，结果按「人物数据版本 + 条件」缓存。
- 行内摘要（第二行、生命、AC）一次算好放进 `rowOf`，不在每次渲染时重算。
- 头像懒加载（`EntityAvatar` 已支持）。

## 10. 验收

**单元测试**
- `nextNames`：首次 1 个不编号；数量 > 1；已有同条目时续号；已有人不改名；编号不回收。
- `hpFromEntry`：固定值、特殊规则、原书未给出。
- `filterPeople`：各字段命中；多标签同时具备；回收站排除。
- `sortPeople`：四种键、并列规则、没有等级的排最后、分数挑战等级。
- `groupPeople`：「全部」与单个分类的分组；空组不出现。
- store：唯一条目（已存在、在回收站）；分类增删改与移人（默认三类拒绝）；标签改名、合并（并集）、按标签移分类、删除；收藏、置顶、复制（唯一跳过）；回收站恢复（原分类已删 → 队伍）、彻底删除、清空；撤销成功与「已无法撤销」；迁移补齐默认分类。

**e2e**（Chrome 与 WebKit；弹层与弹窗按开发规范 §5.3 的弹层用例写）
1. 从库里加地精 ×3 → 进「敌人」、名字地精 1–3、生命 7 → 撤销 → 消失。
2. 新建空白人物 → 进人物卡 → 返回 → 分类、滚动、筛选还原，该行闪一下。
3. 收藏 → 收藏条出现 → 切到别的分类仍在。
4. 多选两人 → 移到 NPC → 撤销。
5. 删除 → 回收站 → 恢复回原分类；彻底删除走确认页，弹窗始终只有一个。
6. 两个标签同时具备的筛选 →「共 N 人」→「清除」。
7. 新建自建分类 → 删除时选去向「队伍」→ 撤销。
8. 唯一 NPC 第二次加入 →「已经在列表里 · 打开」。
9. 键盘：`/` 搜索、↑↓ 移动、Enter 打开、Esc 依次退出。
10. 行尾菜单与「标签」弹层：打开 → 点选项 → 值变化 → 弹层关闭且 `body.style.pointerEvents` 恢复（开发规范 §5.3）。
