## 0. 范围

**本单元做**：人物页的列表与全部管理功能——分类、收藏、置顶、搜索、标签筛选、排序、多选批量、行尾菜单、新建（从库里选、空白人物）、分类管理、标签管理、回收站、撤销；以及支撑这些的数据与 store。

**本单元不做**：
- 人物卡本身（外壳与五个分页）——各自的 Unit；
- 流程式 6 步建卡——以后的进阶版本（菜单里灰显）；
- 随行 / 留守、营地——做完地图后，进阶版本做营地时再做；
- 全队休息、分经验、分战利品——【活动模块】；
- 「谁是玩家扮演的角色」（给 AI 用）——U4.0 决定。

**依赖**：U6.1 数据层（本文件 §6）；R1.1 提供行内的等级、AC、生命上限（R1.1 完成前，完整卡的行只显示已填的值）；L1B 选择器（「从库里选」复用）；G3 的头像组件 `EntityAvatar`；外壳与弹窗宿主（U1）。

## 1. 玩家在这一页要做的事

| 任务 | 一句话 | 主动作 |
|---|---|---|
| 找到某个人并打开他的人物卡 | 收藏条一点，或在分类里扫一眼、搜一下 | 点行 |
| 加怪物 / 加 NPC | 从库里选，填数量，进对应分类 | 「＋ 新建 → 从库里选」 |
| 建一个自己的角色 | 起个名字，进人物卡填 | 「＋ 新建 → 空白人物」 |
| 整理 | 分类、标签、收藏、置顶，打完仗把怪物一起删了 | 多选 → 批量操作 |
| 找回误删的人 | 回收站里恢复 | 「⋯ → 回收站」 |

每屏主角是**人物列表**，主动作是**点行打开人物卡**；新建是第二重要，放右上角主按钮；其余管理收进「⋯」和多选。

## 3. 各区细则

### 3.1 分类栏（A）

- **默认分类**：队伍、NPC、敌人。能改名，**不能删、不能挪位置**，永远排在前三位。
- **「全部」不是分类**，只是把所有人列出来；永远在最左边。
- **自建分类**：点「＋」，分类栏里就地出现输入框，回车创建、Esc 取消；名字 1–16 字，不能和已有分类重名（不分大小写）。自建分类排在默认三个后面，顺序在「分类管理」里调。
- **一个人只属于一个分类**。换分类 = 移过去（行尾 ⋯ 或多选）。
- 每个标签后面显示人数；分类名超过 8 个字时截断加省略号，悬停或长按显示全名。
- 分类多了放不下时，分类栏可以横向滑动，两端渐隐，并有左右箭头按钮。
- 当前分类记在本次打开期间；重新打开人物页回到上次的分类。

### 3.2 收藏条（B）

- 打了 ★ 的人，按收藏的先后排成一条：小头像（28×35）+ 名字。
- **不管切到哪个分类都在**；点一下直接进人物卡。
- 没有收藏时整条不显示，不留空位。
- 放不下时横向滑动，规则同分类栏。

### 3.3 工具行（C）

**搜索**
- 只有一个搜索框，占位文字「搜名字、种族、职业、标签」。
- 匹配：名字、英文名、种族名、职业名（多职业逐个）、属性块的怪物名、标签名；不分大小写；中文输入法拼字期间不搜，拼完再搜。
- 只在当前分类里搜；在「全部」里就是搜所有人。

**标签筛选**
- 点「＋ 标签」弹出下拉框：顶部有搜索，下面是所有标签和人数；点一个就加成一枚筛选胶囊。
- 选了多个标签时，要同时有这些标签的人才显示；胶囊上的 × 去掉这个条件。
- 有搜索词或筛选条件时，工具行末尾出现「清除条件」。

**排序**
- 四种：**修改时间**（默认）· **创建时间** · **名称** · **等级或挑战等级**；旁边的箭头按钮切换先后顺序。
- 修改时间：打开人物卡、保存人物卡、在列表里改过他（收藏、移分类、改标签……）都算修改。默认最近的在前。
- 名称：按中文拼音顺序（`localeCompare('zh')`）。
- 等级或挑战等级：完整卡按总等级，属性块按挑战等级，两种放在一起按数字比；没有等级的排最后。默认高的在前。
- 排序选择记在战役设置里，下次打开还是它。

**选择**：进入多选（§3.5）。

### 3.4 列表（D、E）

**分组**
- 「全部」：置顶 → 队伍 → NPC → 敌人 → 各自建分类。每组标题可以点击折叠（折叠状态本次打开期间记住）；没有人的组不显示。
- 某个分类里：有置顶时分「置顶」「其余」两组；没有置顶就不显示组标题。

**人物行显示什么**

| 位置 | 内容 | 规则 |
|---|---|---|
| 头像 | 40×50 | 玩家上传的图优先；没有时属性块怪物用立绘焦点裁切，没有立绘用生物类型图标（G3 的 `EntityAvatar`）；其余人显示剪影 |
| 名字 | 中文名；后面灰色小字英文名 | 英文名和中文名一样就不显示；过长截断，悬停或长按看全名 |
| 第二行 | 完整卡：「法师 3 / 人类」，多职业「战士 3 · 法师 2 / 人类」；属性块：「地精 / 挑战 1/4」 | 什么都没填就留空，**不写「未填写」** |
| 标签 | 最多 2 枚，多的写「+N」 | 点标签 = 用它筛选当前列表 |
| 状态 | 最多 2 枚，多的写「+N」 | **有状态才显示**；只是显示，点了等于点整行 |
| 生命 | 「12/18」加一条短血条 | 当前为 0 时写「倒下」，不画血条；不知道上限时整块不显示 |
| AC | 「AC 12」 | 不知道时不显示 |
| ★ 📌 | 收藏、置顶开关 | 关着时显示淡色空心图标（触屏也能点到，不靠悬停）；开着时实心（★ 金色、📌 酒红） |
| ⋯ | 行尾菜单（§3.6） | |

**点哪做什么（一个位置只做一件事）**

| 点 | 结果 |
|---|---|
| 行的空白处、头像、名字、第二行、生命、AC | 打开人物卡 |
| 标签 | 按这个标签筛选 |
| ★ / 📌 | 切换收藏 / 置顶（立即生效，提示条可撤销） |
| ⋯ | 打开行尾菜单 |
| 组标题（「全部」视图） | 折叠或展开这一组 |

列表里**不加术语下划线**：整行就是「打开人物卡」，种族、职业名不单独打开资料卡（框架 §6）。

**从人物卡返回时**：列表回到原来的滚动位置，刚才打开的那一行淡金色闪一下。

### 3.5 多选（F）

- 点「选择」进入：每行最前面出现方框，点行任意处 = 勾选或取消；桌面上 Shift + 点击可以连续选一段。
- 底栏：已选 N 人 · 「全选当前结果（N）」· 移到分类 ▾ · 标签 ▾（加 / 去掉，可以新建标签）· 收藏 · 置顶 · 复制 · 删除 ·「完成」。
- 收藏、置顶按钮：选中的人全都已收藏时，按钮变成「取消收藏」；否则是「收藏」。置顶同理。
- 复制：唯一条目的人（具名 NPC）不复制，提示条写「2 个唯一人物没有复制」。
- 删除：进回收站，不再确认；提示条可以撤销。
- 「完成」或 Esc 退出多选；退出时清空勾选。
- 多选只作用于**当前看得见的结果**（经过搜索和筛选后的）。

### 3.6 行尾菜单（⋯）

```
打开
复制一份            （唯一人物灰显：唯一人物不能复制）
移到分类     ▸      队伍 / NPC / 敌人 / 自建…（当前分类打勾）
编辑标签     ▸      勾选已有标签；最后一行「新建标签…」
收藏 / 取消收藏
置顶 / 取消置顶
───────────
删除                （进回收站）
```

菜单用浮层，不会被列表或底栏挡住；Esc 关闭。

  ───────────

### 3.8 从库里选（弹窗内换页）

```
┌ ← 人物 · 从库里选 ───────────────────────────────────────────────
│ [ 怪物 | 具名 NPC ]   [⌕ 搜名字、挑战等级、类型…]   [筛选 ▾]
│ ─────────────────────────────────────────────────────────────
│ [头像] 地精 Goblin            小型类人 · 挑战 1/4 · 怪物图鉴
│ [头像] 地精首领 Goblin Boss   小型类人 · 挑战 1   · 怪物图鉴
│ …
│ ───────────── 选中后在下方展开 ─────────────
│ 地精 Goblin                                           看资料卡 ›
│ 生命 7（卡上的固定值）   AC 15   挑战 1/4
│ 数量  [−]  3  [+]           放进  [ 敌人 ▾ ]
│ 会叫：地精 1、地精 2、地精 3
│                                                   [ 加入 ]
```

- 列表、搜索、筛选复用 L1B 选择器，锁定在怪物与具名 NPC 两类。
- **数量** 1–30；**放进**的默认值：怪物 → 敌人，具名 NPC → NPC；可改。
- **唯一条目**（具名 NPC）：数量锁定为 1。已经在列表里时，「加入」换成「已经在列表里 [打开]」；在回收站里时换成「在回收站里 [恢复]」。
- **生命值**（驾驶员定：取卡上写的固定值）：

| 卡上 | 加进来的人 | 这一页显示 |
|---|---|---|
| 有固定值（如 15，公式 2d8+6） | 当前 = 上限 = 15 | 「生命 15（卡上的固定值）」 |
| 写的是特殊规则（如召唤物「40 + 高于 4 环每环 10 点」） | 上限留空 | 「生命：卡上写『…』，加入后请在人物卡里填」 |
| 原书未给出 | 上限留空 | 「生命：原书未给出，加入后请在人物卡里填」 |

  想掷骰决定生命值，进人物卡自己改。（转换器把 16 个纯数字放错位置、14 个未给出写成 0 的问题，在 G3 续做 §12.6 修。）
- **命名**：同一个库条目第一次只加 1 个时叫「地精」；数量大于 1，或者列表里已经有同一条目的人时，按编号「地精 2、地精 3…」往下排（不带编号的那个算 1）。编号不回收，已有的人不会被改名。
- **加入后**：回到列表（切到加入的那个分类），新行淡金色闪一下并滚到可见处；提示条「已加入 地精 1–3 [撤销]」。
- 「看资料卡 ›」：在弹窗内换页到库的条目详情页，返回时选中状态还在。

### 3.9 空白人物（弹窗内换页）

```
┌ ← 人物 · 空白人物 ─────────────────────
│ 名字   [                    ]       （必填，1–40 字）
│ 放进   [ 当前分类 ▾ ]               （在「全部」里新建时默认「队伍」）
│                         [ 创建并打开 ]
```

- 名字为空时按钮不可点，输入框下写「起个名字」。
- 创建后直接进这个人的人物卡（新人物的种族、职业、背景胶囊显示成虚线「选种族 ›」等）。

### 3.10 分类管理（⋯ → 分类管理，弹窗内换页）

```
┌ ← 人物 · 分类管理 ─────────────────────────────────────
│ 队伍     4 人                                    [改名]
│ NPC      9 人                                    [改名]
│ 敌人     2 人                                    [改名]
│ ─────────
│ 深水小队  3 人                    [改名] [↑] [↓] [删除]
│   删除时就地展开：里面 3 人移到 [ 队伍 ▾ ]   [删除] [取消]
│ [ ＋ 新建分类 ]
```

- 改名就地变输入框；回车保存、Esc 取消。
- 删除自建分类：必须选好里面的人移到哪个分类（默认队伍），确认后删除；提示条可以撤销。

### 3.11 标签管理（⋯ → 标签管理，弹窗内换页）

```
┌ ← 人物 · 标签管理 ─────────────────────────────────────────────────
│ 冒险者  5 人     [改名]  [合并到 ▾]  [把这 5 人移到分类 ▾]  [删除]
│ 商人    4 人     [改名]  [合并到 ▾]  [把这 4 人移到分类 ▾]  [删除]
│   合并时就地确认：把「商人」的 4 人并到「商贩」，删掉「商人」   [确认] [取消]
│   删除时就地确认：从 4 人身上去掉「商人」                       [确认] [取消]
│ [ ＋ 新建标签 ]
```

- 标签名 1–24 字，不分大小写不能重名。
- 「把这些人移到分类」= 一次性把带这个标签的人都移过去，标签保留。
- 每个操作都有提示条撤销。

### 3.12 回收站（⋯ → 回收站，弹窗内换页）

```
┌ ← 人物 · 回收站 ───────────────────────────────────────
│ [头像] 地精 1     原来在：敌人    3 天前删除     [恢复] [彻底删除]
│ [头像] 地精 2     原来在：敌人    3 天前删除     [恢复] [彻底删除]
│ [ 清空回收站 ]
│   清空时就地确认：彻底删除 2 人，不能恢复      [确认] [取消]
```

- 恢复回原来的分类；原分类已删时恢复到「队伍」，并在提示条写明。
- 「彻底删除」逐个就地确认；不自动清空。
- 回收站里的人不出现在列表、收藏条、搜索里，也不给 AI。

### 3.13 提示条与撤销

- 列表里的每个操作**立即生效**（写进当前数据），右下角提示条给「撤销」，8 秒后消失，鼠标停留时暂停计时。
- 例子：「已收藏 盖尔」「已把 3 人移到 NPC」「已删除 地精 1、地精 2」「已加入 地精 1–3」。
- 撤销只还原这一次操作；如果这几个人之后又被改过，提示「已无法撤销」，不强行覆盖。
- 人物卡里的草稿与这里无关：在列表页时没有打开任何人物卡，不存在没保存的草稿。

### 3.14 空状态与加载

| 情况 | 显示 |
|---|---|
| 一个人都没有 | 「还没有人物」+ [从库里选] [空白人物] 两个按钮 |
| 当前分类没人 | 「这个分类还没有人」+ [＋ 新建] |
| 搜索或筛选没结果 | 「没有符合的人物」+ [清除条件] |
| 加载中 | 3 行骨架占位，不显示「加载中…」文字 |

## 4. 视觉风格

## 5. 交互通则

- **键盘**：`/` 聚焦搜索（不在输入框里时）；↑ ↓ 在行之间移动焦点，Enter 打开；多选时空格勾选；Esc 依次关闭菜单、清空搜索、退出多选。
- **触屏**：所有可点的东西不小于 40×40；不靠悬停才出现的按钮。
- **中文输入法**：拼字期间不搜索、不提交、不重建输入框。
- **状态保留**：每个分类各自记住搜索词、标签筛选、滚动位置、组折叠，记在本次打开期间；排序记在战役设置里。从人物卡返回时全部还原。
- **大量人物**：一个分类超过 80 人时用虚拟列表（`src/ui/kit/VirtualList.vue`），分组标题吸顶。
- **可访问性**：分类栏是 tablist；每行是列表项，行内按钮有可读名称（如「收藏 盖尔」「置顶 盖尔」「盖尔的更多操作」）；状态不只靠颜色（开关有实心 / 空心之分）。

## 6. 数据（U6.1）

### 6.1 存储

存进当前数据 `workspace.data`：`people: Person[]`、`categories: Category[]`、`tags: Tag[]`。新增一步迁移（`src/core/migrate.ts` 的框架）：旧数据补齐这三个键，`categories` 写入三个默认分类；高版本数据拒绝读取。Zod 定义放 `src/schemas/people.ts`。

### 6.2 人物 `Person`（外层；人物卡内部的数据由各自 Unit 定义）

| 字段 | 说明 |
|---|---|
| `id` | 唯一 |
| `name` | 1–40 字，去首尾空白；允许重名 |
| `nameEn` | 可选 |
| `avatar` | 可选：网络地址或 `{ $asset }`（玩家上传） |
| `categoryId` | 所属分类 |
| `tags` | 标签 id 数组 |
| `favoriteAt` | 收藏时间；没收藏为空（收藏条按它排） |
| `pinned` | 布尔 |
| `sourceRef` | 从库里选时记录 `{ packId, version, entryId }` |
| `serial` | 同一 `sourceRef` 下的编号；不带编号的为空 |
| `unique` | 来自唯一条目（具名 NPC） |
| `cardType` | `full` 完整卡 / `block` 属性块 |
| `hp` | `{ current, temp, deathSaves }`；上限：属性块取 `data`，完整卡由 R1.1 算或手填 |
| `conditions` | 当前状态与效果（说明与时长） |
| `data` | 人物卡数据（各分页 Unit 定义） |
| `giveAi` | 给 AI 的级别（U4.0 使用，本单元不显示） |
| `trashedAt`、`trashedFrom` | 进回收站的时间与原分类 |
| `createdAt` | 创建时间 |
| `touchedAt` | 修改时间（打开、保存、列表里的改动都更新） |

不写 0 代替「不知道」：不知道的值留空。

### 6.3 分类与标签

- `Category`：`{ id, name, builtin, order }`；默认三个的 `id` 固定为 `party`、`npc`、`enemy`，`builtin: true`。
- `Tag`：`{ id, name }`。

### 6.4 Store：`usePeopleStore`

所有写入经 action；列表操作立即写当前数据，并返回撤销令牌。

| action | 说明 |
|---|---|
| `addFromEntry({ ref, count, categoryId })` | §3.8 的命名、生命值、唯一条目规则；返回新人物与令牌 |
| `addBlank({ name, categoryId })` | §3.9 |
| `duplicate(ids)` | 名字按编号规则；唯一人物跳过并返回跳过名单；生命值回满 |
| `move(ids, categoryId)`、`setFavorite(ids, on)`、`setPinned(ids, on)` | |
| `addTag(ids, tagId)`、`removeTag(ids, tagId)`、`createTag`、`renameTag`、`mergeTag(from, to)`、`deleteTag`、`moveTagged(tagId, categoryId)` | |
| `createCategory`、`renameCategory`、`reorderCategory`、`deleteCategory(id, moveTo)` | 默认分类拒绝删除与挪位置 |
| `trash(ids)`、`restore(ids)`、`purge(ids)`、`emptyTrash()` | |
| `touch(id)` | 打开人物卡时调用 |
| `undo(token)` | §3.13 |

只读：`list({ categoryId, search, tags, sort, dir })`（返回已分组的结果）、`counts()`、`favorites()`、`trashed()`、`rowOf(id)`（行内显示用的摘要：第二行文字、生命、AC、状态；数值来自 R1.1）。

### 6.5 排序键

| 排序 | 键 | 并列时 |
|---|---|---|
| 修改时间 | `touchedAt` | 按名称 |
| 创建时间 | `createdAt` | 按名称 |
| 名称 | `name`（`localeCompare('zh')`），再按 `serial` | — |
| 等级或挑战等级 | 完整卡总等级；属性块挑战等级（1/4 按 0.25） | 按名称；没有等级的排最后 |

## 7. 验收

**单元测试**
- `addFromEntry`：命名与编号（首次 1 个不编号；数量大于 1；已有同条目时续号；已有人不改名）；生命值三种情况；唯一条目（已存在、在回收站）；默认分类。
- 分类：新建、重名拒绝、改名、调顺序、删除并移人；默认分类拒绝删除。
- 标签：改名、合并（人员并集、旧标签消失）、按标签移分类、删除。
- 收藏、置顶、复制（唯一人物跳过）、回收站（恢复到原分类 / 原分类已删时到队伍）、清空。
- 撤销：成功；之后又改过时返回「已无法撤销」。
- 搜索与筛选：各字段命中、多标签同时具备、输入法拼字期间不触发。
- 排序：四种键与并列规则；没有等级的排最后。
- 迁移：旧数据补齐三个键与默认分类。

**e2e**（Chrome 与 WebKit）
1. 从库里加地精 ×3 → 进「敌人」→ 名字是地精 1–3、生命 7 → 撤销 → 消失。
2. 新建空白人物 → 进人物卡 → 返回 → 列表滚动位置还原、该行闪一下。
3. 收藏 → 收藏条出现 → 切到别的分类仍在。
4. 多选两个人 → 移到 NPC → 撤销。
5. 删除 → 回收站 → 恢复 → 回到原分类。
6. 标签筛选两个标签同时具备；清除条件。
7. 新建自建分类 → 删除时把人移到队伍。
8. 唯一 NPC 第二次加入 → 显示「已经在列表里 [打开]」。

**截图**：「全部」视图、某分类、多选、从库里选、三个管理页、空状态 × 深浅色 × 三种宽度，逐张看过。

**驾驶员真机验收**（TauriTavern）：加怪物、加空白人物、收藏、置顶、多选移动与删除、回收站恢复、标签筛选，各走一遍；手机宽度下点按不误触。
