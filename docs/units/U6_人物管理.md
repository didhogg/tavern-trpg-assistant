## 1. 设计说明

- **北极星**：一眼找到人，一下进人物卡；加一批怪不超过 5 下。
- **主角**是人物列表；**主动作**是点行进人物卡；第二位是「＋ 新建」（右上唯一实心按钮）与「模板」。
- **视觉层级**（强 → 弱）：名字 → 生命 → 第二行（职业种族 / 怪物挑战等级）→ 标签、AC → 图标按钮。每行只有名字用衬线字与正文色。
- **四个问题**（人物模块框架 §1）：每个功能先问「玩家会不会主动用？撤销能不能代替？要不要多记一份数据？会不会背着玩家改别的数？」，占两条就删或改简单。§0 表里删掉的都是这样判出来的。

## 2. 真人怎么用（验收按这些走）

| 场景 | 操作 | 点击数 |
|---|---|---|
| 开团前建自己的角色 | 人物 →「＋ 新建」→ 空白人物卡（光标在名字框）→ 填 →「保存」 | 进卡 2 下 |
| DM 开战前加 3 只地精 | 「模板」→ 搜「地精」或筛「怪物图鉴、挑战 0 到 2」→ 点地精看资料卡 → 数量 3 →「加入列表」→ 接着加 2 只狼 → x | 约 5 下 |
| 拿一个怪改成精英 | 「模板」→ 点地精首领 →「编辑后加入」→ 人物卡已填好 → 改生命 →「保存」 | 4 下 |
| 用自己做的怪 | 先在【库 → 我的】用 U11 做好「精英卫兵」→ 人物「模板」里筛「我的资料」→ 加入 | 同上 |
| 跑团中找人 | 收藏条点头像；或切分类、搜名字 | 1–2 下 |
| 打完收尾 | 「选择」→ 勾死掉的地精 →「删除」（进回收站，提示条可撤销） | 4 下 |

### 3.3 状态保留

- 从人物卡回列表：分类、搜索词、标签筛选、排序、滚动位置原样；刚才那一行高亮一下（§9.3 第 3 种）。
- 切分类：搜索词与标签筛选保留（全页一套），滚动回顶部。
- 排序与方向存在战役设置里；当前分类存在战役设置里，下次打开人物页回到它。
- 模板弹窗：关掉再开，类型分页、搜索词、筛选、选中的那一条都还在（本次打开扩展期间）。

### 4.3 区块与控件

| 区块 | 控件 | 规则 |
|---|---|---|
| 页头 | 标题「人物」+「共 N 人」；次按钮「模板」；主按钮「＋ 新建」（窄屏为「＋」，可读名称「新建」）；图标按钮「...」 | 「...」菜单：标签管理、回收站（N）（N 为 0 时写「回收站」） |
| 分类栏 | 分类胶囊（`role=tablist`）；右端文字按钮「编辑分类」 | 顺序：全部 → 队伍 → NPC → 敌人 → 自建分类（按建立先后）；每个写人数；放不下横向滑动（滚轮也能横滑，窄屏右端露出半个胶囊提示还有） |
| 收藏条 | 头像 + 名字，横向一排 | 按收藏先后排；跨分类常驻；点了进人物卡；没有收藏时整条不出现；窄屏不写「收藏」二字 |
| 工具行 | 搜索框；「＋ 标签」；排序下拉 + 方向按钮；「选择」 | 一直显示 |
| 筛选行 | 已选标签药丸（带 x）；「共 N 人」；「清除」 | 有搜索词或标签筛选时才出现 |
| 列表 | 人物行 | §4.4 |

**搜索**：匹配名字、英文名、种族、职业（多职业逐个）、怪物种类名、标签名，不分大小写；只在当前分类里搜；输入停 150 毫秒后搜；中文拼音没打完不搜。
**「＋ 标签」**：可搜索下拉（`Combobox`），列出全部标签和人数；点了加进筛选；已在筛选里的不再列出；多个标签 = 同时具备。行里点标签也是加进筛选。
**清除**：清空搜索词和全部标签筛选，排序不变。搜索框的 x 只清搜索词。
**排序**：修改时间（默认，打开人物卡也算修改）/ 创建时间 / 名称 / 等级或挑战等级；方向按钮切换，可读名称随排序变（从新到旧、从旧到新、A→Z、Z→A、从高到低、从低到高）。置顶的人永远在当前视图最前，置顶的人之间也按当前排序。
**「全部」**：平铺列表，不分组；每行第二行末尾写分类名。

### 4.4 人物行

| 位置 | 内容 | 规则 |
|---|---|---|
| 头像 | 40×50 | 玩家上传的图 → 属性块立绘（焦点裁切）→ 生物类型图标（来自怪物）→ 人形剪影；`EntityAvatar` |
| 名字 | 中文名 + 英文名 | 英文名与中文名相同或为空时不显示；一行放不下截断，悬停显示全名；置顶的人名字后有小图钉 |
| 第二行 | 职业与等级 ・ 种族（多职业「战士 3 ・ 法师 2 ・ 人类」）；来自怪物的写「地精 ・ 挑战 1/4」；「全部」里末尾加 ・ 分类名 | 什么都没有就空着 |
| 标签 | 药丸，可点（= 加进筛选） | 全部显示，放不下换行 |
| 效果 | 「效果：祝福、中毒」纯文字 | 没有就不显示；放不下截断，悬停显示全部；不能点 |
| 生命 | 「12/18」+ 血条 | 临时生命在血条后接一段金色；为 0 就是「0/7」和空血条，不加任何字；上限未知时整块不显示 |
| AC | 「AC 12」 | 未知不显示 |
| ＊ | 收藏开关 | 点了立即生效 |
| ... | 行尾菜单 | §5.1 |

**点哪里做什么**：行空白、头像、名字、第二行、生命、AC、效果 → 进人物卡；标签 → 加进筛选；＊ → 收藏开关；... → 菜单。行内**不加术语下划线**（人物模块框架 §6）。
**键盘**：↑↓ 在行之间移动，Enter 进人物卡，行内按钮用 Tab；`/` 聚焦搜索框；Esc 依次关弹层 → 清搜索 → 退出多选。

## 5. 行尾菜单与标签

### 5.1 行尾菜单（`MoreMenu`）与编辑标签弹层

```
+----------------------------+
| 置顶 / 取消置顶            |
| 移到分类      >            |
| 编辑标签...                |
| 复制一份                   |
+----------------------------+
| 删除（红字）               |
+----------------------------+

+------------------------------------------+
| 盖尔 的标签                              |
| (冒险者 x)  (深水 x)                     |
| [ 输入或选择标签                 ]       |
|   冒险者                 已添加          |
|   深水                   已添加          |
|   商人                                   |
|   新建并添加「旅行商人」                 |
+------------------------------------------+
```

| 菜单项 | 做什么 | 反馈 |
|---|---|---|
| 置顶 / 取消置顶 | 立即生效；这一行移到当前视图最前 / 回到排序位置 | 提示条「已置顶 盖尔」 |
| 移到分类 ▸ | 子菜单列出全部分类，当前分类打勾不可点；点了立即移动 | 不再属于当前视图时这一行消失；提示条「已把 盖尔 移到 NPC」 |
| 编辑标签... | 打开编辑标签弹层 | 见下 |
| 复制一份 | 完全一样的一份（含当前生命、效果），名字按 §7.2 续号 | 新行出现、滚到看得见、高亮；提示条「已复制：盖尔 2」 |
| 删除（红字，放最后） | 移入回收站，不确认 | 行消失；提示条「已移到回收站：盖尔 · 撤销」（6 秒；撤销 = 从回收站恢复） |

**编辑标签弹层**（照旧规格 §1.1.6）：
- 上面是这个人现有的标签（带 x）；下面输入框，候选列出全部标签，打字按名字匹配（不分大小写）；已有的标「已添加」，不能重复加。
- 点候选 = 加上；输入新名字后回车或点「新建并添加『名字』」= 新建标签并加上；同名标签直接复用；去掉首尾空格，空名字不提交。
- 加完清空输入框，候选仍在，可以接着加；点 x 只从这个人身上拿掉（标签本身还在）。
- 改动立即生效，不用保存；Esc、再点一次按钮或点外面关。
- 中文输入法确认候选的回车只完成拼字，不建标签。

## 6. 多选

```
+--------------------------------------------------------------------------------------------------+
| [-] 全选 3 人   已选 2 人     [ 移到分类 v ]  [ 加标签 ]  [ 去标签 ]  [ 删除 ]          [ 完成 ] |
+--------------------------------------------------------------------------------------------------+
| [x] [像] 地精                                             7/7 [##########]  AC 15                |
| [x] [像] 地精 2                                           0/7 [----------]  AC 15                |
| [ ] [像] 地精 3                                           7/7 [##########]  AC 15                |
+--------------------------------------------------------------------------------------------------+
```

- 「选择」进入；多选栏**替换工具行**（搜索、排序那一行），筛选行与分类栏保留。
- 行首出现勾选框；点行任意处 = 勾选或取消（不进人物卡）；行尾 ＊ 和 ... 隐藏。
- 全选框三态（空 / 横线 / 勾）；全选只选当前搜索与筛选的结果，旁边写人数。
- 没选人时四个操作按钮不能点（半透明）。

| 按钮 | 做什么 | 反馈 |
|---|---|---|
| 移到分类 ▾ | 下拉列出分类（当前分类不可点）；点了立即移动 | 提示条「已把 2 人移到 NPC」 |
| 加标签 | 标签弹层（同 §5.1 的输入与候选，没有上面的现有标签区）；点候选或新建 = 给所选的人都加上 | 行内标签同时变 |
| 去标签 | 弹层只列所选的人身上实际有的标签，写「N 人有」；点一个 = 从所选的人身上拿掉 | 同上 |
| 删除（红字） | 移入回收站，不确认 | 提示条「已移到回收站：2 人 · 撤销」 |

- 做完一个操作仍在多选里，勾选保留（已不在当前视图的人自动取消勾选）。
- 改搜索、改筛选、切分类：清空勾选，仍在多选里。
- 「完成」或 Esc 退出多选并清空勾选。

### 7.1 样子

### 7.2 规则

- **它就是 L1B 的选择器**：类型锁定「怪物」「具名 NPC」；分页「全部 / 怪物 / 具名 NPC」写数量；搜索名字、英文名；排序「名称 / 挑战等级」。不另做一套搜索。
- **来源**：范围默认「本存档已启用的包」，可切「全部已安装的包」；来源书列表里官方书和「我的」包在一起，可打字找、可多选。自己做的怪物与具名 NPC（U11）就是这样出现的，人物页面不另存模板。
- **看详情**：点一行 = 选中（主色 8% 浅底 + 左边 3px 竖条），宽屏右栏显示资料卡，窄屏换到资料卡页（「‹ 模板」返回，选中与滚动都在）。资料卡就是库的条目详情页（`EntryDetailPage`），不显示图片与 token。列表里的名字不加下划线（一行只有一种点法）。
- **底部操作栏**（只在选中了一条时出现）：
  - 「编辑后加入」：关弹窗，打开人物卡（新人物，已用这条填好，放进「放进」选的分类）；数量不管用。
  - 「放进」：下拉选分类；默认怪物 → 敌人，具名 NPC → NPC。
  - 「数量」：`[-] 数字 [+]`，1–30，可直接打字；只对「加入列表」有用。
  - 「加入列表」：按数量建人、立即保存；弹窗不关；提示条「已加入 地精、地精 2、地精 3（敌人）」。关弹窗回列表时切到那个分类、新行高亮。
- **套用模式**（人物卡「套用模板」打开）：底部只有一个主按钮「套用到 X」：关弹窗，回人物卡，把这条的数据写进人物卡**草稿**（名字有就不动、空着就填；分类、标签、收藏、置顶不动），「未保存」数加 1，提示条「已套用 地精首领，不满意点撤销」。不弹确认。
- **起名字**：第一个叫「地精」；列表（含回收站）里已有来自同一条目的人时，续号「地精 2」「地精 3」；一次加 3 个且之前没有 = 地精、地精 2、地精 3。号不回收，已有的人不改名。复制一份同样续号。
- **生命值**：卡上有固定值（`hp.average > 0`）→ 当前 = 上限 = 固定值；卡上是特殊规则或原书没给 → 上限空着，进人物卡自己填。不掷骰。
- **具名 NPC**：数值读它 `statblock` 指向的怪物；那个怪物所在的包没装时，「编辑后加入」「加入列表」不能点，旁边写「它的数值所在的书没有安装」。
- **加入后**：卡上的数据**复制**到人物身上（`data.block`），并记下来源（`sourceRef`）；以后库更新不影响已经加入的人。

## 8. 回收站、标签管理、分类管理（弹窗）

### 8.1 回收站

```
+--------------------------------------------------------------------------------------------------+
| 回收站  共 2 人                                                                                x |
+--------------------------------------------------------------------------------------------------+
| [x] 全选 2 人    已选 2 人                                       [ 恢复所选 ]   [ 彻底删除所选 ] |
+--------------------------------------------------------------------------------------------------+
| [x] [像] 地精 2  地精 ・ 挑战 1/4    原来在：敌人    3 天前删除      [ 恢复 ]  彻底删除          |
| [x] [像] 雷纳    NPC                 原来在：NPC     今天删除        [ 恢复 ]  彻底删除          |
+--------------------------------------------------------------------------------------------------+
| 点「彻底删除」-> 列表上方原地出现一行（不弹第二个窗）：                                          |
| 彻底删除 地精 2、雷纳？删了就找不回来。                            [ 取消 ]  [ 彻底删除 ]        |
+--------------------------------------------------------------------------------------------------+
```

- 每行一直有勾选框；全选三态；「恢复所选」「彻底删除所选」按钮上写人数（「恢复 2 人」）。
- 单行「恢复」「彻底删除」只作用于这一行，不连带其他勾选。
- 「彻底删除」（单行或所选）在列表上方原地出现确认行，列出名字（超过 5 个写「地精 2、雷纳等 7 人」）；「取消」收起，勾选保留。
- 恢复回原分类；原分类已删就回「队伍」，提示条写明「原来的分类没了，放进了队伍」。
- 回收站里的人不出现在列表、收藏条、搜索、模板续号以外的任何地方，不交给 AI；不自动清空。空了显示「回收站是空的」，没有按钮。

### 8.2 标签管理

```
+--------------------------------------------------------------------------------------------------+
| 标签管理                                                                                       x |
+--------------------------------------------------------------------------------------------------+
| 新标签 [                        ]  [ 新建 ]                                                      |
+--------------------------------------------------------------------------------------------------+
| 冒险者          5 人                                                       [ 改名 ]   删除       |
| 商人            2 人                                                       [ 改名 ]   删除       |
+--------------------------------------------------------------------------------------------------+
| 点「改名」-> 原地变输入框：商人 [ 旅行商人          ]  [ 取消 ] [ 保存 ]                         |
|           重名时框下写「已经有这个标签了」，不合并。                                             |
| 点「删除」-> 原地：删除标签「商人」？会从 2 个人身上拿掉，人不受影响。     [ 取消 ] [ 删除 ]     |
+--------------------------------------------------------------------------------------------------+
```

- 新建：名字 1–24 字，不分大小写不能重名；重名在输入框下写「已经有这个标签了」。只建标签，不给任何人加。
- 改名：原地变输入框；回车或「保存」生效，Esc 或「取消」放弃；重名同上，不合并。改名后所有人身上、筛选药丸同时更新。
- 删除：原地确认行写影响人数（含回收站里的人）；确认后从所有人身上拿掉，人不受影响，筛选里有它就一并移除。
- 人数为 0 的标签照常列出。

### 8.3 分类管理

```
+--------------------------------------------------------------------------------------------------+
| 分类管理                                                                                       x |
+--------------------------------------------------------------------------------------------------+
| 新分类 [                        ]  [ 新建 ]                                                      |
+--------------------------------------------------------------------------------------------------+
| 队伍            4 人    （默认，只能改名）                                 [ 改名 ]              |
| NPC             9 人    （默认，只能改名）                                 [ 改名 ]              |
| 敌人            2 人    （默认，只能改名）                                 [ 改名 ]              |
| 深水小队        3 人                                                       [ 改名 ]   删除       |
+--------------------------------------------------------------------------------------------------+
| 点「删除」-> 原地：删除「深水小队」？里面 3 人移到 [ 队伍 v ]               [ 取消 ] [ 删除 ]    |
| （空分类直接删，不问）                                                                           |
+--------------------------------------------------------------------------------------------------+
```

- 新建：名字 1–16 字，不分大小写不能重名；建好后分类栏末尾多一个。
- 默认三类（队伍、NPC、敌人）只能改名。
- 删除自建分类：有人时原地出现确认行，选这些人移到哪个分类（默认队伍）；空分类直接删。删掉当前所在的分类时，列表切到「全部」。

## 10. 反馈与文案

### 10.1 每个操作的反馈

| 操作 | 马上看到 | 提示条 |
|---|---|---|
| 点行 / 收藏条 | 换到人物卡 | — |
| 点 ＊ | 星变化；收藏条同时增减 | — |
| 置顶 / 取消置顶 | 行移动 | 「已置顶 盖尔」/「已取消置顶 盖尔」 |

| 加入列表 | 弹窗不关 | 「已加入 地精、地精 2、地精 3（敌人）」 |

| 可读名称 | 收藏 盖尔 / 取消收藏 盖尔 · 盖尔的更多操作 · 按标签「冒险者」筛选 · 移除筛选「冒险者」 · 移除盖尔的「冒险者」标签 |

不出现「实体」「条目 ID」「数据」等开发词。

## 11. 边界、总原则与无障碍

| 情况 | 处理 |
|---|---|
| 名字很长 | 截断，悬停显示全名；收藏条最多 6 字 |
| 重名 | 允许；靠头像、第二行、编号区分 |
| 人很多 | 普通列表，不用 `VirtualList`、不改它；执行时用 500 人的夹具实测滚动，卡顿写进报告由规划者定 |
| 自建分类很多 | 分类栏横向滑动 |
| 来源包被卸载 | 人照常显示（数据已复制）；点人物身上的下划线名字时资料卡提示「这个条目所在的扩展包没有安装」 |
| 没有当前战役 | 列表区显示「先开一个战役」+ 去开局向导的主按钮（沿用首页做法） |
| 新人物没保存就离开 | 不存在，不弹框（人物模块框架 §1） |

**总原则**（规格没写到时照这个定，并写进报告）：一个操作一个入口；能撤销就不确认，不能撤销才原地确认；不显示空信息；不背着玩家改别的数；不加新颜色、新动效、新组件。

**无障碍**：分类栏 `tablist`/`tab` + `aria-selected`；列表 `list`/`listitem`；开关按钮 `aria-pressed`；提示条 `aria-live="polite"`；状态不只靠颜色（星实心 / 空心）；所有图标按钮有可读名称（§10.2）；中文输入法拼字期间不搜索、不提交。
