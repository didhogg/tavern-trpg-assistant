## 0. 北极星与层级 〔已被 U5R 视觉修订 §1 取代，见该节〕

- **北极星**：翻开一页冒险者名册——先认出这个人，再看还剩多少血，然后是六项属性，最后才是各种设定。
- **主角**：A 基本信息卡（头像、名字、生命）。第二层：B 属性卡。其余（C、D、分页）安静。
- **主动作**：点一个数字去骰盘（先攻、属性、豁免、技能）。次动作：点 ✎ 改生命。页面里**唯一的实心主按钮**是顶栏「保存」。
- **层级（强 → 弱）**：头像 → 名字 → 「职业 等级 · 种族」→ 生命数字与红条 → 六个检定方框 → AC 与读数 → 豁免 → 法术位、力竭、效果 → 档案区 → 图标按钮。
- **灰度结构**：本文 §2 的灰度图是视觉验收的结构基线；先在灰度下读得通，颜色只做强调（`--primary` 酒红、`--gold` 金、`--hp` 红、`--ok` 绿、`--danger`）。
- **视觉上删掉的**（先删再给）：每个小块各自的渐变、投影；每个属性卡不同的强调色；格子里的装饰图案；图标按钮的描边底色（平时无底无边，悬停才出现边）；整页第二个实心按钮；任何「示例」「制作说明」文字。

## 1. 设计变量 〔已被 U5R 视觉修订 §2 取代，见该节〕

只用 `tokens.css` 已有变量；**不新增颜色**。

| 用途 | 变量 |
|---|---|
| 页面底 | `--paper` |
| 卡片（A、B、C、F 栏卡）、输入框、弹窗内容 | `--card` |
| 档案区、顶栏迷你条、抽屉标题栏、分页标签托盘 | `--panel` |
| 分隔线、边框 | `--line`（1px）；方框数字用 `--frame` |
| 正文、次要文字 | `--ink`、`--ink-2` |
| 主色（选中、实心主按钮、熟练、法术位实心） | `--primary`、`--primary-ink` |
| 金（灵感有、临时生命、专精、新加入高亮） | `--gold` |
| 血条 | `--hp`，底槽 `--hp-track` |
| 头像外框 | `--frame` |
| 成功（死亡豁免） / 失败 / 未保存 | `--ok` / `--danger` / `--unsaved` |
| 阴影 | `--shadow-card`、`--shadow-card-hover`、`--shadow-float` |
| 圆角 | 卡片 12；抽屉无圆角；输入与方框 8；药丸 999；小控件 6 |
| 字体 | 名字、数值、栏目标题：`--font-serif`；其余 `--font-sans`；所有数字 `tabular-nums` |

- 字号：正文 ≥ 14px；辅助文字 ≥ 12px；**不用 9–11px**（oil-ui 可读性）。
- 间距 4px 网格；同一种关系同一种间距：卡片内部 16，卡片之间 12，卡片内子区块之间 12，药丸之间 8。
- 深色模式沿用 `tokens.css` 的深色值，不单独调色；所有状态不只靠颜色（形状、文字、图标同时区分）。

## 12. 响应式与无障碍

- 检查宽度：390、900、1440（窗口内部宽度）；≤ 480 为窄屏；481–1023 中宽；≥ 1024 宽屏（开发规范 §5.2）。
- 触屏点击区 ≥ 44px（图标按钮可视 32、点击区 44；圆点可视 18–20、点击区 32 起，行间距保证相邻圆点不误触）。
- 每个图标按钮有可读名称；圆点、星、圆圈有「第 N 个、当前状态」的名称；方框数字读作「力量检定 负 1」。
- 键盘：Tab 顺序按视觉阅读顺序（顶栏 → A → B → C → D → E → F）；焦点环 2px `--primary`、偏移 2；抽屉、弹层打开时焦点进入，关闭后回到触发处。
- 颜色之外的区分：熟练用形状（环、半实、实心、菱形）；死亡豁免用「成功」「失败」文字；灵感用实心 / 空心星；未保存用文字加圆点；力竭等级用文字与数字。
- 深色模式：所有颜色走变量；检查 `--frame`、`--hp`、`--gold` 在深色下的对比。

## 13. 验收

### 13.1 截图（深浅色 × 1440 / 900 / 390，逐张看过；用有头像的玩家角色、有立绘的真实怪物（地精、地精头目）、没有图片的人各至少一个）

4. B 属性卡：宽屏一行六张、窄屏 3 × 2；有上限截断（上限 20）的一张。

### 13.2 指标

- **一眼看清**：1440 宽下，不放大能在 1 秒内读出：名字、「职业 等级 · 种族」、生命 当前 / 上限、AC、六个检定值；390 宽下同样。
- **对齐**：六张属性卡等高、等宽；读数四格等宽；A 卡内所有数字右对齐 / 居中规则一致；没有数值时栏位保留不跳动。
- **可读**：正文 ≥ 14px、辅助 ≥ 12px；中文标题与说明在 390 宽不重叠、不出现行末孤字。
- **图标**：同一界面图标同一套（Phosphor Regular）、同一描边粗细；两个图例骰子图标一模一样。
- **颜色**：深浅色都不出现新色相；不靠颜色单独表达状态。
- **独立评审**：交付前由一个没看过过程的评审者只看截图打分（10 分制），8 分以下按意见改到 8 分以上，评分与改动写进报告。
- 功能 e2e 全部仍过（`people`、`library`、`upgrade`、存档、新增 `card`）；视觉改动不改测试断言。
