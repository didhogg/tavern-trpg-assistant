## 2. 色盘（取代视觉 §1 的颜色用途；**不新增色相**）

只用 `tokens.css`：`--paper --panel --card --line --frame --ink --ink-2 --primary --primary-ink --gold --hp --hp-track --danger --unsaved`。**`--ok` 不再用于详情页。**

| 用途 | 颜色 |
|---|---|
| 页面底 | `--paper`；卡片、输入框、弹窗内容 `--card`；档案三卡也是 `--card`（**不再用 `--panel` 大底块**）；`--panel` 只用在：标签栏底托、悬停底、只读数字单元格、迷你条 |
| **主色 `--primary`（酒红）= 选中、可操作的强调、熟练、法术位实心、生命骰实心、死亡豁免成功、主按钮、红框高亮（点数已分配）** | |
| **金 `--gold`** | 只给：临时生命、灵感「有」、专精菱形、经验 / 挑战徽章底、属性值被上限截断的小点、新加入药丸的 1.2s 底、头像内框线。**不给血条以外的大面积** |
| 血条 | 填充 `--hp`；临时段 `--gold`；低于 1/4 填充改 `--danger` |
| 死亡豁免 | **成功 = `--primary` 实心；失败 = `--ink` 实心；空心 = 2px 环 `--ink-2` 60%**；旁边「成功」「失败」文字照写（不靠颜色） |
| 状态、效果药丸 | **全部同一款**（`--card` 底、1px `--line`）；**不用红底 / 红字区分状态**；类别靠分行与小字，不靠颜色 |
| 未保存 | `--unsaved` 圆点 + 文字 |
| 错误 | 框下红字 `--danger`；输入框红边 + `--danger` 10% 底 |

> 灰、黑圈乱入（视觉清单 7）的根因：成功 / 失败各占一种新颜色 + 圆圈有的实心有的描边。本文用「形状 + 文字」承担区分，颜色只剩酒红、墨色、金三种。

## 5. 间距与网格（取代视觉 §2.1 的数值）

- 4px 网格；**同一种关系同一个间距**：卡内边距 16；卡与卡之间 **14**（宽屏与手机一致，不再有桌面端 B/C 之间的大空白）；卡内分区之间 12；药丸之间 8。
- 页面（宽屏 ≥ 1024）：`身份卡 minmax(340px, 400px) | 右列 1fr`，`align-items: stretch`（**底边对齐**）；右列内战斗卡与属性卡 14 间距；右列高度由内容决定，身份卡跟随右列高度，**生命区贴身份卡底部**（`margin-top: auto`），中间留白靠头像尺寸（96×120→宽屏加大到 104×132）与行距吃掉，不放占位内容。
- 档案三卡：`repeat(3, minmax(0, 1fr))`（容器宽 ≥ 980），否则单列；**最小高度 110**，三卡等高；**宽屏内容区最大宽 1240**（视线不要横跨整个屏幕）。
- 页面内边距：宽屏 20，其余 16；底部留白 ≥ **96 + 安全区**（让位悬浮按钮，§7）。
- 容器查询阈值（组件按**所在容器宽**折叠，不按窗口宽）：≤ 980（档案单列、A / 右列单列）、≤ 760（顶栏精简）、≤ 640（读数 2×2、属性 3×2、技能收起、生命编辑三框竖排）。

## 7. 悬浮骰子按钮（FAB）与页面底部（驾驶员问题 4）

## 11. 动效（沿用视觉 §11 的 8 种，**不新增**；补充两点）

- 悬停气泡出现：`opacity 0→1`，120ms（`prefers-reduced-motion` 直接显示）。
- 弹窗开 / 关：居中弹窗 `opacity + translateY(8→0)` 160ms；手机底部整页 `translateY(100%→0)` 200ms。
- 骰盘掷骰：结果卡 `opacity 0→1` 与骰面数字滚动 ≤ 460ms（沿用基础版）；其余切换无动画（**选项目不重排所以没有位移动画**）。
- 点数池放入：被放入的行外圈 `box-shadow` 由无到 2px `--primary` 160ms；池里数字 opacity 1→.45 120ms。
