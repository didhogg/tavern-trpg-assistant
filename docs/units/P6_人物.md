## 2. 怎么算做完

**三种状态**：○ 没做 · ◐ 做了，真机没点过 · ● 真机像玩家点通了（写日期 + 截图路径）

**每一项的做法**
```
改代码 → make test-changed → 相关的单个 e2e（Chrome + WebKit，perl alarm 限时）
→ 装真机 → 用遥控工具在 TauriTavern 里像玩家一样点 → 截图、核对人物数据和存档
→ 点不通：自己找原因修，修完再点；点通才标 ●
```

**每一页的做法**：整页的项都 ● 后，汇报驾驶员（ASCII + 大白话 + 截图路径 + 点了什么、没点什么）→ 驾驶员验收 → 提交、推送、装真机（驾驶员常驻规则：每个单元做完都推送）。

**真机固定的测试人**（每页都用这几个，从空白卡建起）：
- 德鲁伊（2 级选子职业）
- 战士（3 级选子职业）
- 牧师（1 级选子职业）
- 法师（施法职业，看法术页）
- 页头 / 职业页另外走：兼职、降级、重选一级、新建自制、窄屏

**速度**：点了之后 1 秒内有画面反馈。作者自己的大步骤（例如「填充法术书」）单独记时间，不算超时。

**真机怎么驱动**：见 `docs/handoff/P6-R_页头两单元_交接.md` §8（装真机、tauri-pilot、脚本规矩）。写操作前先核对当前聊天和战役；确认写入成功后才点撤销。
