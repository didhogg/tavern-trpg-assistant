# L1B 全库搜索与资料阅读 · 单元蓝图

状态：草案，待驾驶员审批。

## 0. 范围

- 全库搜索：在已安装的全部内容包里按名称与正文查找条目，带类型、书籍与各类专属筛选。
- 选择器：同一个搜索页带锁定筛选，供人物、背包等界面选择法术、物品、专长、可选特性等（U5、U6 复用）。
- 条目详情页的阅读规则：规则 / 介绍分区、结构化字段的人话显示、版本与重印、去重复。
- 随机表术语与随机表页：正文里的可掷表显示为可点术语，点开随机表页，可以掷一次。
- 对比页的人话显示。

数据来自 D1.1b（`docs/handoff/D1.1b_数据收尾_交接.md` §5）。控件、浮层、窄屏、键盘遵守开发规范 §5.3–§5.5 与 L1 §4 的统一做法：下划线术语、弹窗内换页不叠加、「⋯」为下拉菜单。

## 1. 每屏的主角与主动作

| 界面 | 主角 | 主动作 |
|---|---|---|
| 全库搜索 | 结果列表 | 打开条目 |
| 筛选页 | 当前类型的筛选项 | 完成（显示 N 条） |
| 选择器 | 结果列表 | 选择 / 确定 |
| 条目详情 | 条目内容 | 无（查看；有多个版本时切换版本） |
| 随机表页 | 表格 | 掷一次 |

## 2. 入口

- 库页头右侧，「⤓ 导入文件」左边加「⌕ 全库搜索」；三个分段都显示。库页内按 ⌘K / Ctrl+K 也能打开。
- 包详情弹窗里的搜索框仍只搜本包；结果为空时最后一行显示「在全库中搜索『…』」，点击后弹窗换成全库搜索页，带上关键词。
- 选择器的入口由使用它的单元定义，本单元只定义选择器本身（§6）。

## 3. 条目详情页

### 3.1 结构

```
┌ ‹ 全库搜索    气                                             [PHB ▾]   ✕ ┐
│ 职业特性 · 武僧 2 级 · 玩家手册 第 76 页 · Ki                                │
│ ─────────────────────────────────────────────────────────────────────────── │
│ 使用次数    气点 = 武僧等级（2 级 2 点 … 20 级 20 点）· 短休或长休后恢复      │
│ 包含        ‗疾风连击‗ · ‗坚强防御‗ · ‗疾步如风‗                              │
│ 豁免难度    8 + 熟练加值 + 感知调整值                                       │
│                                                                             │
│ 你的训练使你能够驾驭名为气的神秘能量……                                       │
│ ……                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **标题行**：名称（带 `nameSuffix`）。右侧在条目有 `versionGroup` 时显示版本下拉 `[PHB ▾]`，列出同组各版本的书名，切换时在同一页替换内容。
- **副标题行**（淡色、一行）：类型 · 归属（如「武僧 2 级」）· 书名 第 N 页 · 英文名。不再显示 `summary`；`summary` 只用于列表行。
- **提示条**（有才显示，位于副标题下）：
  - 被重印：「已被《魔邓肯巨献：多元宇宙的怪物》重印 · ‗查看新版‗」
  - 非玩家选项：「NPC 种族，不能用于建卡」
  - 流程说明：「这是升级时的一个步骤，由升级向导完成；人物卡上不单独显示」
- **分区**：条目有 `lore` 时，副标题下出现分段 `[规则] [介绍]`，默认「规则」；没有 `lore` 时不显示分段。
- **事实栏**：标签列宽固定、右对齐到同一条线；值可换行；引用是下划线术语；数量多的列表用「·」分隔，超过 3 行折叠为「展开全部（N）」。
- **正文**：段落之间空一行；小标题加粗；列表带圆点；表格放在自己的横向滚动容器里，表头固定。
- **复述块**：正文里 `restated: true` 的列表默认收起为一行「原文要点 ▸」，点击展开。

### 3.2 结构化字段的人话写法

| 字段 | 显示 |
|---|---|
| `uses` | 「每次长休 2 次」「次数 = 熟练加值 · 长休后恢复」；随等级变化时写「3 级起 3 次」 |
| `scaleValue` | 职业页事实栏：「狂暴次数：1 级 2 · 3 级 3 · 6 级 4 · 12 级 5 · 17 级 6 · 20 级 无限」 |
| `slotsByLevel` | 职业表里的「1环」…「9环」列；没有法术位的格子显示「—」 |
| `trait` | 「获得：重甲熟练」「从 运动、威吓、察觉 中选 2 项」 |
| `itemChoice` | 「3 级：从 ‗巨像屠夫‗ · ‗巨人杀手‗ · ‗灭族者‗ 中选 1 项」；按 `optionKind` 选的写「选 2 个 ‗魔能祈唤‗」 |
| `prerequisite` | 「需要：魔契师 5 级 · 已学会 ‗魔能爆‗」 |
| `effects` | 「生命值上限 +2 × 角色等级」「对毒素伤害有抗性」；`note` 类原样显示文字 |
| `optional: 'tce-ocf'` | 「可选职业特性（需在本存档开启 ‗可选职业特性‗）」，替换时加「替换 ‗宿敌‗」 |
| 公式 | 用中文说出来：`@prof` →「熟练加值」，`@mod` →「施法属性调整值」，`@classes.monk.levels` →「武僧等级」 |
| 编号 | 一律换成中文名；查不到中文名时显示「未知（编号）」并计入诊断，不显示原始编号串 |

### 3.3 禁止出现在可见文字里

- 花括号、`{{`、`@` 公式、`|` 来源代码、条目 id、英文编号（`AF`、`EI`、`MV:B` 等）
- `undefined`、`null`、`NaN`、`[object Object]`、JSON
- 「中文English」粘连
- 同一信息在摘要、事实栏、正文三处重复

e2e 对每个类型的样本逐页检查以上内容（§9）。

## 4. 随机表

### 4.1 正文里的随机表术语

```
│ 你把手伸进袋中，取出一颗豆子……掷 ⚄‗豆袋效应表（d100）‗ 决定效果。          │
```

- `tableRef` 块显示为一行：骰子图标 + 下划线术语「表名（骰子）」。点击后在同一弹窗内换到随机表页，「‹」回到原条目原位置。
- 不可掷的表照常以表格显示在正文里。

### 4.2 随机表页

```
┌ ‹ 豆袋    豆袋效应表                                                       ✕ ┐
│ 随机表 · d100 · 城主指南 第 152 页 · 来自 ‗豆袋‗                              │
│                                                        [ ⚄ 掷一次 ]          │
│ ┌ 掷出 17 ───────────────────────────────────────────────────────────────┐ │
│ │ 长出 ‗树人‗。此树人有 50% 的概率属于混乱邪恶并发起攻击。                  │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
│  d100     效应                                                               │
│  01       长出 5d4 个毒蕈……                                                  │
│  02–10    喷出一股间歇泉……                                                   │
│▸ 11–20    长出 ‗树人‗……                       ← 掷中的行高亮                │
│  …                                                                           │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 副标题：随机表 · 骰子 · 书名页码 · 「来自 ‗所属条目‗」或「所在章节：‗章节名‗」。
- 「掷一次」用现有骰子核心掷表的骰子，结果卡显示点数与该行内容，表中对应行高亮并滚入视野；再掷替换结果。结果只在本页显示，不发送、不写日志。
- 行里有「再掷 ‗某表‗」（`then`）时，结果卡里出现「⚄ 继续掷 ‗某表‗」，点击换到那张表并自动掷一次。
- 牌组表：结果卡显示该牌的说明；表格每行可展开看说明。
- 表头固定；行内引用可点。窄屏每行变成两行：第一行骰点，第二行内容。

## 5. 全库搜索

### 5.1 宽屏

```
┌ 全库搜索                                                                     ✕ ┐
│ ⌕ [ 火球                                                     ]   [ 筛选 · 2 ] │
│ [全部 312] [法术 18] [物品 9] [怪物 4] [特性 6] [规则 2] [随机表 1] …   ‹ ›    │
│ (3 环 ✕) (塑能 ✕)                                                 清除筛选     │
│ ─────────────────────────────────────────────────────────────────────────────── │
│ 名称匹配                                                                       │
│  ‗火球术‗                法术 · 3 环 · 塑能 · 法师、术士            PHB        │
│  ‗延迟爆裂火球‗          法术 · 7 环 · 塑能 · 法师、术士            PHB        │
│ 正文匹配                                                                       │
│  ‗火球项链‗              物品 · 珍稀 · 奇物                        DMG        │
│     …可以取下一颗珠子投掷，使其如 3 环【火球】术般爆炸…                        │
│ ─────────────────────────────────────────────────────────────────────────────── │
│ 共 18 条 · 在本存档已启用的包中                       排序 [相关度 ▾]         │
└────────────────────────────────────────────────────────────────────────────────┘
```

- 打开即聚焦搜索框；输入停顿 150ms 后更新结果。空搜索框时显示按类型浏览（按名称排序）。
- **搜索范围**：名称、英文名、关键词、正文。结果分「名称匹配」「正文匹配」两组；正文匹配显示一行命中片段，命中词加粗。
- **类型标签**：一行可横向滚动，带数量；数量为 0 的类型不显示。选中一个类型后，「筛选」页只出现这个类型的专属筛选。
- **已选筛选**以可删除的标签显示在类型标签下，「清除筛选」清空全部（不清搜索词）。
- **结果行**：名称（下划线术语）、类型 · 2–3 个关键事实、书名缩写角标。同一 `versionGroup` 合并为一行，名称后显示「+N 版本」，打开后用标题行的版本下拉切换；被重印的旧版默认不出现。
- **底栏**：数量、范围（「本存档已启用的包」或「全部已安装的包」，没有当前存档时为后者）、排序（相关度 / 名称 / 环阶或挑战等级）。
- 点结果在同一弹窗内换到条目详情页；「‹ 全库搜索」返回时保留关键词、筛选与滚动位置。
- 键盘：↑↓ 移动、Enter 打开、Esc 先清空搜索框再关闭弹窗。

### 5.2 筛选页（弹窗内换页）

```
┌ ‹ 全库搜索    筛选 · 法术                                                    ✕ ┐
│ 范围      (●) 本存档已启用的包   ( ) 全部已安装的包                            │
│ 书籍      [PHB] [XGE] [TCE] [BMT]                         ← 可多选的药丸       │
│ 环阶      [戏法] [1] [2] [3] … [9]                                             │
│ 学派      [防护] [咒法] [预言] [惑控] [塑能] [幻术] [死灵] [变化]              │
│ 职业      [可搜索下拉 ▾]                                                       │
│ 其他      ○━ 仪式    ○━ 专注                                                   │
│ 显示      ○━ 已被重印的旧版    ━● 非玩家选项                                   │
│                                                                                │
│                                    [ 清除 ]   [ 完成 · 显示 18 条 ]           │
└────────────────────────────────────────────────────────────────────────────────┘
```

- 每改一项，「完成」按钮上的数量立即更新。
- 各类型的专属筛选：

| 类型 | 筛选 |
|---|---|
| 法术 | 环阶、学派、职业、仪式、专注、伤害类型、豁免属性 |
| 物品 | 类别、稀有度、需同调、魔法 / 普通 |
| 怪物 | 挑战等级区间、生物类型、体型 |
| 职业 / 子职业 | 所属职业 |
| 种族 / 亚种族 | 体型、可作为玩家选项 |
| 特性 | 来源（职业 / 子职业 / 种族 / 背景 / 专长）、所属职业、可选特性种类、等级区间 |
| 专长 | 有属性提升、有前置条件 |
| 随机表 | 骰子、种类（掷表 / 姓名 / 出身 / 牌组） |
| 地点 | 种类（位面 / 地区 / 城镇 / 地点）、上级地点 |
| 神祇 | 神系、阵营、领域 |
| 全部 | 只有范围、书籍、显示 |

### 5.3 窄屏（≤ 480px）

整页显示。搜索框与「筛选」按钮固定在顶部，类型标签在其下横向滚动；结果行两行：第一行名称与书名角标，第二行类型与关键事实；正文片段为第三行。筛选页为整页，「完成」固定在底部。

### 5.4 状态

| 状态 | 显示 |
|---|---|
| 正在建立索引 | 结果区显示骨架行与「正在整理 5,985 条资料…」 |
| 没有结果 | 「没有找到『…』」；有筛选时给「清除筛选再试」；范围是本存档时给「改为在全部已安装的包中搜索」 |
| 没有安装任何包 | 「还没有安装资料」与「去扩展」按钮 |

## 6. 选择器

同一个搜索页，由调用方传入：标题、锁定的筛选、可选数量、不可选的判断。

```
┌ 选择魔能祈唤 · 魔契师 5 级 · 已选 1 / 2                                      ✕ ┐
│ ⌕ [                                                          ]   [ 筛选 ]     │
│ (🔒 可选特性：魔能祈唤) (🔒 符合前置条件)                                       │
│  [✓] ‗苦痛爆破‗                需要 ‗魔能爆‗                      PHB          │
│  [ ] ‗恶魔之视‗                                                   PHB          │
│  [ ] ‗刃之渴求‗  不可选：需要 刃之契约                              PHB          │
│ ─────────────────────────────────────────────────────────────────────────────── │
│                                             [ 取消 ]   [ 确定 · 已选 1 ]       │
└────────────────────────────────────────────────────────────────────────────────┘
```

- 锁定的筛选带 🔒，不能删除。「符合前置条件」可由调用方设为可关闭；关闭后不可选的行仍显示原因。
- 单选时点行即选中并返回；多选时用勾选框，达到上限后其余行变灰。
- 点名称（下划线术语）在同一弹窗内看详情，「‹」回到选择器并保留已选。

## 7. 版本与重名

- 同一 `versionGroup` 在搜索结果合并为一行；在详情页用版本下拉切换。默认显示最新版本（被重印的旧版排在最后）。
- 不同书的同名条目（不同组）都显示书名角标；同书同名已由数据加 `nameSuffix` 区分。
- 特性名常重复（「额外攻击」「施法」），结果行的关键事实里写归属：「武僧 5 级」「战士 5 级」。

## 8. 对比页

- 字段名用中文标签（与事实栏同一张标签表）；值用 §3.2 的人话写法；正文差异按段落并排显示，不同的段落加底色。
- 不出现 JSON；无法转成人话的字段写「（结构不同，见详情）」。

- 单元测试：§3.2 每种字段的人话写法；编号查不到中文名时的退路；搜索打分（名称优先于正文、版本合并、重印隐藏）。
- e2e（Chrome + WebKit）：
  - 全库搜索：输入、类型标签、筛选页「完成」数量、已选标签删除、返回保留状态、键盘操作、窄屏。
  - 选择器：锁定筛选不可删、上限、不可选原因、看详情后返回保留已选。
  - 随机表：正文术语跳转、掷一次高亮对应行、「继续掷」、返回原位置。
