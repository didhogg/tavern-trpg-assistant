# U5 人物卡 · 单元蓝图

状态：草案（U5.1 待驾驶员定稿；U5.2 起在各自开工前补全）

## 0. 范围与归属

本单元负责：人物详情页（顶部与分页导航、各分页）、完整卡与属性块的数据定义与展示编辑、头像。人物的创建与列表由 U6 负责（`docs/units/U6_人物管理.md`），派生数值由 R1.1 负责（`docs/units/R1_规则引擎.md`）。

按小 Unit 逐个交付，每个交付经驾驶员验收后再做下一个：

| 小 Unit | 里程碑 | 交付 |
|---|---|---|
| U5.1 详情顶部 | M5 | §2 详情页壳、顶部、分页导航、生命值快速调整、编辑开关、`⋯` 菜单；列表行点击进入详情 |
| U5.2 数值 | M5 | 数值分页：属性来源与调整、技能与豁免熟练、AC 算法选择、生命值与生命骰、感官与速度、抗性与状态防御（覆盖与来源） |
| U5.3 行动（只展示） | M5 | 行动分页：列出攻击、动作；点击行动打开骰盘预填（M6 前只显示，不结算） |
| U5.4 背包 | M5 | 物品、装备、货币、容器、转移 |
| U5.5 法术与资源 | M5 | 法术位、法术列表与准备、职业与种族资源 |
| U5.6 特性与效果 | M5 | 当前状态与效果（含持续时间与专注）、特性列表 |
| U5.7 背景与笔记 | M5 | 身份与角色扮演资料、给 AI 的说明、笔记 |

依赖：U6.1 的人物数据；R1.1 的 `derive.summary`；U6.2 提供列表与进入详情的入口；U1 提供外壳与弹窗宿主。

本单元读取：当前数据里的人物（`people`）、`derive.summary`、已启用扩展包的条目（职业、种族、物品、法术、状态）。本单元写入：人物的 `data`、`hp`、`conditions` 等字段（经 `usePeopleStore.update`）。

## 1. 约定

1. **没有"保存人物"按钮**：所有修改立即写入当前数据，页头出现"● 保存"，由 U2 统一存档。
2. **查看 / 编辑**：详情默认是"查看"状态——干净、不出现输入框，没有内容的区块整块隐藏；点顶部"编辑"进入编辑状态，数字变为输入框并出现"＋"类入口。**生命值快速调整与状态增删在两种状态下都能用**（它们是游戏进行中的操作，不是改资料）。
3. 摘要不单独存储：详情各处的数字都来自同一份人物数据，经 R1.1 计算，编辑后各处即时一致。
4. 手动覆盖的数值带"手动"标记，点"恢复自动"清除覆盖。
5. 每屏一个主角、一个主动作：详情顶部的主角是生命值方块，主动作是调整生命值。
6. 窄屏（≤ 480px）：详情是整页（标题栏左侧"‹"返回人物页）；宽屏在人物页内替换列表，左上角"← 人物"返回，返回后列表的滚动、筛选、展开状态保持（U6.3）。
7. 名称与数值的详情一律用下划线术语 + 详情弹窗（点属性格是"计算来源"小面板，见 §2.4）。

### 2.4 顶部各部分的行为

**标题行**
- 名称（24–30px 衬线粗体）；完整卡的第二行写"职业 等级 · 种族 · 背景 · 阵营"，缺项直接省略，不写"未填写"；属性块写"体型类型（标签）· 阵营 · CR（经验）"。
- `★你`、`📌`：点击切换（带文字提示"设为玩家角色"、"常驻"），`★` 只在队伍成员上出现，同一队伍设为第二人时原来的自动取消并提示。
- 身份条是三个下拉：身份、队伍、随行 / 留守；改成其他身份时先在原处显示一行确认（"将移出博德小队，标签保留　[取消] [确认]"），确认后提示条给"撤销"（U6 §2.5）。
- 完整卡处于草稿时标题行下显示"待填 N 项"徽章，点开就地列出待填清单，点某一项跳到对应分页的对应位置（U5.2 起可用；此前清单只读）。

**生命值方块**
- 数字格式"当前 / 上限"，临时生命值用金色"临时 +N"，条为红棕色，低于一半变暗，条右侧接一段金色表示临时生命值；0 时写"倒地"（完整卡）或"倒下"（属性块）。
- `[− 伤害]` `[＋ 治疗]` 点击后就地展开：

```
│ ┌ 生命值 ──────────────────────────────┐ │
│ │  12 / 18   临时 +3                    │ │
│ │  [  7  ]  [ 伤害 ] [ 治疗 ] [ 临时 ]  │ │
│ │  先扣临时：+3 → 0，再扣当前：12 → 8   │ │
│ └───────────────────────────────────────┘ │
```

  - 输入框自动聚焦；回车 = 最近点开的那个按钮（默认伤害）；预览文字来自 R1 §2.6 的 `steps`；Esc 或再点方块收起。
  - 确认后数字滚动，提示条"盖尔 生命值 12 → 8，临时 3 → 0　[撤销]"（8 秒）。
  - 扣到 0（完整卡）：预览写"生命值 0 · 倒地 · 开始死亡豁免"，方块下出现死亡豁免"成功 ○○○　失败 ○○○"，点圆点设置（再点当前最高已选点清空该组，三个成功稳定、三个失败死亡）；治疗到 ≥ 1 时自动清除。
  - 属性块扣到 0：显示"倒下"，不出现死亡豁免。
  - 此操作是手动改数字，不掷骰；M6 的掷骰卡确认时调用同一个 R1 函数。
- 编辑状态下，"上限"变为可输入的覆盖值（带"手动"与"恢复自动"）。

**AC、先攻、速度、熟练**：四个只读小格，点开显示"计算来源"小面板（R1 的 `sources`，如"皮甲 11 ＋ 敏捷 2"），在编辑状态下可改覆盖值；AC 的算法选择在 U5.2。

**被动值**：察觉、洞悉、调查三项（完整卡）；属性块写数据里的被动察觉。

**六项属性**：宽屏一行六格，中宽三列两行，窄屏三列两行。每格：属性名、调整值（衬线大字）、属性值（小字）、豁免加值（熟练用 ● 标出，状态不只靠颜色）。点格弹出"计算来源"小面板；M6 起同一位置增加"掷这个属性检定"与"掷豁免"。编辑状态下属性值与豁免熟练可直接改。

**状态**：横向一行药丸，无分类；点文字就近展开说明、来源、剩余时间（U5.6 完成持续时间与专注）；× 在原处展开"保留 / 取消"；`＋状态` 打开可搜索下拉（来自已启用扩展包的状态条目，也可输入自定义名称）。无状态时显示"当前无状态"和 `＋状态`。

**法术位**：只列出人物拥有的环阶；点实心格用掉一个，点空心格恢复一个；契约位单列并标环阶；没有任何法术位时整行隐藏。点标题进入"法术"分页。

**`⋯` 菜单**：存为模板（U5.7 之后）、复制一个、移入回收站、给 AI ▾（自动 / 只给名字 / 完整 / 不提供）。

**分页导航**：完整卡七个（行动、法术、背包、特性、数值、背景、笔记）；属性块三个（行动、特性、笔记）；名称与顺序固定；各分页分别保留滚动与展开状态；U5.1 阶段所有分页显示"本分页尚未开放"，只有导航可用。

### 2.5 从列表进入与返回

- 列表行点击空白处或名字进入；行内的标签、"⋯ 更多"、状态药丸各自响应，不连带进入。
- 返回人物页后：滚动位置、搜索、筛选、排序、分组展开、所在分页都保持原样；刚编辑过的行不跳动。
- 在详情里把人物移入回收站、改了身份，返回时人物页切到对应的新分页并定位到该行（身份变化）或直接回到列表（回收站）。
- 动效：列表 → 详情 160ms 淡入并向右移 8px，返回反向；生命值数字滚动与条的长度过渡 240ms，扣到 0 时方块描边闪一次红色；遵守"减少动态效果"。

### 2.6 键盘与可访问性

- 生命值方块是一个按钮组，`伤害` / `治疗` 可用 Tab 到达；输入框有可见标签"数值"；预览文字用 `aria-live="polite"`。
- 属性格是按钮，读作"力量 8，调整值负 1，豁免负 1，未熟练"；`★` 与 `📌` 读作"设为玩家角色，已开启"。
- 分页导航是 `tablist`，方向键切换；状态药丸的 × 读作"移除 盖尔 的 中毒 状态"。

### 3.2 真机验收（驾驶员，TauriTavern；U5.1 完成后）

1. 在人物页点一个队友进入详情：头像、名字、HP、AC、六项属性、法术位、状态都正确，分页导航可点（内容显示"尚未开放"）。
2. 点 `− 伤害` 输入数字回车：HP 下降、提示条出现，点撤销恢复；把 HP 扣到 0：显示倒地与死亡豁免，治疗后恢复。
3. 点"编辑"：数字变成输入框；再点"完成"：回到干净的查看状态；中途调整 HP 始终可用。
4. 改身份、随行 / 留守、★、📌；返回人物页，列表分组随之变化，滚动位置没变。
5. 点敌人进入属性块；用"‹ A B C ›"在同组切换。
6. 窄屏上重复第 1、2 步；分页导航横向滑动正常；整个过程屏幕上从未同时出现两个弹窗。
