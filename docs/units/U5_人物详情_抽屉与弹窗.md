# U5 人物详情 · 抽屉与弹窗逐个规格

状态：草案 v1（2026-11-03），是 [`U5_人物详情.md`](U5_人物详情.md)（基本规格）的附录；视觉尺寸见 [`U5_人物详情_视觉规格.md`](U5_人物详情_视觉规格.md)。本文件的编号（§5.x）被基本规格引用，不要改。

**本文件的读法**：每一个抽屉、弹窗、弹层都写了「入口 → 长什么样（ASCII）→ 里面有什么与规则 → 怎么操作 → 读写哪些数据 → 依据」。规则依据写《玩家手册》中译本 v1.72 的页码（印刷页），或项目数据字段 / `docs/模块数据约定.md` 的章节。**没有依据的内容没有写进来；规格没写到的情况不许自己补，照基本规格 §1 总规则处理并写进报告。**

---

## 5.1 通用

- 抽屉 = `ModalHost` 的 `drawer` 变体，右侧滑出，页面栈；小弹窗 = `dialog` 变体（宽 480，高度跟内容，最高 80%）；弹层（下拉、菜单、来源弹层）不遮挡后面。一次最多一个模态，**不叠加**；抽屉里前进一页 = 入栈，左上「‹ 上一页名称」返回；✕、Esc、点遮罩关闭，焦点回到触发处。
- **抽屉没有「完成」按钮**：抽屉里的改动即时进草稿（设定类）或即时写入（当场状态），没有「确定」这一步，关闭就是 ✕ / Esc / 遮罩。（订正：基本规格 §1.8 里「完成只是关闭抽屉」的说法以本条为准。）
- 含设定类内容的抽屉底部一行 12px 小字：「改动进入草稿，点右上「保存」后生效」。
- 标题栏沿用 `ModalHost` 现有标题栏（衬线标题 + ✕）；抽屉宽度见基本规格 §1.8。
- 键盘：抽屉里 Tab 循环；Esc 逐页返回；输入框按基本规格 §1.3。
- 每个抽屉底部的错误行：输入超范围时在该格下方显示一行红字，格子保留原输入，不静默改值。

## 5.2 身份抽屉（UNIT2） 〔已被 U5R §10.1、§10.2 取代，见该节〕

**入口**：点 A 卡的名字（含英文名）、身份行里的种族 / 亚种族、虚线「选种族 ›」。**单页，没有标签。**

```
+-----------------------------------------------+
| 身份                                    [✕]   |
|-----------------------------------------------|
| +--------+   [上传图片]  [重新截取]  [清除]    |
| |  头像  |                                      |
| +--------+                                      |
|                                                 |
| 名字      [ 盖尔                  ]            |
| 英文名    [ Gale                  ]            |
| 阵营      [ 中立善良           ▾ ]            |
| 种族      [ 人类               ▾ ]            |
| 亚种族    [ 未选                ▾ ]            |
| 背景      [ 侍僧               ▾ ]            |
| 体型 [ 中型 ▾ ]   类型 [ 类人生物 ▾ ]           |  ← 只有模板怪物才显示
|-----------------------------------------------|
| 改动进入草稿，点右上「保存」后生效              |
+-----------------------------------------------+
```

### 字段与规则

| 字段 | 控件 | 规则 | 写入 |
|---|---|---|---|
| 头像 | 预览（96×120 头像框）+ 三个按钮 | 见下「头像」 | `avatar`、`avatarSource` |
| 名字 | 输入框 | 1–40 个字（`PERSON_NAME_MAX`），不能为空；超限在框下红字 | `name` |
| 英文名 | 输入框 | ≤ 80 个字，可空 | `nameEn` |
| 阵营 | 下拉（6–15 项固定选项用下拉，开发规范 §5.3） | 九种加「无阵营」：守序善良、中立善良、混乱善良、守序中立、绝对中立、混乱中立、守序邪恶、中立邪恶、混乱邪恶（《玩家手册》p122）；可清空 | `block.alignment`，**写项目数据里的代码写法**：用空格分开的字母，`L G` = 守序善良、`N` = 绝对中立、`C E` = 混乱邪恶、`U` = 无阵营（和模板一致，`src/ui/library/zh.ts` 的 `ALIGNMENT` 负责显示） |
| 种族 | 可搜索下拉（`Combobox`） | 候选 = 已启用的包里所有 `race` 条目；每行：中文名、英文名、来源书徽章；选中后字段旁出现「看资料」（术语下划线，点开资料卡，弹窗内换页）；可清空 | `block.race`（条目编号） |
| 亚种族 | 可搜索下拉 | 候选 = 已启用的包里 `subrace` 条目中 `data.parentRace` 等于所选种族条目编号的（例：`subrace.dwarf-mountain.phb` 的 `parentRace` 是 `race.dwarf.phb`）；没选种族时禁用；种族改变且旧亚种族不属于新种族时，**清空亚种族**；所选种族没有任何亚种族时下拉禁用 | `block.subrace` |
| 背景 | 可搜索下拉 | 候选 = 已启用的包里所有 `background` 条目；其余同种族 | `block.background` |
| 体型 | 下拉 | 6 档：微型、小型、中型、大型、巨型、超巨型；**只有「来自模板的怪物」（有 `cr`）才显示** | `block.size` |
| 类型 | 下拉 | 14 种生物类型（异怪、野兽、天界生物…）；同上 | `block.creatureType.type` |

- **选种族、亚种族、背景只存选择，不自动分配任何东西**：种族的固定属性加成会自动出现在属性计算表的「种族 / 背景」列（只读，基本规格 §6.1）；熟练、语言、武器、工具的分配归 UNIT4 的 [自动分配熟练项目]（驾驶员 2026-11-03：先把种族与背景加进身份抽屉，分配之后在职业页面做）。
- 种族、亚种族、背景的下拉没有可选条目时（没装包）：下拉里显示「没有可选的种族，请先到「库」里安装资料」，不报错。
- 阵营下拉不加任何括号注释。

### 头像

| 按钮 | 什么时候出现 | 做什么 |
|---|---|---|
| 上传图片 | 总是 | 打开系统文件选择；选好后**自动截取**（同 A 卡点头像，规则见基本规格 §4.2.1）并立刻换图 |
| 重新截取 | 已有头像且保存过原图（`avatarSource` 存在）时 | 抽屉里前进到「重新截取」页（§5.3） |
| 清除 | 已有头像时 | 删除 `avatar` 与 `avatarSource`；头像框回到默认（立绘或生物类型图标）。不弹确认，顶栏「撤销」可撤回 |

- 没有头像时只有「上传图片」；有头像但没有原图（旧数据）时有「上传图片」「清除」，没有「重新截取」。
- 图片不合规（类型、大小，L1 §2.2）：预览下方一行红字写原因，不改变现有头像。

**读写**：设定类（草稿）。名字为空时抽屉不阻止关闭，但顶栏「保存」禁用并在名字框下显示红字。

## 5.3 重新截取头像（身份抽屉里的一页，UNIT2）

**入口**：身份抽屉「重新截取」。这是抽屉页面栈里的第二页，左上「‹ 身份」。

```
+-----------------------------------------------+
| ‹ 身份    重新截取头像                         |
|-----------------------------------------------|
| +----------------------------------+          |
| |  原图（拖动截取框 / 拖角缩放）     |   预览    |
| |       +--------+                 |  +-----+  |
| |       | 截取框  |                 |  | 4:5 |  |
| |       +--------+                 |  +-----+  |
| +----------------------------------+          |
| 缩放 [−────────●────────＋]                    |
|                                                 |
|              [取消]       [使用这个截取]         |
+-----------------------------------------------+
```

| 项 | 规则 |
|---|---|
| 截取框 | 比例锁定 4:5；默认放在上次保存的位置（`avatarSource.crop`）；框外盖半透明遮罩 |
| 移动 | 拖动框；键盘：方向键移动 2%，Shift + 方向键 10% |
| 缩放 | 拖框的四角、拖滑块、点 − / ＋（每次 5%）、触屏双指捏合；最小为原图短边的 20%，最大为原图能放下的最大框 |
| 边界 | 框始终在原图内，不能拖出去 |
| 预览 | 右侧（窄屏在原图下方）实时显示 96×120 头像框里的样子 |
| 「使用这个截取」 | 用新截取框重新生成 320×400 的 `avatar`，更新 `avatarSource.crop`，返回身份抽屉；头像立刻更新 |
| 「取消」 | 返回身份抽屉，不改任何东西 |

**读写**：设定类（草稿）；原图从图片仓库读取（`avatarSource.asset`）；读不到原图时显示一行红字「原图已不在，请重新上传」，并只提供「上传图片」。

### 生成区

三种方式用分段按钮（`Segmented`）切换，**切换方式不改任何已有数值**。

**标准数组**

```
  数组   [ 15 ]  [ 14 ]  [ 13 ]  [ 12 ]  [ 10 ]  [ 8 ]
  点击数字，再点击下方属性行放入
```

- 点池里的数字 → 它高亮（选中）；再点计算表里某一行的「基础」格（或整行）→ 放入：该属性的 `abilities` 变成这个数，池里的数字变灰。
- 已变灰的数字再点一次 = 取消放入：该属性的基础值恢复为放入前的值，数字回到可用。
- 把另一个数字放到已经有放入值的行上 = 替换，原来的数字回到池里。
- 池状态（哪些数字已放入）只放在抽屉本地内存里；关闭再开会重新开始，但已写进 `abilities` 的值保留。

**4d6 去最低**（用户只看每组的总分，不需要关心划掉的那颗，驾驶员 2026-11-03）

```
  [骰] 一键掷 6 组点数

  摇出的点数池（点击数字，再点击下方属性行放入）：
    [ 14 ]   [ 10 ]   [ 15 ]   [ 12 ]   [ 8 ]   [ 13 ]

  ▸ 点数明细（可选展开）
    14 (5+3+6, 弃1) | 10 (4+4+2, 弃1) | 15 (5+5+5, 弃2) | …
```

- 「一键掷 6 组点数」：每组掷四颗六面骰、去掉最低的一颗、其余三颗相加，共 6 组；用 `src/rules/dice` 的 `cryptoRng`（不写 `Math.random`）。结果显示为 6 个总分按钮（池）。
- 点数明细默认收起（▸），展开后每组写「总分 (三颗相加, 弃去的)」，仅供查看，不可操作。
- 再点「一键掷」= 重新掷出新池；已放入属性行的值不变。
- 放入、取消放入的规则同标准数组。

**购点**

```
  剩余 8 点   已花 19 / 27
  成本   8=0  9=1  10=2  11=3  12=4  13=5  14=7  15=9
```

- 池区域换成上面两行；计算表里每行「基础」格变成 `[−] 8 [+]` 步进器；范围 8–15；每次 ± 1 并更新已花点数。
- 加一步会使已花点数超过 27 时，该行的 [+] 变灰。
- 已有基础值超出 8–15 的属性，该行显示原值并在行下红字「购点范围 8–15」，点 [−] / [+] 时先钳到范围内。已花点数只统计范围内的行。
- 出处：《玩家手册》p13：标准数组 15、14、13、12、10、8；4d6 去最低，重复六次得到六个数；购点 27 点，每项 8–15（种族加值之前），成本如上。

### 计算表

每行一项属性，列：

| 列 | 内容 | 能不能改 | 来源 |
|---|---|---|---|
| 属性 | 力量 … 魅力 | — | `ABILITY_LABELS` |
| 基础 | 数字输入（1–30）；购点模式下是步进器 | **可改** | `block.abilities` |
| 种族/背景 | 所选种族 + 亚种族的固定加成（如 +2）；没有就 `+0`；还有「自选」部分的种族此列只显示固定部分 | 只读（灰） | 种族 `abilityBonus.fixed`（基本规格 §6.1） |
| 成长/专长 | 属性提升加点、专长的 +1 | 只读（灰） | `block.abilityGrowth`，**UNIT4 写**；此前恒为 `+0` |
| 装备/魔法物品 | 已装备物品的 `abilityBonus` 加值，或「设为 20」之类 | 只读（灰） | 背包（UNIT5）；此前恒为 `+0`；数据里只有 2 件魔法物品有结构化的属性效果 |
| 其他（手动） | 数字输入（−20 到 +20，整数，默认 0） | **可改** | `block.abilityOther` |
| 最终 | 算出来的最终值；超出上限时显示上限值，下面 12px「上限 20」 | 只读；覆盖视图里变输入框 | `derive` |
| 调整值 | ⌊(最终 − 10) ÷ 2⌋ | 只读 | p7、p13 |
| 豁免 | 勾选框：这项属性的豁免是否有熟练 | **可勾** | `proficiencies.saves` |

- **灰色列不是死数据**：别的 UNIT 写好后这里自动出现，不需要任何调用（基本规格 §10）。「—」不会出现在这张表里，没有值一律 `+0`。
- **上限**：默认 20（专长耐性写「上限为 20」p166；属性提升也不能超过 20，p49）；特性可抬高（原初斗士等，UNIT4 写）。
- 豁免勾选：勾上 = 在 `proficiencies.saves` 里加这项（来源 `manual`）；取消勾选 = 删掉这一项（包括其他来源，如职业给的）。职业给的豁免熟练由 UNIT4 的 [自动分配熟练项目] 写入；此前模板怪物的写死豁免总值读作覆盖值，勾选框按「总值 − 调整值 ≥ 熟练加值」推断显示（只显示不写回），玩家点勾选框时清除该项写死值并写入手动勾选。
- 变体人类、「选 2 项各 +1」的种族（半精灵）等：数据里没有或还没分配，先在「其他（手动）」里填。

### 两个按钮

| 按钮 | 做什么 |
|---|---|
| [覆盖] | 切换覆盖视图：「最终」列变成数字输入框（覆盖值，1–30），其他列照旧显示；再点退出覆盖视图（已填的覆盖值保留）。清空某个输入框 = 删除该项覆盖 |
| [全部自动计算] | 清空本抽屉里**所有**「其他（手动）」与覆盖值；**不动**基础、豁免勾选。算一步撤销 |

### 读写

- 设定类（草稿）：`abilities`、`abilityOther`、`overrides.abilities`、`proficiencies.saves`。
- 读：种族、亚种族条目（`abilityBonus`）、`abilityGrowth`、装备效果。
- 一个数据只有一个编辑入口：基础与其他在这里改；种族 / 背景在身份抽屉；成长在 UNIT4；装备在 UNIT5。

窄屏：每一行是一张小卡（项目名 + 最终值在上，下面按列逐行写）。

### 行与列

| 行 | 基础 | 能力 | 等级 / 熟练 | 装备 / 效果 | 其他 | 最终 | 依据 |
|---|---|---|---|---|---|---|---|
| AC | 没装备时 10；模板怪物写死的 AC 值显示在这里 | 敏捷调整值 | — | 效果 `ac` 的 `bonus`（只读） | 可填 | 基础 + 能力 + 效果 + 其他 | 无甲 AC = 10 + 敏捷调整值（p14）；**护甲、盾牌由背包 UNIT 自动算，本抽屉不做算法下拉** |
| 先攻 | — | 敏捷调整值 | — | 效果 `initiative` 的 `bonus`（只读） | 可填 | 同上 | 先攻是一次敏捷检定（p177） |

- 「＋ 移动方式 ▾」：下拉菜单（弹层），列出还没有的方式；选中后追加一行并聚焦基础格；全部用完则变灰。追加行右端 ✕：就地出现「删除「飞行」速度？[删除][取消]」气泡（不整页弹窗），删除后该方式回到可添加。

- 有优势 +5、有劣势 −5（p175）只在掷骰那一次才有意义，不写入这里。
- AC、先攻、熟练加值、被动在 A 卡读数里显示的就是这张表的「最终」。
- **[覆盖] / [全部自动计算]**：同属性抽屉（§5.4）；覆盖视图里「最终」列是输入框，对应 `overrides.ac / initiative / proficiency / passive / speed`。

**读写**：设定类（草稿）：`adjust`、`overrides`、`block.speed`。读：种族与职业数据、效果。

- **[全部自动计算]**：清空所有技能覆盖值，**不动**熟练图标。

```

| [☐] 只看有熟练的                     |

```

- 数据：技能总值 = 属性调整值 + 熟练项（0、½、1、2 倍熟练加值）（基本规格 §6.4）；模板怪物的 `skills`（写死总值）读作覆盖值，熟练图标按「总值 − 调整值」推断显示，只显示不写回；玩家点图标时清除该项写死值（§5.1 数据说明）。

**读写**：设定类（草稿）：`proficiencies.skills`、`overrides.skills`。「行动与技能」页主界面只显示熟练项（基本规格 §4.7.3），图标只读。

## 5.7 档案区九个弹窗（UNIT3；结构完全相同，共用一个组件） 〔已被 U5R §8、§10.6 取代，见该节〕

```
| 来源        种族 · 精灵   [看资料]   |
|             背景 · 侍僧   [看资料]   |
|                          [移除]     |
+------------------------------------+
```

- 「获得方式」三种：**自动分配**（来自 UNIT4 的 [自动分配熟练项目]，`auto`）、**手动**（用户自己添加，`manual`）、**模板自带**（`template`，来源写模板名称，取自 `person.sourceRef` 所指条目）。同一项有多个来源时「来源」逐条列出。
- 「看资料」：打开来源条目的资料卡（弹窗内换页，不叠）。
- 「移除」：同弹窗里 ×，立刻移除整个条目（含所有来源）。只读药丸（模板怪物的 `languages` 文字、带条件的抗性）没有「移除」。
- **UNIT3 时数据里只会出现「手动」和「模板自带」**；「自动分配」随 UNIT4 出现，弹层结构不变。
- 无障碍：弹层是 `role="dialog"`、`aria-modal="false"`；Esc 关闭，焦点回到药丸。

## 5.12 各抽屉与弹窗的写入汇总
