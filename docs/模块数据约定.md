# 模块数据约定

后续模块（U6.1 人物数据层、R1.1 派生数值、L1B 全库搜索与选择器、U6.2 加入流程、U5.x 人物卡、R1.2 规则引擎、M7 战斗、M9 战役）从内容包读数据时，以本文件为准：**哪些字段能依赖、什么形状、怎么读、哪些读不出来。**

本文件随 G2 逐段增补。**现在写到：G2a（人物底子）。** 施法计算（升环、材料成分、法术攻击与难度）、规则计算、怪物与战斗、查找与输出分别在 G2b、G2c、G2d 补。

## 0. 怎么看这份约定

- 每个字段后面标状态：
  - ✅ **可用**：形状固定，已和书逐项核对过，可以直接依赖。
  - ⚠️ **读得出，但有例外**：绝大多数可用，个别条目有已登记的缺陷（列在括号里）；读取器要处理例外。
  - ⛔ **G2.5 后可用**：现在的数据缺这部分，或写法需要先统一；人物模块不要现在依赖，等 G2.5 修完。
- 每条对应一个**参考读取器**（`tests/data/consumer/`，只在测试里用）和一个**登记表**（`docs/probes/D1.2-G2_发现登记/`）。读取器是“怎么读”的可执行示范，后续模块照思路自己实现，不直接依赖测试目录。
- 遇到不认识的形状，读取器**抛错**，不静默当成没有。人物模块也请这样做。
- 代码统一用小写英文：能力 `str dex con int wis cha`；技能 `acrobatics`、`animal handling`、`sleight of hand`（带空格，18 个，`rule` 条目对应）；伤害类型 `acid bludgeoning cold fire force lightning necrotic piercing poison psychic radiant slashing thunder`；状态 `blinded charmed deafened exhaustion frightened grappled incapacitated invisible paralyzed petrified poisoned prone restrained stunned unconscious`。代码表在 `src/rules/dnd5e2014/data/enums.ts`。中文显示由代码表或条目名给出。
- 条目编号：`类型.英文名.书` 如 `class.wizard.phb`、`spell.fireball.phb`。引用别的条目的字段值就是条目编号；正文里是 `{{ref:编号|显示字}}`。

## 1. 职业与子职业（`class`、`subclass`）

读取器：`classSheet.ts`（`readProficiencies`、`readEquipment`、`readSpellcasting`、`readGrants`、`asiLevels`）。

| 字段 | 形状 | 状态 | 怎么读 |
|---|---|---|---|
| `hitDie` | 数字 6/8/10/12 | ✅ | 13 个职业与书一致 |
| `saves` | 能力代码数组 | ✅ | |
| `proficiencies.armor` | `light medium heavy shield` 数组 | ✅ | |
| `proficiencies.weapons` | 字符串数组：`简易` `军用` `火器`，或 `{{ref:物品编号\|名}}` | ⚠️ | `简易/军用` 是类别，引用是具名武器。奇械师的 `火器` 是条件性熟练（TCE：DM 使用火器规则且接触过火器时才有），不要当无条件（登记 a1-weaponCats） |
| `proficiencies.tools` | 数组：`{{ref}}` 是固定工具；含“自选/任选”的是文字 | ⚠️ | 吟游诗人（自选三种乐器）、武僧（一种工匠工具或乐器）、奇械师（一种工匠工具）只有文字，读不成结构（登记 a2-tool-choice-prose，待决定） |
| `proficiencies.skills` | `{ choose: 数, from: [技能代码] }` | ✅ | 吟游诗人 `from` 是全部 18 个 |
| `subclassLevel` | 数字 | ✅ | 第一次获得子职业的等级（牧师、术士、魔契师 1；德鲁伊、法师 2；其余 3） |
| `startingEquipment` | 块数组：`{fixed:[...]}`、`{choice:[[...],[...]]}`、`{gold:{dice,multiplier}}` | ⛔ | 形状可读，但**“任意简易/军用武器”“其它乐器”“法器”“圣徽”等类别选项整条丢失**（11 个职业，登记 a3）。G2.5 后加类别选项；物品是中文名，不是编号（见 §5） |
| `multiclass.requires` | `{ all: [{ ability: {str:13} }] }` | ⚠️ | 战士写成 `{ability:{dex:13,str:13}}` 而书上是“或”，没有约定（登记 a8-requires-or）；其余按“全部要满足”读 |
| `multiclass.proficiencies` | 同 `proficiencies` 的子集 | ✅ | |
| `spellcasting` | 见 §3 | ✅ | |
| `table` | `{cols:[中文列名], rows:[{level, values:[字符串]}]}` | ✅ | 熟练加值和“特性”列不存，熟练加值按等级算：`2 + floor((等级-1)/4)`；战士没有职业表列 |
| 逐级授予 | `advancement[]` 里 `kind=itemGrant`：`{level, items:[特性编号], optional}` | ✅ | 1,573 个授予编号全部存在；属性值提升是授予名含 `ability-score-improvement` 的特性：4/8/12/16/19，战士另 6/14，游荡者另 10（用 `asiLevels`） |
| 选择池 | `advancement[]` 里 `kind=itemChoice`：`{level, count, pool:[编号]}` | ✅ | 子职业的三选一（猎人、图腾等） |
| 子职业 `classId` | 职业编号 | ✅ | |
| 子职业 `expandedSpells` | `[{level, spells:[法术编号]}]` | ⛔ | 领域/誓言/扩展法术**有 34 个等级缺法术**（18 个子职业，登记 a10）；G2.5 补 |
| 子职业 `spellcasting` | 奥法骑士、奥法诡术师可用；**四象武僧、先祖守护者带了 `progression=full` 却没有法术位表，不是施法者**（登记 a4） | ⚠️ | 读到 `progression` 时先看有没有 `slotsByLevel`，没有就不是施法者 |

**跨包登记（joins）读法**（G1 的约定，已核对）✅：某职业/子职业某级的“可选特性” = 所有已装包里 `data.joins` 指向它、`as: "optional"`、`level` 相同的特性；某选择池的选项 = 池里原有的 + `as: "option"` 指向该子职业的特性。塔莎的 45 项可选特性与子职业变体、剑湾 6 个图腾选项，与原始数据 45/45 一致。

## 2. 种族、亚种、背景、专长

读取器：`originSheet.ts`（`readRace` 合并种族与亚种、`readTraits` 展开任选）。

**种族 + 亚种合并规则**（读取器的做法，人物模块照做）：属性加值相加；体型、速度取亚种的；黑暗视觉取较大者；语言、熟练取并集。

| 字段 | 形状 | 状态 | 说明 |
|---|---|---|---|
| `abilityBonus` | `{ fixed:{str:2}, choose:{amount, count, from:[能力]} }` | ⚠️ | 变体人类是“替换”人类的加值，数据没有表达，叠加读会错（登记 a12-abilities）；其余 PHB 种族 ✅ |
| `size` | `["M"]` 等 | ⚠️ | 4 个亚种（森林侏儒、岩侏儒、轻足半身人、强健半身人）写成中型，应为小型（登记 a12-size） |
| `speed` | `{walk:30, fly:..., swim:...}` | ✅ | |
| `senses` | `[{type:"darkvision", range:60}]` | ✅ | |
| `languages` | `{ fixed:[语言代码], choose: 数 }` | ✅ | “任选”没有范围，约定为**全部可学语言**（standard + exotic，不含秘密语言） |
| `proficiencies` | `{armor,skills,tools,weapons: {fixed:[...], choose:{count,from}}}` | ✅ | 种族里武器/工具是**小写英文名**（`battleaxe`、`smith's tools`），职业里是引用；读取器按英文名对应物品（`fold` 去标点后比较） |
| 天生法术 | 种族 `effects[]` 里 `kind=spellGrant`（`mode: innate/known`, `spells`, `uses`） | ⛔ | **没有“解锁等级”字段**（提夫林 3/5 级、卓尔 3/5 级、灰矮人 3/5 级，登记 a12-innate-unlock-level）；深侏儒的天生施法没有授予法术（登记 a12-innate-not-structured） |
| `traits` | 特性编号数组 | ✅ | 全部存在 |
| 背景 `proficiencies` | `{skills,tools,languages: {fixed, choose:{count, from?}}}` | ✅ | PHB 13 个背景逐项一致；`from` 里的记号是不带前缀的 `anyGamingSet` 等 |
| 背景 `characteristics` | `[{label, table}]` 指向随机表 | ⚠️ | 11 个剑湾背景没有（书上写“使用某某背景的特征表”，登记 a13） |
| 背景 `equipment` | 同职业起始装备 | ⛔ | 物品名是中文名；49 项对不上条目（见 §5） |
| 专长 `requires` | `{all:[...], any:[...]}`，单项可含 `ability`、`proficiency:{armor}`、`spellcasting:true`、`race:[编号]`、`level` | ⚠️ | PHB 42 个专长逐项一致；精灵准确、天赋异禀的种族前置只是文字（登记 a14）；**一项里多个 `ability` 键没有约定**，不要依赖 |
| 专长 `abilityIncrease` | `[{ability, amount}]` 或 `[{choose:1, from:[...]}]` | ✅ | |

## 3. 施法

读取器：`classSheet.ts` 的 `readSpellcasting`；`expected/slots.ts` 是书上的法术位表（可作测试夹具）。

| 字段 | 形状 | 状态 | 说明 |
|---|---|---|---|
| `spellcasting.progression` | `full` `half` `third` `pact` | ✅ | 奇械师写 `half`，但 1 级就有 2 个 1 环位（表里已是对的，直接读 `slotsByLevel`） |
| `slotsByLevel` | `[{level, slots:[9个数]}]`，魔契师为 `[{level, pact:{count, level}}]` | ✅ | **11 个施法职业/子职业 × 20 级 × 9 环逐格与书一致**；不要自己用 `progression` 推导，直接读表 |
| `cantripsKnown` | 20 个数 | ✅ | 没有这个字段 = 没有戏法（圣武士、游侠） |
| `spellsKnown` | 20 个数 | ✅ | 牧师、德鲁伊、法师、圣武士、奇械师没有（他们“准备”法术） |
| `preparation` | `{mode:"known"}` 或 `{mode:"prepared"/"spellbook", formula:{ability, level:"full"/"half", min}}` | ✅ | 法师 智力+等级；牧师/德鲁伊 感知+等级；圣武士 魅力+一半等级；奇械师 智力+一半等级（至少 1） |
| `ability` | 施法属性 | ✅ | |
| 魔契师 `invocationsKnown` / 奇械师 `infusionsKnown/Active` | 20 个数 | ✅ | |
| 职业法术表 | 法术的 `classes` | ⛔ | **奇械师只有 7 个法术（应为 85 个）；塔莎等书的可选扩展列表被写进了 PHB 法术的职业里（65 处）**，核心列表和可选规则分不开（登记 a16b）。G2.5 后：职业自己列出全部法术 + 扩展书用 `joins` 的 `as:"spell"` 登记。**现在不要用 `classes` 当“该职业的法术表”** |
| 升环施法、材料成分价格、法术攻击与豁免难度 | — | ⛔ | G2b 检查，G2.5 修 |

**法术本身的字段**（读取器：`g2a-spell.test.ts` 里的比较函数）：

| 字段 | 形状 | 状态 |
|---|---|---|
| `level`、`school`、`ritual` | 数字、英文学派、布尔 | ✅ 319 个 SRD 法术逐项一致 |
| `castTime` | `[{n, unit: action/bonus/reaction/minute/hour, condition?}]` | ✅ 反应法术带触发条件 |
| `range` | `{type: point/cone/radius/line/cube/sphere/hemisphere/special, amount, unit: feet/miles/self/touch/sight/unlimited}` | ⚠️ `type` 是形状时表示“自身 + 该形状区域”；**球形/柱形等区域在 74 个法术里没有结构化**（火球术的 20 尺球形只在文字里，登记 a16-area-missing） |
| `components` | `{v, s, m:{text, cost?, consumed?}}` | ⚠️ `m.cost` / `m.consumed` 全空（G2b） |
| `duration` | `[{type: instant/timed/permanent/special, amount?, unit?, concentration}]` | ✅ 24 小时与 1 天等价 |
| `save` / `damage` | `['dex']`、`[{dice, type}]` | ⚠️ 伤害类型错或缺 5 个（延迟爆裂火球、烈焰风暴、冰风暴、流星爆、虔诚护卫，登记 a16-damage-*） |
| 攻击 | 在 `activities` 里 `kind=attack`，没有单独的 `attack` 字段 | ✅ |

## 4. 物品基础

读取器：`g2a-item.test.ts` 里的比较函数；`consumer/expand.ts` 的 `baseWeapons/baseArmors/toolItems`。

| 字段 | 形状 | 状态 |
|---|---|---|
| `weapon` | `{category: simple/martial, damage:[{dice,type}], versatile?, properties:[L F T V 2H A LD H R S …], range?:{normal,long}}` | ✅ SRD 武器全部与 5e API 一致 |
| `armor` | `{category: light/medium/heavy/shield, ac, dexCap?, strReq?, stealthDisadvantage}` | ✅ |
| `value` / `weight` | **铜币整数** / 磅；**单件**（箭按一支计，铁蒺藜“一包 20 个”按整包） | ⚠️ 单件不足 1 铜币的（投石索弹丸）被取整成 0；牧笛没价格（登记 a15-value）。无价格/无重量的物品（魔法物品多数书上本来就没有）读到 `undefined` |
| 工具分类 | 物品 `tags`：`T` 一般工具、`AT` 工匠工具、`INS` 乐器、`GS` 游戏套组 | ✅ 靠 tags 判断，不靠类别（工匠工具的 `category` 是 `treasure`） |
| 套组 `contents` | `[{item: 编号, qty}]` | ⚠️ 17 个带内容物，编号全部存在；牧师套组缺 4 项、学者套组缺 2 项且羊皮纸数量错、窃贼套组缺 1 项（登记 a15-contents-differ） |
| 家族 `category: "family"` + `members` | 编号数组 | ✅ 38 个家族 387 个成员全部存在 |

**普通物品的识别**：`rarity === "none"` 且没有 `variantOf`；具装（`… Barding`）是基础物品的变体但 `rarity` 也是 none。

## 5. 「任选」记号与自由文字物品

读取器：`expand.ts`（`expandToken`、`expandPool`）。

**记号**：`类别:值`，出现在 `advancement[kind=trait]` 的 `grants`（固定给的）和 `choices[].pool`（从池里选 `count` 个）、专长的同类字段。全库 87 种、共 500 处，全部能展开。

| 记号 | 展开成 | 状态 |
|---|---|---|
| `skill:*` | 18 个技能代码 | ✅ |
| `skill:acrobatics` | 该技能 | ✅ `animal-handling` 是 `animal handling` 的别写（登记 a17-spelling） |
| `lang:*` | 全部标准+异界语言（不含秘密语言） | ✅ |
| `lang:anyStandard` | 标准语言 | ✅ |
| `lang:代码` | 该语言 | ⚠️ `aquan/auran/terran` 没有语言条目（原初语方言），返回代码（登记 a17-no-entry） |
| `lang:other` | — | ⛔ 含义不明，读取器返回“含义不明”（吉斯人、穴蜥人、啵灵蛙，登记 a17-ambiguous） |
| `tool:*` | 全部工具 | ✅ |
| `tool:anyArtisansTool` `anyGamingSet` `anyMusicalInstrument` | 对应 tags 的全部物品 | ✅ `gaming set`、`musical instrument` 是别写 |
| `tool:具体英文名` | 该工具条目 | ✅ `smiths-tools` 与 `smith's tools` 等混用；读取器按去标点的英文名对应 |
| `tool:vehicles (land/water)` | 代码 | ⚠️ 没有条目（载具熟练） |
| `weapon:martial` `simple` `*` `firearms` | 对应类别的基础武器 | ✅ |
| `weapon:英文名` | 该武器 | ✅ |
| `armor:light/medium/heavy/shield` | 护甲组代码 | ✅ |

**背景/职业的起始物品是中文名**，用 `resolveItemName`（先精确，再去掉括号数量后比较）对应物品条目。对不上的约定为**自由文字物品**（书上本来就是描述性文字：家系族谱、情书、信物、地图、熏香……），人物模块把它当“一件普通物品，名字就是这段文字”，不要报错。49 项里有 5 项是漏配（纸、羊皮纸、墨水笔、墨水），3 项是带描述的版本，41 项是真正的自由文字（登记 a3）；G2.5 后用 `id` / `free: true` 区分。
