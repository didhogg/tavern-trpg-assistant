# 模块数据约定

后续模块（U6.1 人物数据层、R1.1 派生数值、L1B 全库搜索与选择器、U6.2 加入流程、U5.x 人物卡、R1.2 规则引擎、M7 战斗、M9 战役）从内容包读数据时，以本文件为准：**哪些字段能依赖、什么形状、怎么读、哪些读不出来。**

本文件随 G2 逐段增补。**G2a–G2d 全部写完（人物底子、规则计算、怪物与战斗、查找与输出）。** 标 ⛔/⚠️ 的字段在 G2.5 数据修正后可用。

## 0. 怎么看这份约定

- 每个字段后面标状态：
  - ✅ **可用**：形状固定，已和书逐项核对过，可以直接依赖。
  - ⚠️ **读得出，但有例外**：绝大多数可用，个别条目有已登记的缺陷（列在括号里）；读取器要处理例外。
  - ⛔ **G2.5 后可用**：现在的数据缺这部分，或写法需要先统一；人物模块不要现在依赖，等 G2.5 修完。
- 每条对应一个**参考读取器**（`tests/data/consumer/`，只在测试里用）和一个**登记表**（`docs/probes/D1.2-G2_发现登记/`）。读取器是“怎么读”的可执行示范，后续模块照思路自己实现，不直接依赖测试目录。
- 遇到不认识的形状，读取器**抛错**，不静默当成没有。人物模块也请这样做。
- 代码统一用小写英文：能力 `str dex con int wis cha`；技能 `acrobatics`、`animal handling`、`sleight of hand`（带空格，18 个，`rule` 条目对应）；伤害类型 `acid bludgeoning cold fire force lightning necrotic piercing poison psychic radiant slashing thunder`；状态 `blinded charmed deafened exhaustion frightened grappled incapacitated invisible paralyzed petrified poisoned prone restrained stunned unconscious`。代码表在 `src/rules/dnd5e2014/data/enums.ts`。中文显示由代码表或条目名给出。
- 条目编号：`类型.英文名.书` 如 `class.wizard.phb`、`spell.fireball.phb`。引用别的条目的字段值就是条目编号；正文里是 `{{ref:编号|显示字}}`。

## 6. 派生数值（R1.1 照这个算；样卡 `tests/data/g2b-sample.test.ts` 是可执行示范）

读取器：`consumer/derive.ts`。**用包里的数据加书上的通用规则**，19 张样卡 141 项对照手算，135 项一致。

| 要算的 | 怎么读 | 状态 |
|---|---|---|
| 属性调整值、熟练加值 | `floor((值-10)/2)`；`2 + floor((等级-1)/4)` | ✅ 通用规则，不进数据 |
| 豁免、技能 | 职业 `saves` + 背景固定技能 + 种族固定技能 + 玩家自选；加熟练加值 | ✅ |
| 被动察觉 | 10 + 察觉 + 效果里的 `passive` 加值（观察者专长 +5） | ✅ |
| 护甲等级 | 护甲 `armor.ac` + 敏捷（受 `dexCap` 限制；重甲不加）+ 盾牌；再取效果里 `ac` 的 `base` 公式较大者；`bonus` 相加 | ⚠️ 无甲防御（野蛮人、武僧）能算，但**条件只有文字**（「未穿护甲」），读取器靠关键词；龙脉术士的龙族韧性在说明文字里，读不出（登记 b2-derived-in-note）；蜥蜴人/穴蜥人天生护甲、双持客 +1 是 0 占位 |
| 生命值上限 | 1 级满生命骰 + 体质，之后每级平均值（骰面/2+1）+ 体质；加效果里 `hpMax` 的 `perLevel × 等级 + flat` | ⚠️ 强健专长（+2/级）能算；矮人坚韧、龙族韧性每级加成缺（0 占位） |
| 先攻 | 敏捷 + 效果里 `initiative` 的 `bonus`（警觉 +5） | ✅ |
| 速度 | 种族步行速度 + 效果里 `speed` 的 `bonus`；`amount` 的含义**没有约定**（有的是设成多少，有的是加多少） | ⛔ 快速移动、无甲移动、灵活移动、动力步伐等 `amount` 都是 0 占位（登记 b2-zero-placeholder），G2.5 后可用 |
| 法术位 | 直接读职业 `slotsByLevel`；兼职按书上规则：全施法等级相加 + 半施法/2 向下取整 + 三分之一施法/3 向下取整 + 奇械师/2 向上取整，再查全施法表（`consumer/derive.ts` 的 `multiclassCasterLevel`） | ✅ |
| 法术豁免难度、法术攻击 | `8 + 熟练 + 施法属性调整值`；`熟练 + 施法属性调整值`；施法属性读 `spellcasting.ability` | ✅ |

## 7. 效果 `effects`（601 条）

形状：`{ kind, ...字段, transfer?, when?, condition? }`，`kind` 共 26 种（抗性、授予法术、速度、护甲等级、生命上限、优势劣势、先攻、被动、技能、豁免、熟练、感官、攻击/伤害/DC 加值……）；601 条全部符合格式定义。

- ✅ 抗性/免疫/易伤的伤害类型、授予法术的编号、优势/劣势的 `on`（attack/check/save/initiative）合法。
- ⚠️ `when`（触发条件）只有 3 个条目用，且都是文字（登记 b2-when-text）：**不要依赖 `when` 的内容，先当作“始终生效 + 在说明里提示条件”**。
