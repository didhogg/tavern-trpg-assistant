# 基本蓝图

本文件定义产品整体骨架。每个 Unit 的界面细节、字段与交互在 `docs/units/` 的单元蓝图中定稿。

## 1. 信息层级与数据原则

```
规则（如 D&D 5e 2014）              ← 最高层；切换规则 = 切换整套界面上下文；规则由代码注册
 ├─ 扩展包     库中全局安装；分组：资料与规则 / 冒险 / 设定 / 工具
 │   内容：条目（怪物、法术、物品、职业、种族、背景、专长、随机表、规则条目）、官方条目修改版、
 │         冒险（地点与底图、人物、派系、任务、遭遇、事件、文档；可为合集或系列）、
 │         功能（规则选项、AI 基调、建卡方式、活动、追踪器）
 └─ 我的库     玩家自己的可编辑扩展包；存档中的内容可存入，所有存档可用
存档（属于一个规则；全局存放，标注所属角色卡）
当前数据（每张角色卡/群组一份；属于一个规则；自动持久化）
```

- 扩展包只有一种格式，全局安装，所有角色卡通用；存档启用扩展包后使用其条目与功能，冒险内容在导入时复制进存档。存档只靠自身数据即可打开与游玩，库的变化不改写存档。详见 L1。
- 扩展包只含数据，不含可执行代码。
- 插件保存两类数据：**静态资料与关联**（条目、描述、地点与卡片的关联）和**规则状态**（数值、资源、状态、背包、遭遇、先攻、日志）。剧情中的时间、天气、人物去向与是否在场由 RP AI 依据对话判断。
- 新存档：选规则 → 勾选扩展、选择冒险（可不选）→ 命名。分支存档：把当前数据另存为新存档位并切换过去，原存档保持原样。
- 保存：玩家点"保存"时把当前数据写入当前存档；读档、分支、新存档前自动写入自动存档位（滚动保留 3 个）。
- 模板与游戏内副本：扩展包与存档内模板中的条目可直接查看、引用、交给 AI；对条目执行需要记录状态的操作（掷骰、加入遭遇、编辑、加入队伍、设为常驻）时，自动在当前数据中生成该条目的副本并记录来源。模板更新时提示可同步并显示差异。
  - **唯一**条目（具名 NPC、首领、唯一物品）在当前数据中只有一份，所有地点与遭遇引用同一份。
  - **普通**条目（普通怪物等）每次加入遭遇生成新的副本并自动编号。
- 地点、人物、敌人、任务、遭遇在任何时候都可以手动新建、编辑、删除。
- 每个条目有两个可选文本字段：**描述**（进入 AI 事实层）与 **DM 秘密**（第四面墙层）。

## 2. 界面结构

```
悬浮球（可拖动、贴边；点击打开/收起悬浮窗）
悬浮窗（可拖动、可缩放；完整 / 迷你两种模式）
 ├─ 没有战役时：侧栏只有首页、库、设置；首页的纯色横幅按钮打开开局向导弹窗（规则 → 资料 → 冒险 → 命名）
 ├─ 侧栏（深色）：品牌 · 导航〔首页 人物 战斗 地图 战役 活动 资料〕 · 底部〔库 设置〕
 ├─ 内容区（浅色）
 │   ├─ 页头：页面标题 … 状态芯片〔存档名▾〕〔● 保存〕〔📍当前地点▾〕〔⚔第N轮〕 … 〔AI≈token〕〔–〕〔✕〕
 │   ├─ 页面内容
 │   └─ ⚄ 骰盘按钮（内容区右下角，所有页面常驻）→ 打开骰盘悬浮窗
 └─ 窄屏：顶部深色标题栏 + 底部标签栏（全部页面，可横向滑动）+ ⚄ 骰盘按钮

骰盘悬浮窗（独立悬浮窗，不占用页面布局）
 ├─ 基础版（M3）：结果、快捷骰、优势/普通/劣势、加值、骰式、说明、填入输入框、复制、最近记录
 └─ 完整版（U3，M5 起）：行动者、掷骰卡（DC、前提/DM 裁决、发给 AI 的文字、确认）、待发送队列、记录、随机表、D&D 行动结算

详情弹窗（模态）：点击任何下划线术语打开；弹窗内点条目、关联术语都在同一个弹窗里换页并可返回；模态弹窗不叠加
```

添加入口：队友在"人物·队伍"；敌人在"战役·遭遇"（准备）或"战斗"（临时加入）；地点在"地图"；NPC 在"人物·NPC"；任务在"战役"；资料页"加入▾"可送往以上任一处。

### 2.1 布局与尺寸

| 悬浮窗内部宽度 | 布局 |
|---|---|
| ≥ 720px | 侧栏展开（176px，图标 + 文字） |
| 481–719px | 侧栏收窄（56px，仅图标，悬停/聚焦显示名称） |
| ≤ 480px 或手机 | 顶部深色标题栏（48px，右侧：有改动时的"● 保存"与"⋯"菜单〔存档、当前地点、AI 内容、迷你模式、关闭〕）+ 底部标签栏（56px + 安全区，列出全部页面与库、设置，可横向滑动，当前项自动滚入视野，两端有渐隐提示）；骰盘为右下角按钮，点开为骰盘悬浮窗 |

- 悬浮窗默认 960×640，可缩放，最小 360×480；拖动把手：侧栏品牌区 / 窄屏标题栏。
- 页面切换不保存、不结算、不写入酒馆输入框，并保留各页的滚动、展开与筛选状态。

### 2.1.1 骰盘悬浮窗

- 骰盘悬浮窗是独立窗口：可拖动、位置记忆、不挡住后面，点外部不关闭，只有点 ✕ 或再次点 ⚄ 才关闭；打开与关闭不改变主窗口的布局与滚动位置；主窗口收起时它可以单独留在聊天上方；主窗口里打开模态弹窗时它不被遮住，照常可用。
- 宽屏：宽 360px，高度随内容、不超过视口的 70%；窄屏：宽度为视口的 92%，贴近底部标签栏上方，可上下拖动，「最近」默认折叠为一行。
- 窗口内的选择控件按开发规范 §5.3 实现，弹出的列表浮在所有窗口之上，不撑开骰盘悬浮窗，也不影响主窗口。
- ⚄ 在没有战役时也显示（自由掷骰不需要战役）。迷你模式中的"骰盘"同样是打开该悬浮窗的按钮。
- 分两版交付：**基础版**（M3，自由掷骰）先上线；**完整版**（U3，M5 起）在同一个窗口里加入行动者、掷骰入口预填、掷骰卡、确认、待发送队列与 D&D 行动结算，基础版的布局保留为完整版的「自由掷骰」区。

**基础版（M3）**
- 定位为自由掷骰：不改 HP、不扣资源、不写战役日志，也不冒充已结算的行动。
- 快捷骰 d4–d100 点一下立即掷一颗；d20 用主色。优势 / 普通 / 劣势只影响 d20；加值用 [–] [+] 调整，设定后每次都带上，直到改回。
- 骰式输入支持 `XdY`、多组骰相加与加减常数（如 `2d6+1d4+3`）；回车 = 掷；骰式不合法时在输入框下就近提示。
- 结果为衬线大字，揭示时数字滚动 200ms；下方明细列出每颗骰子；天然 20 用金色、天然 1 用红色，同时显示文字「天然 20」「天然 1」。
- 「填入输入框」把结果以注释追加到酒馆输入框末尾，不发送、不覆盖原有文字，例如 `<!-- [掷骰] 感知检定：1d20+5 = 17（12+5） -->`；按钮变为「已填入 ✓」2 秒。填入失败时显示「尚未填入」并保留「复制」。
- 「最近」保留本卡最近 20 次（本机保存）；每行直接写出算式与每颗骰子的点数（如「17 = 12 + 5」），不需要再点开；行尾 ↻ 用同样设置再掷一次。

### 2.2 视觉语言

- 深色"书脊"（侧栏、窄屏标题栏）+ 羊皮纸内容区；主色红棕只用于主操作与选中态，金色只作细线、徽记与少量点缀。
- 标题与大数字用衬线体；正文、控件用系统无衬线；数字等宽。
- 卡片只承载完整对象（人物、战役、内容包）：米白卡面、细描边、柔和阴影；列表行用细分隔线，不给每行加卡片。
- 状态用带浅底色的方块徽章（内置、已安装、有更新、未保存等），可点击的标签用药丸；状态不只靠颜色。
- 首页可展示一张横幅插画（玩家可自选图片；默认为无版权顾虑的纹样）；其他页面不放装饰插画。
- 图标统一使用 Phosphor（MIT，Regular 粗细）；骰子、职业等 TRPG 专属图标使用 game-icons.net（CC BY 3.0，在关于页署名）。

## 3. 人物模型

| 属性 | 取值 | 修改位置 |
|---|---|---|
| 卡型 | 完整卡 / 属性块（名称由规则包提供） | 新建时选定 |
| 身份 | 队伍成员 / NPC / 敌人 | 详情顶部分段按钮；多选批量 |
| 所属队伍 | 身份为队伍成员时必选；可有多支队伍，其中一支为**当前冒险队伍** | 选择"队伍成员"时的下拉；换队伍 |
| 随行 / 留守 | 仅队伍成员 | 详情顶部；多选批量 |
| ★玩家角色 | 每支队伍至多一人；摘要中标为"你" | 详情顶部 |
| 📌常驻 | 开/关；常驻者总在"相关"范围中 | 列表行或详情顶部 |
| 对外称呼 | 可选；AI 摘要使用对外称呼 | 详情 |
| 关键词 | 名字、对外称呼、别名；用于提及激活 | 详情 |
| 给 AI | 自动 / 只给名字 / 完整 / 不提供 | 详情；AI 预览抽屉 |
| 标签 | 多个；只用于分类、搜索、筛选 | 详情 +标签；多选批量 |
| 唯一 / 普通 | 来自模板；见 §1 | 模板定义 |
| 状态 | 正常 / 草稿 / 回收站 | 自动；移入回收站 |

## 4. 主流程

1. **首次进入**：首页显示"开始一场新的冒险"横幅 → 点击打开开局向导弹窗（选规则 → 资料 → 冒险 → 命名；没有冒险包时跳过冒险）→ 首页战役概览 + 上手清单；冒险一步选《凡戴尔的失落矿坑》时一并载入预设角色；或点横幅下方"读取已有存档"。
2. **新建人物**：任一入口打开同一个"新建人物"对话框——身份（默认等于当前视图）、所属队伍（身份为队伍成员时）、来源（从模板 / 空白）、模板搜索与预览、数量（敌人）、卡型（空白时）、名称、"同时加入当前遭遇"（遭遇中）。创建后进入该人物详情，显示"草稿"与"待填 N 项"，必填项完成后转为正常；提示条提供撤销。其他入口带上下文预填：资料页"加入▾"、战斗"+加入"、遭遇编辑"新建…"。完整卡另有"分步创建"入口。
3. **改身份与入队**：在人物详情顶部切换身份；切到队伍成员时选择队伍；多人用多选批量。人物始终是同一份数据。
4. **队伍管理**：队伍切换器提供新建、改名、设为当前冒险队伍、解散；解散后原成员身份变为 NPC，标签保留。成员顺序可调整；"📦 队伍公共"管理公共背包、金币与成员顺序。
5. **相关人物**：NPC 与敌人视图默认显示"相关"——最近对话提及（扫描最近 3 层，按关键词匹配）、当前地点关联、当前遭遇参战者、常驻；"全部"显示当前数据中的全部人物；"模组库"浏览已启用扩展包与存档内模板中的人物模板。
6. **列表操作**：搜索覆盖姓名、对外称呼、种族、职业、标签；标签筛选为"同时具备"；显示"显示 N / 共 M"；"清除条件"保留排序；筛选与排序在切换页面后保留。多选模式下"全选"作用于全部筛选结果，批量操作有改身份、换队伍、随行/留守、加标签、去标签、加入遭遇、休息、移入回收站；需要目标的操作逐人预览后一次确认。
7. **标签**：详情顶部"+标签"打开可搜索下拉，列出已有标签并标记"已添加"，输入新名称回车即"新建并添加"，可连续添加；药丸 × 只移除该人物的标签；点标签文字加入列表筛选；"标签管理"提供使用人数、改名、删除。
8. **回收站**：移入回收站的人物不参与任何列表、遭遇、休息与 AI 摘要；找回时恢复队伍与标签；彻底删除前在原处列出姓名确认。
9. **日常检定**：人物详情中点技能/豁免/攻击/法术，或"行动"分页中的行动 → 骰盘悬浮窗自动打开并预填 → 按模式重掷 → 确认 → 结果进入待发送队列（默认以注释追加到输入框）→ 玩家发送消息 → AI 按结果写剧情。不可执行的行动显示原因。
10. **切换地点**：页头 📍 或地图页"设为当前"；对话提及已有地点名时出现切换提示；切换后摘要更新，行程自动记一条。
11. **战斗**：战斗页"开始遭遇"（选参战者：当前冒险队伍随行成员默认勾选；敌人来自预设遭遇、模组模板或已有人物 → 先攻方式 → 确认）→ 回合推进，当前行动者的行动在底部行动栏，经骰盘悬浮窗结算；点参战者打开同一人物详情 → 结束遭遇 → 小结（经验、战利品入公共背包、"移除已击败的普通敌人"默认勾选、写日志）。
12. **准备**：地图页建地点、写描述、关联卡片、放底图与点位；战役页建遭遇与任务；或导入冒险（库·本存档·冒险）。做好的内容可存到我的库，或导出为模组包。
13. **活动**：活动页选择流程 → 分步窗口（参与者默认为当前冒险队伍随行成员，可增减）→ 结果经骰盘悬浮窗确认。
14. **查询**：资料页搜索 → 详情卡（可钉住）→ 加入▾ / 提供给 AI。
15. **存档**：存档名▾ → 保存 / 分支存档 / 读档 / 新存档；有未保存改动时提示"保存 / 不保存 / 取消"。

## 7. AI 信息分层与输出

| 层 | 读取者 | 内容 |
|---|---|---|
| 事实层 | RP AI 与 DM 助手（注入） | 当前地点与描述；此地关联条目名单；最近对话提及条目的描述；当前冒险队伍随行成员拥有项的数值；遭遇轮次、先攻与参战者状态；进行中任务；最新确认的掷骰与结算 |
| 第四面墙层 | 仅 DM 助手（检索） | 规则条目、模板全文、DM 秘密、敌人精确数值、完整日志、历史存档 |

**提及激活**：发送消息、收到回复、切换回复、切换聊天时，扫描最近 3 层对话；条目关键词命中即激活，进入"相关"范围，并按其"给 AI"级别进入事实层。

**"给 AI"级别**：自动（按摘要规则）/ 只给名字 / 完整 / 不提供；资料页的结果可单独"提供给 AI"。

**掷骰输出**（文字均可在确认前编辑）：
- 注释（默认）：确认后追加到输入框末尾，保留玩家已写内容，不自动发送；发送前多次确认合并为一个块。
  ```
  <!--TRPG
  掷骰 盖尔·感知检定 d20[9]+2=11 vs DC? 普通
  前提:… | 裁决:…
  结算:狗头人A HP5→0 倒地
  -->
  ```
- 注入：作为"最新掷骰"写入提示词注入，保留到下一条用户消息发出。
- 填入失败时结算保持有效，骰盘悬浮窗显示"尚未填入"并提供"再次填入 / 复制"；同一结算不会重复生效；待裁定内容以"待裁定"表述。

**状态摘要**（事实层，每次生成前保持最新）：
```
[TRPG|5e2014|存档:龙金劫-2]
地点:龙骨洞 — 潮湿的海蚀洞，通往码头与深处祭坛
此地相关:码头监工葛雷、狗头人部落
提及:托姆 — 驼背老渔夫，说话夹着咳嗽
遭遇 第2轮 先攻:▶盖尔 → 邦妮 → 狗头人A → 狗头人B
队:盖尔(你) 法师3 HP12/18 AC12 专注[护盾术] 位1:2/4 2:1/2 | 邦妮 战士3 HP30/30 AC16 回气1/1
敌:狗头人A 重伤 倒地 | 狗头人B 无伤
任务:▶寻找龙蛋（当前目标：进入祭坛）
最新:盖尔 魔法飞弹→狗头人A 伤7
```
摘要规则：只写人物实际拥有的项；默认值与空值不写；法术位写到最高拥有环阶，契约位另列；人物以对外称呼出现；敌人默认写可见状态（设置可改为精确数值）；任务只写进行中与最近变化；总长默认上限 1200 token，超出按优先级截断并在预览中标出；各部分可单独开关。

**同步状态**：AI 预览抽屉分别显示"待更新"（当前数据生成的内容）与"已同步"（最近一次写入提示词的内容）；提供暂停与恢复。
