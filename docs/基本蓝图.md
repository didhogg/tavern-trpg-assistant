# 基本蓝图

本文件定义产品整体骨架。每个 Unit 的界面细节、字段与交互在 `docs/units/` 的单元蓝图中定稿。

## 1. 信息层级与数据原则

```
规则（如 D&D 5e 2014）              ← 最高层；切换规则 = 切换整套界面上下文
 ├─ 数据包     资料：怪物、法术、物品、职业、种族、背景、专长、规则条目
 └─ 模组扩展   地点与底图、人物/物品/敌人模板、关联关系、任务、遭遇、变体与房规开关、活动
存档（属于一个规则；全局存放，标注所属角色卡）
当前数据（每张角色卡/群组一份；属于一个规则；自动持久化）
```

- 数据包与模组扩展是同一种内容包格式，以 `kind` 区分；全局安装，所有角色卡通用。
- 插件保存两类数据：**静态资料与关联**（条目、描述、地点与卡片的关联）和**规则状态**（数值、资源、状态、背包、遭遇、先攻、日志）。剧情中的时间、天气、人物去向与是否在场由 RP AI 依据对话判断。
- 新存档：选规则 → 勾选该规则下的数据包与模组 → 命名。分支存档：把当前数据另存为新存档位并切换过去，原存档保持原样。
- 保存：玩家点"保存"时把当前数据写入当前存档；读档、分支、新存档前自动写入自动存档位（滚动保留 3 个）。
- 模板与游戏内副本：模组与数据包中的条目可直接查看、引用、交给 AI；对条目执行需要记录状态的操作（掷骰、加入遭遇、编辑、加入队伍、设为常驻）时，自动在当前数据中生成该条目的副本并记录来源。模板更新时提示可同步并显示差异。
  - **唯一**条目（具名 NPC、首领、唯一物品）在当前数据中只有一份，所有地点与遭遇引用同一份。
  - **普通**条目（普通怪物等）每次加入遭遇生成新的副本并自动编号。
- 地点、人物、敌人、任务、遭遇在任何时候都可以手动新建、编辑、删除。
- 每个条目有两个可选文本字段：**描述**（进入 AI 事实层）与 **DM 秘密**（第四面墙层）。

## 2. 界面结构

```
悬浮球（可拖动、贴边；点击打开/收起悬浮窗）
悬浮窗（可拖动、可缩放；完整 / 迷你两种模式）
 ├─ 顶栏：[存档名▾ ●未保存] [📍当前地点▾] [⚔第N轮]（遭遇中显示） … [🔍] [AI≈token] [⋯] [–] [✕]
 ├─ 标签：人物（主页） · 战斗 · 地图 · 战役 · 活动
 ├─ 内容区
 └─ 骰盘（所有标签常驻；全部掷骰在此展开、确认、发送；"记录▴"展开最近记录与待发送队列）
```

| 入口 | 唯一职责 |
|---|---|
| 存档名▾ | 存档抽屉：保存、分支存档、读档、自动存档、新存档 |
| 📍当前地点▾ | 可搜索下拉，切换当前地点（自动记行程）；对话提及已有地点名时旁边出现"提到了『X』，切换？"提示 |
| ⚔第N轮 | 跳到战斗标签 |
| 🔍 | 资料搜索层：当前规则下的数据包与模组条目；结果可"加入▾"（队伍/NPC/敌人/当前遭遇）与"提供给 AI" |
| AI≈token | AI 内容预览抽屉：状态摘要、待发送掷骰、各条目"给 AI"设置、暂停提供、待更新/已同步状态 |
| ⋯ | 规则与扩展库、设置、上手引导、关于 |
| – | 切换迷你模式 |

| 标签 | 职责 |
|---|---|
| 人物 | 队伍、NPC、敌人的列表与人物详情；日常检定入口 |
| 战斗 | 遭遇的开始、先攻、回合推进、结束；战斗中的行动栏 |
| 地图 | 地点树、地点详情与关联、底图、点位、区块、设为当前地点 |
| 战役 | 遭遇（预设敌人组）、任务、日志 |
| 活动 | 规则与模组注册的流程：短休、长休、扎营、模组活动 |

## 3. 人物模型

| 属性 | 取值 | 修改位置 |
|---|---|---|
| 卡型 | 完整卡 / 属性块（名称由规则包提供） | 新建时选定 |
| 身份 | 队伍成员 / NPC / 敌人 | 详情顶部分段按钮；多选批量 |
| 所属队伍 | 身份为队伍成员时必选；可有多支队伍，其中一支为**当前冒险队伍** | 选择"队伍成员"时的下拉；换队伍 |
| 随行 / 留守 | 仅队伍成员 | 详情顶部；多选批量 |
| ★玩家角色 | 每支队伍至多一人；摘要中标为"你" | 详情顶部 |
| 📌常驻 | 开/关；常驻者总在"相关"范围中 | 列表行或详情顶部 |
| 对外称呼 | 可选；AI 摘要使用对外称呼 | 详情 |
| 关键词 | 名字、对外称呼、别名；用于提及激活 | 详情 |
| 给 AI | 自动 / 只给名字 / 完整 / 不提供 | 详情；AI 预览抽屉 |
| 标签 | 多个；只用于分类、搜索、筛选 | 详情 +标签；多选批量 |
| 唯一 / 普通 | 来自模板；见 §1 | 模板定义 |
| 状态 | 正常 / 草稿 / 回收站 | 自动；移入回收站 |

## 4. 主流程

1. **首次进入**：选规则 →（可选）数据包与模组 → 命名 → 人物标签空状态 + 上手清单；或"试玩示例冒险"载入 SRD 示例模组与预设角色。
2. **新建人物**：任一入口打开同一个"新建人物"对话框——身份（默认等于当前视图）、所属队伍（身份为队伍成员时）、来源（从模板 / 空白）、模板搜索与预览、数量（敌人）、卡型（空白时）、名称、"同时加入当前遭遇"（遭遇中）。创建后进入该人物详情，显示"草稿"与"待填 N 项"，必填项完成后转为正常；提示条提供撤销。其他入口带上下文预填：🔍"加入▾"、战斗"+加入"、遭遇编辑"新建…"。完整卡另有"分步创建"入口。
3. **改身份与入队**：在人物详情顶部切换身份；切到队伍成员时选择队伍；多人用多选批量。人物始终是同一份数据。
4. **队伍管理**：队伍切换器提供新建、改名、设为当前冒险队伍、解散；解散后原成员身份变为 NPC，标签保留。成员顺序可调整；"📦 队伍公共"管理公共背包、金币与成员顺序。
5. **相关人物**：NPC 与敌人视图默认显示"相关"——最近对话提及（扫描最近 3 层，按关键词匹配）、当前地点关联、当前遭遇参战者、常驻；"全部"显示当前数据中的全部人物；"模组库"浏览已启用模组的人物模板。
6. **列表操作**：搜索覆盖姓名、对外称呼、种族、职业、标签；标签筛选为"同时具备"；显示"显示 N / 共 M"；"清除条件"保留排序；筛选与排序在切换页面后保留。多选模式下"全选"作用于全部筛选结果，批量操作有改身份、换队伍、随行/留守、加标签、去标签、加入遭遇、休息、移入回收站；需要目标的操作逐人预览后一次确认。
7. **标签**：详情顶部"+标签"打开可搜索下拉，列出已有标签并标记"已添加"，输入新名称回车即"新建并添加"，可连续添加；药丸 × 只移除该人物的标签；点标签文字加入列表筛选；"标签管理"提供使用人数、改名、删除。
8. **回收站**：移入回收站的人物不参与任何列表、遭遇、休息与 AI 摘要；找回时恢复队伍与标签；彻底删除前在原处列出姓名确认。
9. **日常检定**：人物详情中点技能/豁免/攻击/法术，或"行动"分页中的行动 → 骰盘展开掷骰卡 → 按模式重掷 → 确认 → 结果进入待发送队列（默认以注释追加到输入框）→ 玩家发送消息 → AI 按结果写剧情。不可执行的行动显示原因。
10. **切换地点**：顶栏 📍 或地图页"设为当前"；对话提及已有地点名时出现切换提示；切换后摘要更新，行程自动记一条。
11. **战斗**：战斗页"开始遭遇"（选参战者：当前冒险队伍随行成员默认勾选；敌人来自预设遭遇、模组模板或已有人物 → 先攻方式 → 确认）→ 回合推进，当前行动者的行动在底部行动栏，经骰盘结算；点参战者打开同一人物详情 → 结束遭遇 → 小结（经验、战利品入公共背包、"移除已击败的普通敌人"默认勾选、写日志）。
12. **准备**：地图页建地点、写描述、关联卡片、放底图与点位；战役页建遭遇与任务；或从库导入模组。
13. **活动**：活动页选择流程 → 分步窗口（参与者默认为当前冒险队伍随行成员，可增减）→ 结果经骰盘确认。
14. **查询**：🔍 搜索 → 详情卡（可钉住）→ 加入▾ / 提供给 AI。
15. **存档**：存档名▾ → 保存 / 分支存档 / 读档 / 新存档；有未保存改动时提示"保存 / 不保存 / 取消"。

## 7. AI 信息分层与输出

| 层 | 读取者 | 内容 |
|---|---|---|
| 事实层 | RP AI 与 DM 助手（注入） | 当前地点与描述；此地关联条目名单；最近对话提及条目的描述；当前冒险队伍随行成员拥有项的数值；遭遇轮次、先攻与参战者状态；进行中任务；最新确认的掷骰与结算 |
| 第四面墙层 | 仅 DM 助手（检索） | 规则条目、模板全文、DM 秘密、敌人精确数值、完整日志、历史存档 |

**提及激活**：发送消息、收到回复、切换回复、切换聊天时，扫描最近 3 层对话；条目关键词命中即激活，进入"相关"范围，并按其"给 AI"级别进入事实层。

**"给 AI"级别**：自动（按摘要规则）/ 只给名字 / 完整 / 不提供；🔍 搜索结果可单独"提供给 AI"。

**掷骰输出**（文字均可在确认前编辑）：
- 注释（默认）：确认后追加到输入框末尾，保留玩家已写内容，不自动发送；发送前多次确认合并为一个块。
  ```
  <!--TRPG
  掷骰 盖尔·感知检定 d20[9]+2=11 vs DC? 普通
  前提:… | 裁决:…
  结算:狗头人A HP5→0 倒地
  -->
  ```
- 注入：作为"最新掷骰"写入提示词注入，保留到下一条用户消息发出。
- 填入失败时结算保持有效，骰盘显示"尚未填入"并提供"再次填入 / 复制"；同一结算不会重复生效；待裁定内容以"待裁定"表述。

**状态摘要**（事实层，每次生成前保持最新）：
```
[TRPG|5e2014|存档:龙金劫-2]
地点:龙骨洞 — 潮湿的海蚀洞，通往码头与深处祭坛
此地相关:码头监工葛雷、狗头人部落
提及:托姆 — 驼背老渔夫，说话夹着咳嗽
```
