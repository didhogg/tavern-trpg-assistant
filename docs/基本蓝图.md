# 基本蓝图

本文件定义产品整体骨架。每个 Unit 的界面细节、字段与交互在 `docs/units/` 的单元蓝图中定稿。

## 1. 信息层级

```
规则（如 D&D 5e 2014）              ← 最高层；切换规则 = 切换整套界面上下文
 ├─ 数据包     资料：怪物、法术、物品、职业、种族、背景、专长、规则条目
 └─ 模组扩展   地点与底图、NPC/敌人/物品模板、任务、遭遇、变体与房规开关、活动
存档（属于一个规则；全局存放，标注所属角色卡）
当前数据（每张角色卡/群组一份；属于一个规则；自动持久化）
```

- 数据包与模组扩展是同一种内容包格式，以 `kind` 区分；全局安装，所有角色卡通用。
- 新存档：选规则 → 勾选该规则下的数据包与模组 → 命名。
- 分支存档：把当前数据另存为新存档位并切换过去，原存档保持原样。
- 保存：玩家点"保存"时把当前数据写入当前存档；读档、分支、新存档前自动写入自动存档位（滚动保留 3 个）。
- 模板与实例：加入游戏时把模板完整复制为实例并记录来源；实例可自由编辑；可"存为模板"；模板更新时提示可同步并显示差异。
- 地点、NPC、角色、敌人、任务、遭遇在任何时候都可以手动新建、编辑、删除；模组只是一次性带入预制内容。
- 每个条目有两个可选文本字段：**描述**（进入 AI 事实层）与 **DM 秘密**（第四面墙层）。

## 2. 界面结构

```
悬浮球（可拖动、贴边；点击打开/收起悬浮窗）
悬浮窗（可拖动、可缩放；完整 / 迷你两种模式）
 ├─ 顶栏：[存档名▾ ●未保存] [📍当前地点▾] [⚔第N轮]（遭遇中显示） … [🔍] [AI≈token] [⋯] [–] [✕]
 ├─ 标签：队伍（主页） · 战斗 · 地图 · 战役 · 活动
 ├─ 内容区
 └─ 骰盘（所有标签常驻；全部掷骰在此展开、确认、发送）
```

| 入口 | 唯一职责 |
|---|---|
| 存档名▾ | 存档抽屉：保存、分支存档、读档、自动存档、新存档 |
| 📍当前地点▾ | 可搜索下拉，切换当前地点（自动记行程） |
| ⚔第N轮 | 跳到战斗标签 |
| 🔍 | 资料搜索层（当前规则下的全部资料；结果可"加入▾"队伍/遭遇/战役） |
| AI≈token | AI 内容预览抽屉（状态摘要、待发送掷骰、注入位置） |
| ⋯ | 规则与扩展库、设置、上手引导、关于 |
| – | 切换迷你模式 |

| 标签 | 职责 |
|---|---|
| 队伍 | 队伍成员列表与角色卡；日常检定入口 |
| 战斗 | 遭遇的开始、先攻、回合推进、结束；战斗中的行动入口 |
| 地图 | 地点树、地点详情、底图、点位、区块、设为当前地点 |
| 战役 | NPC、敌人、遭遇（预设敌人组）、任务、日志 |
| 活动 | 规则与模组注册的流程：短休、长休、扎营、模组活动 |

添加入口：队友在"队伍"；敌人在"战役→敌人/遭遇"（准备）或"战斗"（临时加入）；地点在"地图"；NPC、任务在"战役"；🔍 结果的"加入▾"可送往以上任一处。

## 3. 主流程

1. **首次进入**：选规则 →（可选）数据包与模组 → 命名 → 队伍页空状态 + 上手清单；或"试玩示例冒险"直接载入 SRD 示例模组与预设角色。
2. **日常检定**：队伍页角色卡点技能/豁免/攻击/法术 → 骰盘展开掷骰卡 → 按模式重掷 → 确认 → 结果进入待发送队列（默认以注释追加到输入框）→ 玩家发送消息 → AI 按结果写剧情。
3. **切换地点**：顶栏 📍 或地图页"设为当前" → 摘要更新 → 行程自动记一条。
4. **战斗**：战斗页"开始遭遇"（选参战者 → 先攻方式 → 确认）→ 回合推进，当前行动者的行动在骰盘结算 → 结束遭遇 → 小结（经验、战利品入公共背包、写日志）。
5. **准备**：地图页建地点与底图点位；战役页建 NPC、敌人、遭遇、任务；或从库导入模组。
6. **活动**：活动页选择流程（短休/长休等）→ 分步窗口 → 结果经骰盘确认。
7. **查询**：🔍 搜索 → 详情卡（可钉住）→ 加入▾。
8. **存档**：存档名▾ → 保存 / 分支存档 / 读档 / 新存档；有未保存改动时提示"保存 / 不保存 / 取消"。

## 5. 数据框架

| 实体 | 作用域 | 要点 |
|---|---|---|
| RuleSystem | 代码注册 | id、名称、actor 结构、掷骰构建器、结算器、活动、摘要片段 |
| ContentPack | 全局 | id、kind（data/module）、ruleId、版本、来源与协议、条目 |
| Template | 内容包内 | 怪物、法术、物品、职业、种族、背景、专长、规则条目、NPC、地点、任务、遭遇 |
| Workspace（当前数据） | 每卡/群组 | ruleId、启用的包@版本、实例集合、当前地点、遭遇、日志、设置 |
| Actor 实例 | Workspace | 角色/NPC/敌人；sourceRef；描述；DM 秘密 |
| Location | Workspace | 父子层级、描述、DM 秘密、底图、点位、区块、在场对象 |
| Quest / Encounter | Workspace | 状态与目标 / 预设敌人组 |
| Ledger 条目 | Workspace | 掷骰、结算、物品、金币、行程、休息、任务；可撤销项带反向数据 |
| SaveSlot | 全局 | Workspace 快照、所属卡、规则、时间、类型（手动/自动） |

## 6. AI 信息分层与输出

| 层 | 读取者 | 内容 |
|---|---|---|
| 事实层 | RP AI 与 DM 助手（注入） | 队伍成员拥有项的数值、遭遇轮次与先攻、敌人可见状态、当前地点、在场对象的描述、进行中任务、最新确认的掷骰与结算 |
| 第四面墙层 | 仅 DM 助手（检索） | 规则条目、模板全文、DM 秘密、敌人精确数值、完整日志、历史存档 |

**掷骰输出**（两种方式，文字均可在确认前编辑）：
- 注释（默认）：确认后追加到输入框，发送前多次确认合并为一个块。
  ```
  <!--TRPG
  掷骰 盖尔·感知检定 d20[9]+2=11 vs DC? 普通
  前提:… | 裁决:…
  结算:狗头人A HP5→0 倒地
  -->
  ```
- 注入：作为"最新掷骰"写入提示词注入，保留到下一条用户消息发出。

**状态摘要**（事实层，每次生成前保持最新）：
```
[TRPG|5e2014|存档:龙金劫-2]
地点:龙骨洞 — 潮湿的海蚀洞，通往码头与深处祭坛
遭遇 第2轮 先攻:▶盖尔 → 邦妮 → 狗头人A → 狗头人B
队:盖尔 法师3 HP12/18 AC12 专注[护盾术] 位1:2/4 2:1/2 | 邦妮 战士3 HP30/30 AC16 回气1/1
敌:狗头人A 重伤 倒地 | 狗头人B 无伤
在场:老渔夫托姆 — 驼背，说话夹着咳嗽
任务:▶寻找龙蛋（当前目标：进入祭坛）
最新:盖尔 魔法飞弹→狗头人A 伤7
```
摘要规则：只写角色实际拥有的项；默认值与空值不写；法术位写到最高拥有环阶，契约位另列；敌人默认写可见状态（设置可改为精确数值）；描述只写当前地点与在场对象；任务只写进行中与最近变化；总长默认上限 1200 token，超出按优先级截断并在预览中标出；各部分可单独开关。
